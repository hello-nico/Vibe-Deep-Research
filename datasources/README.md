# 数据源 adapter + registry(Phase 1)

`registry.json` 是运行时端点注册表，记录各端点的市场、来源、合规标记、参数、阶段与启用状态。
完整目录见 [CATALOG.md](CATALOG.md)，由 `scripts/gen_catalog.py` 生成并通过测试核对端点清单；数据源连通性体检用 `scripts/health.py`。

## CI 范围

注册表保留 54 个端点：交易日历独立脚本，以及仍含在用端点的源模块。无产品调用的 19 个整模块与七个 legacy 脚本已删除；同文件内其余端点不在本批删除范围。完整端点、市场和参数以注册表及目录为准。

动态 `/feed` 的行情与资讯、`doctor --net` 等在用能力保留。行业、产业研究和信号页面已删除，旧地址统一回关注；`gpu_rent_thermometer` 等保留模块端点不随页面扩删。数据源相关离线测试覆盖注册装配、东财、概率、产业、商品、招聘、HTTP传输与脱敏；不把源连通性或模型研究质量算作离线测试通过。

合规标记和已登记不等于本次可用；当前取数成功、缺口和限制以运行信封为准，也不构成对所有来源商用或再分发权限的保证。
