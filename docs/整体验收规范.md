# 整体验收规范

状态：长期有效的整体测试与验收标准（2026-09-24 由首轮“核心特色整体验收清单”转成）。**只追加用例；只有需求变更（记入 Human Checklist 后）才修改已有用例的预期。**

权威：[产品对象模型与交互 v1](产品对象模型与交互_v1_2026-09-23.md)；[Human Checklist](../human-checklist.md) 各节决定；[开发工作流范式](开发工作流范式.md)。

## 0. 分工与流程

| 角色 | 做什么 |
|---|---|
| 用户 | 重建 Backend、重启工作台，在可见浏览器里打开工作台；说“整体测试”启动一轮；最后看 Claude 的验收结论 |
| Codex（computer use） | 按本文件逐条在真实界面操作、截图、记录结果；**不改代码、不修问题、不重启服务** |
| Claude | 审阅 Codex 的结果与截图，判定通过 / 不通过，汇总问题出修复 Task；修完只复验对应编号 |

一轮流程：用户准备环境 → Codex 执行并写结果 → Claude 验收 → 修复 Task → 复验对应编号。

## 1. 执行规则（Codex）

1. 只用用户已打开的工作台页面操作；不读取、打印或截取密钥、令牌、认证文件与个人配置；截图避开地址栏里的令牌与设置页的凭据字段。
2. 不点「移除」、不删除资料 / 记录 / 议题；需要发布草案、撤回假设等写操作时，只在本文件指定的对象上做。
3. 每条用例：按“操作”执行 → 对照“预期” → 截图 → 记结果：`通过` / `不通过`（写实际现象一句话）/ `跳过`（写原因，如条件不具备）/ `阻塞`（前置失败）。不猜测、不美化，没看到就写没看到。
4. 等待：研究、报告、Agent 回答最长各等 10 分钟；超时记 `不通过：超时`，继续下一条。
5. 结果与截图放 `.local/acceptance/<YYYY-MM-DD>/`（已忽略，不入库）：`result.md` + `NN-简述.png`。`result.md` 用 §4 格式。
6. 遇到服务断开、页面白屏等整体故障：停止，记录现象与时间，告知用户。

## 2. 前置条件

- [ ] 用户已重建 Backend 容器、重启工作台，并在可见浏览器中打开工作台。
- [ ] 设置中模型可用；配色任选（亮 / 暗），加载页应跟随。
- 默认对象：公司 **长江电力**（已有“持股湖北能源”事实关系）、**华能蒙电**（有过期报告）；议题“电力行业公司结构：水电主体的控股与配售电平台结构”。可另选一家新公司从零走。

## 3. 用例

编号永久不变；新增用例接在末尾编号。标注“（可选）”的条件不具备时记 `跳过`。

### 3.1 公司：研究与草案

1. 个股研究名单：有待处理事项的公司行显示状态徽标（报告已过期 / 有新资料 / 草案待确认 / 建立中 / 待确认维护）；灰色行业与“图文报告”标签不算徽标。点徽标到对应处理位置（报告已过期 → 该公司「图文报告」分段）。
2. 公司页「刷新资料」：发现新资料时弹出确认；确认后“资料截至”变为当天（名单与公司页一致）；无新资料时提示“暂无新增资料”，日期不变。
3. 发起公司研究：刷新 / 研究进行中时，「生成图文报告」禁用并有提示。
4. 「我的研究 · 任务」点「查看过程」：右侧面板为原生过程视图（整轮折叠、中文工具行、任务清单卡片），可切「公司研究 / 知识整理」两段，运行中实时增长。
5. 研究完成收到提醒；出草案时「待处理」出现该条，左侧导航有数字。
6. 审阅草案并发布：研究页内容更新；「待处理」该条消失，任务显示“已发布”。
7. （可选）草案超过 24 小时未处理，或刷新资料使研究页更新：任务显示“草案已失效 · 原因”，「重新整理」可重新开始。
8. 页内链接直接进对象主页，没有“返回上一份材料”，没有“正文暂不可读”条目：公司研究页的“所属行业”“相关研究材料”；「行业研究」行业 Wiki 页的“成员公司”。「产业研究」（申万）页顶部“覆盖公司”为纯文本，不在本条范围。（2026-09-24 改：写明页面，避免与产业研究页混淆）

### 3.2 问助手

9. 公司页右上「问助手」：面板为产品配色；Ask、Agent 各问一次，回答为原生样式，引用为行内小标签。
10. 回答操作行里有「保存为记录」，保存后到「我的研究 · 记录」能看到。
11. 面板打开时点回答里的对象标签：主区跳转，面板保持。

### 3.3 议题：研究与判断

12. 进入议题页：「研究页 / 证据墙 / 图文报告」三个分段。
13. 「继续研究」：右侧面板打开议题会话并开始回答；深度对话里原来的会话不被替换。
14. 议题页「更多」→「新会话」：右侧面板首屏为议题开场（标题、判断、可点问题）。（2026-09-24 改：写明入口位置）
15. 议题 Agent 形成或修订判断后，研究页“当前判断”更新并显示判断时间。

### 3.4 证据墙

16. 证据墙显示议题相关对象；长江电力 → 湖北能源为深色“持股”实线；点线弹出小卡，「查看依据」可打开原文依据。
17. 判断便签在左上，虚线箭头指向依据对象。
18. 「画假设线」：依次点两个对象、写一句说明、保存；刷新后仍在（灰色虚线“未核验”）。
19. 点假设 →「找依据」：右侧议题会话开始核对；如给出升格提案，「确认升格」后变为橙色实线，原说明保留；「保持假设」则不变。
20. 拖动节点后刷新，位置保持；「重新排布」复原。
21. 没有对象的新议题：墙显示空白态说明与「继续研究」。

### 3.5 依据变化（议题研究页）

22. 刷新议题依据公司的资料并发布，使研究页更新。
23. 证据墙上该公司节点出现“判断后有更新”；点它切到研究页。
24. 研究页出现“判断之后依据有更新”：按研究结论 / 数据 / 资料时间线列出，可展开看前后对比；无变化依据显示“资料无变化”。
25. 「带着这些变化继续研究」：议题 Agent 先说明变化，不自动改判断。

### 3.6 图文报告（公司与议题）

26. 公司「图文报告」：研究页更新后，旧报告仍显示并提示“研究页在这份报告生成后有更新”，分段上有提示点；「重新生成」得到新报告。
27. 议题「图文报告」：生成后包含研究问题、当前判断、依据对象与关系图（假设标“未核验”）、继续核实与缺口；引用可点开依据。
28. 修订议题判断后回到议题报告：显示对应旧版本，可重新生成。

### 3.7 顺带观察（遇到就记）

29. 关闭「查看依据」后公司页首卡是否空白（若出现，记录是否滚动、窗口宽度）。
30. 新的知识整理摘要、议题建议理由是否为中文。
31. 深度对话读年报时若暂存事实，结束后是否还有“事实未通过核对”。
32. 回答里是否出现未渲染的 `**…**`、正文自我更正（“此处应引…”）或未经计算的派生数字。
33. 布局：侧栏「设置」与导航一致；右侧面板与顶栏留有间距；窗口宽度 ≥ 900px 时面板与主区并排、互不遮挡；< 900px 时面板作为抽屉覆盖主区，可用 × 关闭，关闭后主区完整可见。（2026-09-25 改：窄窗口放不下两栏，改为覆盖式抽屉）

### 3.8 问助手：页面上下文

34. 大盘行情问助手 Ask 问“今天大盘啥情况”：不出现“页面上下文暂存失败”；气泡只有原话与 @ 标签（没有「页面快照」大段文字）；过程里有「读取页面上下文」；回答基于当前页面数字。
35. 同页 Agent 问一个页面答不了的问题：过程里先读页面上下文，再去读研究页 / 原文 / 网页。
36. 资讯雷达 · 公开新闻 @ 一条再问：回答只围绕这一条，不卡；不 @ 问“本栏要点”：能概括整栏。
37. 问助手空白时有引导卡片（实线浅底，Ask / Agent 小标签，右上角 × 可关闭）；引用是灰色行内小标签，不是蓝色链接；「保存为记录」在复制 / 点赞那一行。

### 3.9 缺口与取数

38. 新生成的报告与研究页里，缺口项（如「现金分红」）显示“待补充”，不可点，不出现“稍后重试”。（可选）旧报告里仍可点的缺口项，点开显示“这一项目前是缺口，还没有取到数据”；找不到旧报告时记跳过。（2026-09-24 改：新报告缺口不加引用，区分新旧报告） 议题报告的缺口以说明句列在“缺口”段即可，不要求“待补充”标签。（2026-09-25 补：议题报告缺口为整句说明）
39. 盘后或断网时打开大盘行情：取数失败的块标题旁出现黄色小点，鼠标移上显示“这次没有取到最新数据，显示的是 HH:MM 的内容”；页面上不出现接口名、HTTP 状态码等技术细节，也不说“可能是非交易时段”；各块“更新于”是自己的时间。（2026-09-25 改：用户要求提示改为黄点 + 悬停说明，去掉技术性表述）

### 3.10 注入隔离（Jev 开启时）

40. 深度对话读一个普通新闻网页：工具行无“已隔离”。
41. （可选）读一个含“忽略之前指令”的测试网页：工具行“已隔离 1 条可疑内容”，回答说明来源被隔离。

### 3.11 界面细节

42. 撤回假设、放弃研究草案用的是产品确认框，不是浏览器弹窗。
43. 证据墙「展开画布」铺满整个窗口，「还原窗口」/ Esc 收回；证据墙下没有免责声明。
44. 证据墙节点名称：年报 / 公告显示真实标题（旧占位标题显示为“公司 报告期 类型”），研究记录显示记录标题，不再出现“资料 / 引用”。
45. 侧栏「资讯雷达」无二级菜单，页内分段切换来源，“投资资讯”为中文。
46. 加载页配色跟随设置；侧栏「设置」与导航对齐；右侧面板不贴顶栏；模型下拉菜单为产品配色。

### 3.12 公司研究页

47. 未做公司研究的公司（如华能蒙电）研究页「经营」：说明“还没有从年报中读出的经营数据…”，并列出待补项目标签（装机容量、发电量等）；没有待补清单的公司显示“资料待补充”。

### 3.13 2026-09-25 补充

48. 资料阅读页（从「我的资料」、产业研究的研报，或「查看依据 → 阅读原文」进入）：右上角有「问助手」；选中正文后点「就此追问」，右侧打开以该资料命名的问助手，输入框上方显示“已选原文”（可展开、可 × 移除）；提问后回答只围绕所选原文。
49. 「查看依据」面板与资料时间线的资料标题为“公司 + 报告期 + 报告类型”（如“长江电力 2025 年年度报告”），不出现 `legacy:` 编号；财务块指标名为中文（如“财务费用”“毛利率”）。
50. 任务列表、大盘行情的状态点：鼠标移上去立即显示说明，不出现问号光标。

51. 深度对话问“伊利股份 2026 年半年报的营收、归母净利润、经营现金流分别是多少”：数字旁有可点引用标签，点开是半年报对应原文块（不是整份文档）；回答中的粗体正常显示，不出现 `**`。

### 3.14 2026-09-26 补充

52. 研究名单：发起公司研究后，该行显示“公司研究进行中 · 已用 N 分钟”（橙色）；研究结束后变为“研究已完成，正在整理结论”；有草案时显示“有新的研究结论，确认后写入研究页”；生成图文报告时显示“图文报告生成中 · 已用 N 分钟”，此时“报告已过期”标签暂时隐藏。
53. 公司研究页工具栏：研究进行中按钮为「研究中…」、整理时为「整理中…」、生成报告时为「报告生成中…」，均带转圈且可点击（前两者进入任务记录，后者切到图文报告）；页面顶部进度卡片说明当前阶段并有「查看任务记录」。
54. 研究名单“资料截至”：最近一次研究或刷新晚于资料日期时，显示“资料截至 MM-DD · MM-DD 已核对”。
55. 图文报告页（公司、行业、议题）：还没有报告时显示「生成报告」按钮，不会自动开始生成。
56. 深度对话「新建对话」后在输入框输入 “/” 或 “@”：菜单完整可见（首页向下展开，已有对话向上展开）。
57. 公司研究（含知识整理）完成后不再出现 409 版本冲突失败；有新结论时在「待处理」出现草案，采用后研究页“经营”块更新，财务 / 估值数据仍为最新。
58. 「我的研究 · 任务」每页 10 条，底部显示“第 X / Y 页 · 共 N 个任务”，翻页正常；从“待处理”点进某个草案时自动翻到它所在页。
59. 图文报告中数字与原文对不上的引用旁显示“待核”标记。
