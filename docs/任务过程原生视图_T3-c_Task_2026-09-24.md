## 1. 目标

## 2. 现状（2026-09-24 Claude 核实）

- 面板：`components/TaskProcessPanel.tsx`（壳：类别 + 标题、关闭、拖拽柄；正文 `TaskTranscript`；公司研究分“第一阶段 · 公司研究 / 第二阶段 · 知识整理”两段；底部「中止」「打开成果」），由 `components/layout/FinanceRoot.tsx` 渲染，状态在 `dsh/client.tsx` `openTaskProcess / getTaskProcess`。
- 任务引用 `TaskProcessRef`（`dsh/research-session.tsx`）：`sessionId`、`parentSessionId`（隐藏任务宿主）、`settlementSessionId`、`kind`、`status`、`resultRef`。任务会话是宿主下的子会话，模式可从宿主投影 `subagentCatalog` 取得（`dsh/client.tsx` 已有读取），或用 `client.sessions.subagentAddress(id)`。
- 原生嵌入的现成示范：`@deepseek-ai/dsh-client-ui-subagent` `lib/client.js` 的 `SidebarChatTab` / `ConversationSlotPanel`：`ctx.sessions.retain(address, { source, signal })` 得到 `SessionReference` → `SessionProvider session={reference}` → 渲染 `conversation.content`（`variant: "embedded"`，视图固定为 Chat）。产品 `dsh/client.tsx` 已在用 `sessions.retain` 与 `slots.register`。
- `TaskTranscript` 另被问助手 `components/ui/FinanceAiDock.tsx` 使用（含“保存为记录”），属于 T3-b。

## 3. 冻结决定

- **容器不变**：继续用 `TaskProcessPanel` 的壳与 `finance-side-panel` 契约（宽度、拖拽、主区让位、Esc 关闭）；不接 DSH 右侧栏（`sidebarRight` / `rightbar`）。
- **嵌入方式**：产品注册自己的会话作用域槽位（如 `finance.panel.conversation`，`kind: single`、`scope: session`），组件照示范 `ConversationSlotPanel` 渲染 `conversation.content`（embedded、Chat 固定）；面板以 `SessionProvider` 包住它。会话引用在面板打开时 `retain`（优先用子会话地址 `{ parentSessionId, childSessionId, mode }`，取不到地址时用会话 id），关闭或切换任务时 `release`；`source` 用现有取值中语义最近的一个并回填理由。**不改变前台会话**（不调用 `uiWorkspace.openSession`），主区深度对话保持不变。
- **只读**：面板内不显示输入区与 DSH 自带的只读提示条（面板作用域内隐藏，优先槽位条件，其次作用域 CSS）；停止仍用底部「中止」。
- **公司研究两阶段**：面板头部加两段切换「公司研究 / 知识整理」，默认显示正在运行的阶段（都结束则显示公司研究）；无整理会话时第二段禁用并显示原有说明文字。报告、知识整理任务无切换。
- **运行状态**：「中止」显示条件改读原生会话 `running`（经 `useSessions` / 会话状态），不再依赖 `useTaskTrajectory`。
- **保留不删**：`TaskTranscript`、`lib/taskTrajectory.ts` 仍供问助手与任务提醒使用，待 T3-b 后统一清理；本 Task 只让 `TaskProcessPanel` 不再引用它们。
- 视觉只做功能所需的最小样式（嵌入内容铺满面板、滚动正确）；正式视觉由 Claude 收尾。
