# 记忆触发接入（影子模式：只判断、只记录）

状态：2026-09-25 Claude 写定；2026-09-26 用户决定不再等演示，**立即派发**。待 Codex 实施并回填 §8。执行方只跑自动检查，不重建、不重启、不提交。实施仓库：Stock-Research（`backend/`、`dsh/`）。

权威：[Jev 第 3 轮评估](Jev记忆触发评估_第3轮_Task_2026-09-25.md) §9.2 裁决；Human Checklist「记忆价值与 Jev 触发判断的发送边界（2026-09-25）」。

## 1. 目标

对用户在对话里发出的每条消息，用 Jev 判断是否属于记忆触发（偏好 / 纠正 / 跟踪 / 回忆 / 无），**只记录判断、不执行任何写入或召回**，攒真实正例用于复核阈值。回答不等待判断结果。

## 2. 冻结决定

1. **触发时机**：DSH 宿主在用户会话（深度对话、问助手、议题会话）的 `turn/start` 时异步发起判断；后台会话（公司研究、知识整理、报告任务）不判断。沿用第 3 轮 `evaluate_r3.py` 的过滤规则（产品模板、自动提示、斜杠前缀、引用序列化、验收语句、单条 > 800 字、含私有资料标记）——提到共享模块后由产品与脚本共用。
2. **发送内容**：用户原话（去掉 @ 引用的序列化片段，保留对象名称）+ 上一条助手回答前 400 字（第 3 轮变体 B）。不发送页面快照、工具结果、上传资料、研究记录正文。
3. **题面**：与第 3 轮完全相同（五选一，选项描述与示例原样复用，版本号记录在日志里）。
4. **Backend 接口**：新增 `POST /wiki/research-memory/trigger-judgements`（只允许宿主调用），经 `jev_gateway` 调用，结果写 `research/memory/trigger-log.jsonl`（只追加）：`id`、`session_id`、`turn`、`message`、`choice`、各类概率、`question_version`、`latency_ms`、`created_at`、`status`（completed / not_enabled / provider_error / budget_exhausted / skipped + 原因）。
5. **开关与预算**：`STOCK_RESEARCH_MEMORY_TRIGGER_SHADOW=1` 才启用；每日上限 `STOCK_RESEARCH_JEV_DAILY_LIMIT` 与注入隔离共用计数。失败不影响回答，不重试。
6. **不做**：任何记忆写入、召回注入、界面提示。日志只供 Claude 复核。
7. 复核脚本：`backend/scripts/jev_eval/trigger_log_report.py`，按阈值 0.5 / 0.7 / 0.9 输出各类数量与样例，供人工标注。

## 3. 范围

Stock：`app/services/memory_trigger.py`（新）、路由放新文件 `app/api/v1/memory_trigger.py` 并在 `app/api/v1/__init__.py` 注册（2026-09-26 修订：与报告 Task 并行，避免同时改 `wiki.py`；接口路径不变）、`dsh/src/research-tools.mjs`（`turn/start` 异步调用）、过滤规则共享模块、复核脚本与测试。

## 4. 验收

- **自动**：Backend pytest（开关关闭记 not_enabled 且不调用；过滤命中记 skipped；预算用尽；Jev 失败不影响；日志字段完整）；Stock DSH `pnpm run test`（后台会话不触发；回答路径不等待判断）；`git diff --check`。
- **用户验收**：开启开关后在深度对话说“以后金额都用亿元”“我之前怎么看万华的？”各一次，`trigger-log.jsonl` 分别出现 preference / recall 记录，回答速度无感知变化；记忆页内容不变。

## 5. Stop Conditions

- 宿主无法在不阻塞回答的前提下拿到本轮用户原话与上一条回答：停止，回填。
- 过滤规则无法在产品与脚本间共用而需要复制两份：停止，说明原因。

## 6. Out of Scope

记忆写入与“要记住吗？”确认界面、召回注入、跟踪项（M5）——待真实正例 ≥ 30 条并复核阈值后另立 Task。

## 7. 回滚

关闭开关即停用；日志可删除。
