## 1. 目标

确认能否用 DSH 0.1.7 右侧栏，为任意会话打开**原生对话视图**（交互 / 只读），作为问助手、议题研究、任务过程的统一容器；并确认它能否不随“全局当前会话”切换而串换。

## 2. 已核实（2026-09-24，Claude 只读）

- `@deepseek-ai/dsh-client-ui-sidebar-right`：`ctx.sidebarRight.openTab(kind, options)` / `openResource(address, options)` / `close` / `focus` / `isExpanded` / `toggleExpanded`；两种形态 `push`（让出会话区宽度）与 `fullscreen`；布局按会话存 `localStorage` `dsh.sidebar-right.v1.<sessionId>`。**右侧栏是“每个会话一个停靠面”**：标签归属当前会话，root 作用域 `rightbar` 通过 `rightbar.session` 子树渲染选中的会话。
- `@deepseek-ai/dsh-client-ui-subagent`：注册资源 `dsh-resource://subagentchat/session/<child>?parent=<parent>&mode=<mode>` 与标签类型 `subagentchat`；资源按地址持有子会话 `SessionReference`，标签经 `sidebar.chat.conversation` 渲染共享 `conversation.content`（固定为 Chat，省略主 Header）；已完成的 one-shot 子会话打开为**只读执行记录**，可续接的保留输入与独立停止。
- 产品现状：`components/layout/FinanceRoot.tsx` 已渲染 `slots.renderSlot('rightbar', …)`（固定定位 div）；`dsh/native-dsh.css` 隐藏了会话头右上角展开右栏按钮（`conversation.session.header.corner`）；报告 / 公司研究 / 知识整理是隐藏宿主（`report-tasks.json` `host_session_id`）下的子会话；议题会话与问助手会话是顶层会话；右侧面板统一契约 `finance-side-panel`（`components/layout/research-surfaces.css`，宽度变量与拖拽）。

## 3. 要回答的问题

1. **任务过程（只读）**：在任意产品页，用 `openResource` 打开 `subagentchat` 地址显示一个已完成的后台任务（报告、公司研究、知识整理各一），是否为只读原生视图；整轮折叠、中文工具行（`FinanceToolRow`）、任务清单卡片是否正常；运行中的任务能否实时更新与停止。
2. **顶层会话（交互）**：议题会话、问助手会话不是子会话。能否由产品仿照 `ui-subagent` 注册自己的资源与标签类型（如 `financesession`），持有该会话 `SessionReference` 并经 `sidebar.chat.conversation` 渲染；输入、发送、停止、Ask / Agent 模式（问助手绑定）是否可用；是否与主会话区的同一会话冲突。
3. **停靠面归属**：侧栏按会话持有停靠面。在个股页、议题页等非深度对话页，侧栏归属哪个会话？能否用一个**稳定的产品侧栏宿主会话**（可复用隐藏任务宿主，或新建专用宿主）承载所有侧栏标签，使切换页面、切换深度对话会话时侧栏标签不变；刷新后能否恢复。
4. **议题空白态**：议题新会话在侧栏中首屏能否替换为议题开场（不显示深度对话首页与“最近对话”）；可用哪个槽位或 CSS 范围。
5. **布局**：`push` 形态与产品布局（左导航、`#workspace-main`、现有 `finance-side-panel` 让位规则）是否兼容；两者择一还是可合并；宽度拖拽、全屏、窄屏表现；与 FinanceRoot 现有固定 `rightbar` 容器的关系。
6. **导航保持**：侧栏打开时点对象标签，主区路由切换，侧栏标签与会话是否保持不卸载。
7. **多标签**：同时开议题、问助手、任务过程三个标签，切换是否保留各自滚动与输入草稿。

## 4. 做法

- 原型用开发开关控制，默认关闭（如 `localStorage['finance-side-sessions'] = '1'`，读取包 try/catch）；开关关闭时产品行为完全不变。
- 在开关打开时提供最小入口：任务列表“查看过程”改走侧栏 `subagentchat`；议题页“继续研究”与问助手按钮改开侧栏会话标签。其余入口不动。
- 不改 DSH 包、不新增补丁；需要补丁才能实现的，按 §6 停止并说明。
