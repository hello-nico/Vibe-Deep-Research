# 工具与 Topic 系统审计

## 范围与权威

- 用户授权：首轮审计已交付；随后授权基于多轮实际 sessions 作出初步判断，实施工具收敛及协议补齐。
- 产品边界：`../human-checklist.md`「工具与 Topic 生命周期系统审计」。
- 研究协议：Stock-Research 现有 Backend、DSH 工具及 `docs/human-checklist.md`。
- 审计结果沿现有 `Tools与Skills审计_M7前置_2026-09-10.md` 更新，旧章节保留为历史。

## 工作包

1. 从真实 DSH request/header 提取全部工具、schema 和工具调用统计；与当前角色注册对照。
2. 全工具覆盖职责、输入、输出、状态前置、副作用、错误恢复；区分真实失败和静态风险。
3. 按真实业务场景提出保留、合并、限制可见、内部化和退役建议；不预设工具数量指标。
4. 对照 Topic/Wiki 现有约定与执行链，提出触发、创建、更新、追踪、失败和中止边界。
5. 交付证据清单、缺口优先级、分包实施建议及真实验收矩阵。
6. 依据历史轨迹确定本轮最小改动，补齐公开协议、减少无关暴露、同步示例；保护 Backend 校验。
7. 运行真实 DSH schema 注册与工具调用测试、历史失败参数重放、构建；能运行新模型时验证实际加载与自然问题。

## 验证与完成标准

- 真实请求全部工具均有清单，不用源码计数冒充实际加载。
- 实际角色外工具单列；每个协议发现有源码或轨迹依据。
- 生成材料不含系统全文、模型思考、凭据或个人配置。
- 机械检查文档链接、工具覆盖和 diff；不把只读审计称作模型对照实验。
- 当前轮完成以审计文档、可复核的生成清单和明确待决项为准。
- 修改后机械重放与新模型效果分开；不为验证制造生产 Topic 或发布数据。

## 本轮执行结果

- 已扫描 63 份真实会话文件，提取 469 次调用与 87 次错误；历史版本、验收与自然问题混合，不作为当前错误率。
- 已实施普通研究 Topic 只读、绑定 Topic 写入门禁、显式 UI 发起、计算 schema 收敛、文档/行情/Topic/PageSpec 协议补齐及 Wiki 导航输入精简。
- 构建后 DSH 注册：普通研究 30 tools / 33,900 字符；此前真实请求 32 / 85,039。定义精简不等于模型表现验收。
- DSH 构建和 69/69 测试通过；前端构建及议题相关 14/14 测试通过，后者包含源码契约断言及 mock HTTP。
- 真实 Backend 既有行情成果读取、双区间计算、再读一致通过；未新建成果图或 Topic。
- 浏览器已确认发起表单布局；未执行生产创建。协议清单、历史摘要和真实 Backend 回执在 `../artifacts/tool-audit*` 与 `../artifacts/session-tool-audit-2026-09-15.json`。
- 完整说明见审计文档 F 节。新模型采样、服务加载及同条件质量比较仍待运行；未重启服务、提交或 push。

## Out of Scope

- 数据迁移、Topic 清理、提交和 push；Backend 公开 API/持久化变更。
- 恢复六阶段、引入新框架、重建事实准入或发布权限。

## Stop Conditions

- 工具合并改变公开 API、持久化或权限时，先提交具体方案供用户判断。
- 缺少实际请求或 Provider 原因时保留未知，不用猜测补全证据。
- 用户尚未确认的新 Topic 语义不得写成已生效规则。
