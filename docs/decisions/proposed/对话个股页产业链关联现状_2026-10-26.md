# 对话、个股页、产业链页的关联现状（2026-10-26）

Claude 按代码与华友对话会话（c4146304）核实。只记现状，不提方案。

## 三个入口各是谁

| 入口 | Agent 角色 | 提示词 | 能写什么 |
|---|---|---|---|
| 对话（主对话） | `deep_research` | DEEP_PROMPT（中文，含引用、时点、估值、开始观察等纪律） | `update_company_drivers` 改个股页研究的变量与倍数；推荐「开始观察」「关注公司」；对话后整理（记忆、Wiki 提议） |
| 个股页「问助手」 | `company_wiki`（Ask / Agent 两模式） | COMPANY_PROMPT + ASK/AGENT_PROMPT（英文，较早一套） | 不能改研究（明文「cannot change research pages」）；不能推荐开始观察 |
| 个股页研究任务 | `company_research` | COMPANY_RESEARCH_PROMPT | 保存六节研究（个股页主体） |
| 产业链页 | **没有问助手**：`chain:` 页面不在 `assistantBindingForPage` 名单里，返回「本页没有问助手」；页面却写了一条推荐问题 | — | — |
| 动态卡「讨论」 | `company_wiki`，不绑公司 | 同问助手 | 同问助手 |

## 数据怎么流

```
                 ┌──────────── 公共层（Backend）────────────┐
                 │ 数据包 / 报告原文 / 行情 / 7 条预置链 / 行业估值框架 │
                 └───────┬──────────────┬──────────────┬────┘
                         │读            │读            │读（链结构、成员）
                         ▼              ▼              ▼
   对话 ──wiki_read──▶ 个股页研究 ◀──研究任务写入      产业链页
    │   (只读已存研究)      ▲  ▲                         │
    │                      │  └─ 链上公司档位、模型 ──────┘（读个股页研究）
    ├─update_company_drivers┘   （只改变量与倍数）
    ├─对话后整理 → 记忆（stated）→ 个股页「我的看法」
    ├─对话后整理 → Wiki 更新提议（awaiting_authorization）
    ├─开始观察 → 跟踪页「正在观察」（个股页不显示）
    └─（不能读产业链：对话工具里没有任何链工具）

   个股页「所属产业链」→ 产业链页：按申万二级成分自动挂链（紫金被挂到煤—电—铝）
   产业链页 → 个股页：链上公司名可点进
```

## 现状要点

1. 对话与个股页是「读多写少」：对话能读个股页研究，但只能改数字（变量、倍数），定性结论、新发现、跟踪点回不到个股页；整理提议又只是复制旧研究。
2. 同一家公司有两个助手：主对话（新纪律、能写回）与个股页问助手（旧提示词、不能写回），说法和能力不一致。
3. 产业链页是孤岛：没有问助手，对话读不到链，链只读个股页的档位；且链本身仍是预置的公共链（10-20 已定改为用户对象，待细化）。
4. 对话 → 跟踪的唯一通道（开始观察）会因文字带数字被整块丢弃。
