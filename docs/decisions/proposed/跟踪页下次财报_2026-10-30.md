# 跟踪页「下次财报」改版（2026-10-30）

状态：Owner 10-30 已裁决，见 §5；实施见 [Task](../../tasks/active/跟踪页下次财报改版_Task_2026-10-30.md)。
依据：Owner 10-30：「少了一个类似跟踪项一样的东西，而且它也不可点开。如果它占这么大个篇幅放在这里的话，就显得有点单调。」

## 1. 现状（Claude 核实）

- 一行一家公司：公司名 + 要核对的指标名 + 右边「年报 · 日期未定」。不可点开。
- 数据：Stock `backend/app/services/tracking_next_reports.py`。
  - 指标名取自研究里的「证伪条件」（`falsifiers`），只取了字段名，丢掉了条件本身。每条证伪条件其实带着：一句话（如「毛利率回落至上年水平以下，价差逻辑弱化」）、阈值（13.6%）、看哪份报告（「2026 年第三季度报告」）。
  - 日期：交易所已公布预约日的写日期；否则只推出下一份法定报告，写「日期未定」。
- 前端：`pages/Tracking.tsx` `NextReports`，按关注顺序排，不按日期排。`docs/design.md` 没有这一块的说明。

## 2. 为什么单调

1. **13 行里 11 行写「年报 · 日期未定」**。三季报季刚结束，年报预约日要到 12 月底交易所才公布，所以现在几乎都是这句，信息量接近零。
2. **指标名是字段名，不是判断**。「归属于上市公司股东的净利润」很长，又不说要看它什么，例如低于多少就改判断。
3. **不按时间排**。10-31 要出的长江电力、农业银行夹在中间，不是排在最前。
4. **点不开**。跟踪价格的行能展开看走势和影响，这里没有第二层。

## 3. 建议

**R1 行上（不展开）**
- 按日期近的排前：有日期的排前，「日期未定」的排后。
- 「日期未定」改写法定截止日：年报写「年报 · 最晚 4-30」，一季报写「最晚 4-30」，半年报写「最晚 8-31」，三季报写「最晚 10-31」。这几个日子是交易所规定的，不是猜的。
- 灰字指标名缩短：「归属于上市公司股东的净利润」写「净利润」；最多 3 个，多了写「等 N 项」。

**R2 可展开（和跟踪价格同一套展开样式）**
展开后逐条列证伪条件，每条一行：
- 一句话：这条证伪条件本身（研究里原文）；
- 阈值：「低于 13.6% 就改判断」；
- 看哪份报告：「看 2026 三季报」；
- 如果那份报告已经出了、系统已对账：写「已出：13.9%，未触发」或「已出：12.8%，已触发」。这一步复用现有对账数据，不新增数据源；拿不到就不写。

底部一个文字按钮「看{公司}」，进个股页。

**R3（可选）篇幅**
默认只显示最近 5 家，其余收进「另外 N 家」，和价格列表的「另外 N 项」一样。

## 4. 需要 Owner 决定

1. R1 + R2 一起做，可以吗？（推荐）
2. R3 要不要：默认只露 5 家？
3. R2 里「已出：…，已触发 / 未触发」这半句要不要？它让展开有结论，但要读对账数据，接口多一次读取。

## 5. Owner 裁决

Owner 10-30：「都按你推荐的来，R3 也要」。R1、R2（含「已出：…，已触发 / 未触发」）、R3 全做。
