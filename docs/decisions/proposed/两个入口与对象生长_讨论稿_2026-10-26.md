## 1. 已定的目标（不再讨论）

- 定位（10-10）：你说一句话或贴一段信息，它帮你看清背后的机会和风险，给出有依据的判断和估值；对你关注的公司和产业链，它记着当初的论点，只有判断真的变了才来找你；用得越久，越懂你。
- 立足点（10-20）：股价短期随机、长期贴合估值；每家公司一个估值模型（利润基数 + 因素变动 × 系数 → 三档 → 档位与隐含价），研究建模型、跟踪盯因素、动态标与模型的关系、财报来了就校准。
- 闭环五环（10-12）：研究 → 跟踪 → 发现（动态）→ 讨论（对话）→ 更新（写回变量、取值与论点，重算利润与估值，页首显示判断变化）→ 回到研究。
- 两个入口（10-10、原型 01）：关注为空时一句话加输入框——输入股票即关注、自动研究、推荐所在产业链与同链公司；贴消息即进对话。话题点选作为动态过滤条件。
- 对话结尾推荐（10-08、10-20）：相关追问、开始观察、关注某公司；产业链为用户对象后加「建这条产业链」。
- 对话写回（10-10 §4.3、原型 02、10-20 场景 8）：对话形成的判断可以更新个股或产业链的论点，**自动写入**，变化处悬停提示来源对话，可撤回，并在动态留一条记录；用户确认的看法写回模型或进记忆。10-14：不设待处理或确认收件箱。
- 问助手（10-14）：就是右侧面板里的同一个助手，个股页多带本对象的继续研究、重新研究与撤回。
- 产业链（10-20）：用户对象，初始为空，用户新建或对话推荐后点了才建；骨架由公共结构生成，申万成分只用于生成与推荐；预置链页、关注页「产业链」分段、按申万自动挂链待细化后一并改。
- 顺序（10-20 §9）：估值模型可信 → 行情 → 动态 → 校准 → 跟踪重排 → 跑通后再做产业链页、第一次打开、关于我。
- 跟踪与动态不是入口：对象建起来后，由模型因素、翻转价、校准日期、观察项长出跟踪；由碰到这些的消息、公告、对账卡、档位变化长出动态。

## 2. 实现与已定的偏离（应修，不需重新决定）

| 已定 | 现在的实现 | 偏离 |
|---|---|---|
| 对话判断自动写回论点，可撤回，动态留记录 | 对话只能改变量取值与倍数；整理后生成「个股页更新提议」状态 `awaiting_authorization`，内容是旧研究复制 | 写回范围太窄；出现了已否决的「待确认」；提议内容空转 |
| 问助手 = 同一个助手 | 个股页问助手是 `company_wiki` 角色，旧英文提示词、不能写回、不能推荐开始观察 | 两套助手 |
| 结尾推荐开始观察 | 华友问 4 的观察项因文字带数字被前端整块丢弃 | 推荐通道会断 |
| 产业链用户对象 | 仍是预置链；产业链页无问助手；对话没有读链工具；紫金按申万挂到煤—电—铝 | 已知待改（10-20 定为细化后一并改） |
| 研究写回后页首显示判断变化 | 只在重新研究时出现 | 对话写回后是否同样显示，未验证 |
