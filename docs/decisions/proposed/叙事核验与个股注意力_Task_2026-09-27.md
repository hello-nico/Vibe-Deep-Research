# 叙事核验与个股注意力（讨论记录）

状态：2026-09-27 讨论记录，**尚未形成方案，不授权设计或实施**。本文只记录当前讨论到的问题、方法论和注意力要点，供后续形成方案时引用。已确认的决定只有 §4 估值表达边界，权威见 [Human Checklist](../../../human-checklist.md)「估值表达边界（2026-09-27）」。

## 1. 起因：演示反馈

2026-09-26 演示后，用户（演示对象不懂炒股）反馈产品上手门槛太高：

- **产业研究**（申万 Industry Profile）本来是给模型的“注意力”，用来引导研究时关注什么，不适合直接作为用户页面展示。
- **分不清哪些是用户自己的内容、哪些是系统提供的内容**。现有导航按系统分工切（行业研究 / 产业研究 / 个股研究 / 我的资料 / 我的研究 / 深度对话），而不是按用户要完成的事切。
- 用户判断：底座基本完善，缺的是“剧本”，也就是高价值场景的闭环。讨论中补充：公司研究页（经营 / 财务 / 估值分块陈列）本质仍是数据陈列，门槛来自需要用户自己读懂数据。

## 2. 定位方向（讨论共识，未定稿）

- 面向**个人投资者**，以**基本面分析**为主，**由浅入深**：普通用户也能直接得到结论，进阶用户可以往下挖依据。
- 不做数据终端式产品（参照：萝卜投研的个股页、同类公司对比页，菜单 + 指标 + 图表，由用户自己得出结论）。
- Agent 的意义在于**快速反馈、给出专业判断**：用户带着问题进来，拿着判断走；数据是依据，追问时才出现。参照样例：Alex 对话中“后三步历史上站得住，第一步说过头了”“金银比不是点火器，是计时器”这类有立场的判断。
- **叙事是主导**。

## 3. 方法论：叙事核验链

```
叙事 → 主张 → 拆成因果链 → 分出事实、推断和分析 → 逐条拿证据核实
     → 给出哪里对、哪里过头，以及出现什么情况能证明他错了
```

讨论中出现的两个场景都是这一条链：

| 场景 | 起点 | 核什么 |
|---|---|---|
| 核验别人的观点 | 自媒体截图、雪球帖子（例：雪月霜“加息 → AI 泡沫破 → 降息 → 内需释放，2000–2006 复刻”） | 他的因果链中事实对不对、推断站不站得住 |
| 从一条信息出发核验自己的想法 | 一条快讯（例：财联社“白银突然拉升”）+ 用户自己的判断（金银比与黄金中枢） | 用历史数据和公开文章验证这套规律 |

与现有研究纪律一致：事实、推断与待核验分开；强结论检视反证；给出可验证的裁决条件。

## 4. 已确认：估值表达边界

用户 2026-09-27 确认，详见 Human Checklist：

- ✅ 可以说：估值的历史分位和同业位置；当前价格隐含的增速，并和一致预期、叙事能兑现的程度对比；“价格已经比预期更乐观 / 更悲观”这种相对表述。
- ❌ 不说：买、卖、加仓、减仓、目标价、止损位；“现在是买点”这类措辞。

## 5. 个股注意力的三个点

对大多数人而言，核心是**我当前的标的（个股）**：

1. **大家在看什么**（叙事）：市场围绕这只股票在讲什么故事，为什么涨、为什么跌。
2. **预期是什么**（预期）：市场对它期望有多高，机构一致预期与评级，预期在上调还是下调。
3. **当前估值水平如何**（估值）：历史分位、同业位置、当前价格隐含的增速。用户关心的是“现在买入是否合理”，产品不直接推荐，按 §4 侧面表达。

讨论中提到：专业判断在三者交叉处，即“预期差”——叙事多热、价格已反映多少、兑现可能多大。叙事核验链（§3）是回答第 1 点时保证专业性的方法。

**未采纳**：Claude 提出的“三问判断卡”（固定结构的判断卡片）形式，用户不认同，本轮不设计呈现形式。

| 估值 | `fetch_pe_history` 5 年 PE / PB 日频、`bs_valuation_history`；`percentile_rank`、`forward_pe`、`peg`、`pe_digestion_years` / `pe_digestion_scenarios` | 同业口径未定（申万分类或统计局 41 行业） |

其他缺口：

- 宏观与大宗（两个示例场景均属此类）：目录中只有 `cftc_cot`、`macro_probability`，未见金银价格历史、美国利率与通胀序列。缺数据时不能凭记忆补数。
- 输入形式：用户手里多为截图和链接；我的资料目前支持 PDF / TXT / MD，URL 导入已延期，截图识别未验证。
- 速度：现场发起公司研究约 4–5 分钟，与“快速反馈”存在差距。
