# 月度经营数据可得性（2026-10-20）

## 1. 问题

「量 × 单价 × 毛利率」型公司有没有月度或更高频、免登录可持续的驱动，能否像商品价格一样被盯。对应 [月度经营数据可得性](../../tasks/archived/月度经营数据可得性_Task_2026-10-20.md)。候选来自 [申万候选模型适用性预判](../申万候选模型适用性预判_2026-10-20/README.md) 的部分/不适用组。不接入 Backend、不加关注。

## 2. 方法与数据集

逐项实取公开 URL/接口：来源、是否免登录、频率、最早、最新值、口径、条款。判定：

- **能用**：免登录、机器可读序列，可按发布节奏续取。
- **部分**：免登录但需解析 PDF/网页/图片。
- **不能**：登录、付费或验证码（记缺口，不绕过）。

比亚迪试算：2025-01 至 2026-09 产销快报合计本月销量，乘 2025H2 单车毛利，对照 2026H1「汽车、汽车相关产品及其他产品」毛利。只演示可行性，不调参。F10 主营构成只有半年/年，没有季度分产品。

## 3. 环境

2026-10-20。无模型。东财公告与 F10、中汽协官网、乘联会/面板/制冷剂/批价站点只读 GET。不读凭据、不注册、不付费。内测期公开接口按 Checklist「行情数据授权」（新浪、东财）。

## 4. 结果

逐项见 [results.csv](results.csv)。**能用 0 / 部分 2 / 不能 5**（执行方，待 Claude 裁定）。

| 项 | 判定 | 最新证据 |
| --- | --- | --- |
| 比亚迪产销快报 | 部分 | 东财 `np-anotice-stock` 免登录；2021-01 起月更；正文 JSON 表格需解析。2026-09 合计销量 463,561 辆 |
| 乘联会 | 不能 | `www.cpcaauto.com` HTTP 403，未绕过 |
| 中汽协简析 | 部分 | 2026-08 汽车工业产销简析 2026-09-24 公开，正文是图片，需 OCR；行业总量 |
| 面板报价 | 不能 | WitsView 要 Sign In；生意社验证码 |
| R32 / R134a | 不能 | 氟务无公开价；隆众/卓创要登录 |
| 白酒批价 | 不能 | 无免登录批价序列。茅台仅有季度经营数据（2026Q1 收入拆分，2026-04-25） |
| CXO | 不能 | 药明近 200 条公告无月度产销/经营数据 |

比亚迪试算（销量辆，毛利元）：

| | 2025H1 | 2025H2 | 2026H1 实际 | 2026H1 推算 |
| --- | ---: | ---: | ---: | ---: |
| 合计销量 | 2,145,954 | 2,456,482 | 1,808,511 | 同左 |
| 汽车相关毛利 | 615.65 亿 | 713.18 亿 | 614.78 亿 | 525.06 亿 |
| 单车毛利 | 28,689 | 29,033 | 33,994 | 沿用 29,033 |

销量同比 −15.7%，推算毛利 −14.6%；实际毛利同比 −0.14%。量能月度盯，单价/毛利率不能，方向会把「持平」错成「下滑」。

## 5. 结论与适用边界

没有一项达到商品日线那种「能用」。只有公司自己的产销快报和中汽协图片简析免登录可续取。乘联会、面板、制冷剂、白酒批价、CXO 订单都不是内测期可盯序列。不能推出已该接月度销量进引擎；试算不是预测。防过拟合：不要为制冷剂或面板去接付费资讯。
