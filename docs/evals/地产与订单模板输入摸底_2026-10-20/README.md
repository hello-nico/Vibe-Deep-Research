# 地产与订单模板输入摸底（2026-10-20）

## 1. 问题

realty_nav（保利）与 backlog_pe（中国船舶，航海装备Ⅱ龙头）最少输入能否取到，三档如何锚定同业或理论倍数、现价不恒为中性。对应 [地产与订单模板输入摸底](../../tasks/archived/地产与订单模板输入摸底_Task_2026-10-20.md)。审阅要求沿用同业分位，不用当前倍数 ±20%。不加关注、不调 ensure。

## 2. 方法与数据集

年报 FY2025 巨潮：保利已在 `.local/sw-model-fit/`；船舶新下。8700 只读 packet/coverage/quotes。同业：申万二级成分 `industry_constituents.json`（2026-08-12）× 东财快照 `push2` 的 PE/PB（内测期公开接口）。Profile：`801181.SI`、`801744.SI`。逐项 [results.csv](results.csv)。

## 3. 环境

2026-10-20。两家 coverage 均「未入库」。无模型。

## 4. 结果

**三档**

- 保利：亏损，8700 TTM PE −203，不能用 PE。用 **每股净资产 × 同业 PB 25/50/75 分位**。样本：房地产开发成分权重前 30、东财 PB∈(0, 1.5]（去掉园区/壳高 PB），n=18。p25/p50/p75 = **0.44 / 0.64 / 0.97**。BPS 16.03 元（净资产 1918.89 亿 / 报价股本）。三档价 **7.05 / 10.18 / 15.55**。现价 5.39、东财 PB 0.33 **低于 p25，偏低**。不是恒中性。NAV 年报未披露；合同负债 2463 亿、存货 6682 亿可作已售未结/土储代理。
- 船舶：用 **现价 × (同业 PE 分位 / 自身东财 PE)**，同一快照。样本：航海装备Ⅱ 10 家、PE∈(0,100)，n=5（剔海兰信 496、海防 125、三家亏损）。p25/p50/p75 = **23.62 / 26.92 / 28.23**。自身东财 PE 13.31。三档价 **62.5 / 71.2 / 74.7**。现价 35.22 **低于 p25，偏低**。年报扣非 61.26 亿 / 期末股本 75.26 亿与行情 TTM 对不上（9 月吸收合并中国重工），试算不用年报 EPS 套期末股本。

| 公司 | 关键输入 | 现价位置 |
| --- | --- | --- |
| 保利 | 签约 2530 亿 p9；结算毛利率 12.86% p12；合同负债 2463 亿；有息负债 3412 亿 | 偏低（PB 0.33 vs 同业 0.44–0.97） |

Profile→输入：保利销售韧性/拿地土储/融资成本 → 签约、未来毛利率、有息负债；出险现金流可盯。船舶交付量与均价、在手订单、重组口径 → 年报已有；第二曲线（海兰信叙事）不进本模板。

## 5. 结论与适用边界

年报够当年结算/订单/毛利率/净资产；**数据包全 gap**。同业分位来自东财横截面，不是五年历史、也不是 8700 的 PE（保利符号相反）。样本小（船舶有效 5 家）、地产 PB 仍杂。试算非产品估值。不能推出已可实现两模板。防过拟合：不要为 NAV 去接付费评估。
