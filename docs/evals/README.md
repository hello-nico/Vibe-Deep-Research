# evals

技术验证与 Benchmark 的提炼记录。原始返回、截图、日志留在被忽略的 `.local/<主题>/`；这里只放能长期复用、可追溯的部分，项目内外都可引用。

## 放什么

每次验证一个目录 `<主题>_<YYYY-MM-DD>/`：

- `README.md`：按下方六节写，≤ 150 行。
- `results.csv`（可选）：逐题或逐项的指标，小于 200 KB。
- 重跑脚本（可选）：不含密钥、不读 `.env` 原文。

## README 六节

1. **问题**：这次验证要回答什么，对应哪个 Task。
2. **方法与数据集**：题目或网址清单（这是可复用的 Benchmark 本体），每题跑几次、怎样计分。
3. **环境**：日期、模型与版本、依赖版本、供应商与预算限制。
4. **结果**：指标表；明确哪些是脚本客观指标、哪些是 Claude 判定。
5. **结论与适用边界**：能推出什么、不能推出什么，数据缺口。
6. **重跑**：命令、原始数据路径 `.local/...` 与其产出时间。

## 规则

- 结论由 Claude 判定后写入；执行方只提交客观指标与原始路径。
- 公开仓库：只放指标、标题、网址与我们的结论，不放搜索正文或第三方全文；不放任何密钥、令牌、个人路径以外的私人信息。
- 记录写定后不改结论；新一轮验证另起目录，并在新记录里链接旧记录说明差异。
