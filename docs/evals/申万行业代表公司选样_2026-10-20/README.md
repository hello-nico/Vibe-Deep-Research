# 申万行业代表公司选样（2026-10-20）

## 1. 问题

只在铝、电上调规则会过拟合。要从用户整理的申万资料为每个一级行业选一家代表，组成跨行业验证样本。对应 [申万行业代表公司选样](../../tasks/archived/申万行业代表公司选样_Task_2026-10-20.md)。模板见 [利润模板目录](../../decisions/proposed/利润模板目录_2026-10-12.md)。不加关注。

## 2. 方法与数据集

申万二级 131 条来自 Stock `data/industry_constituents.json`（taxonomy SW2021，as_of 2026-08-12），`parent` 为一级（31 个）。Industry Profile `workspace/research/industry-profiles/catalog.json` 只作变量名与研报公司名单对照，不绑公司。已关注 17 家对照 [覆盖表](../关注名单行业覆盖_2026-10-20/results.csv)。价格能否取得只引用 `external_catalog.py` 与既有摸底，不新取数、不开个股页。

选样：每个一级一家；该级已有关注公司则沿用（有色取紫金、公用事业取长江电力、建材取海螺、电力设备取宁德）；否则取该级主业更单一的龙头（指数权重参考，但不用子行业内虚高权重，如林业平潭、体育中体、焦炭美锦）。港股小米不进 A 股样本。不跑模型。

## 3. 环境

2026-10-20。只读本地冻结资料。不改代码。

## 4. 结果

31 个一级均有一行，见 [results.csv](results.csv)。沿用关注 9 家，新建议 22 家。模板：单位经济型 11、收入利润率型 16、规模费率型 4（银行、保险、电信、移动已算费率）。主驱动：目录已有 7、公开可取（公告/弱相关期货）3、只能靠财报 21。

优先验证 10 家（最可能暴露问题，不是最容易成功）：中国平安（保险=费率+投资重估）、贵州茅台（无商品价）、药明康德（CXO 成长）、保利发展（结算）、神州数码（计算机样本却是分销）、中国移动（ARPU）、农业银行（已知息差缺口）、比亚迪（车+电池多段）、京东方A（面板周期无目录价）、东阳光（综合拆段）。

未进优先：紫金/宁德/长江电力/万华/海螺（已在铝电化材上跑过）；牧原/太阳纸业/三一（模板目录已验证）；神华（动力煤缺口与电解铝同类）。

## 5. 结论与适用边界

本表是选样建议，**不是已加关注、不是已研究**。计算机与传媒因 S1 沿用神州数码、新华文轩，不能代表软件与游戏；若要测这两类需用户另批。权重是 2026-08-12 申万二级指数权重，不是成交额或基本面龙头的独立证明。不能推出 31 家都能用现有估值模型。交 Claude 判定后再交用户确认加哪些。
