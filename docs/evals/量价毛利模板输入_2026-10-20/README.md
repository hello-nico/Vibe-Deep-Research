# 量价毛利模板输入（2026-10-20）

## 1. 问题

volume_pe（量 × 价 × 毛利率 → 市盈率）最少输入能否从年报、数据包与公开月度取到，三档怎么造。对应 [量价毛利模板输入摸底](../../tasks/active/量价毛利模板输入摸底_Task_2026-10-20.md)。总览第 4 节。不加关注、不调 ensure。

## 2. 方法与数据集

四家：茅台 白酒Ⅱ、比亚迪 乘用车、美的 白电、药明 医疗服务。年报 FY2025 巨潮公开（茅台/比亚迪/药明已在 `.local/sw-model-fit/raw/`，美的新下）。8700 只读 `data-packet?as_of=2026-10-20`、`coverage`、`quotes`。Profile：`profiles/801125|095|111|156.SI.json`。月度对照 [月度经营数据可得性](../月度经营数据可得性_2026-10-20/README.md)。写法对照 [银行与保险模板输入](../银行与保险模板输入_2026-10-20/README.md)。逐项 [results.csv](results.csv)。

## 3. 环境

2026-10-20。Backend 127.0.0.1:8700。比亚迪/药明 coverage「未入库可读报告正文」，财务字段全 gap。无模型。

## 4. 结果

**三档建议选 B**（现利润 × 三档市盈率）。理由：总览要区间不预测；A 把量与毛利率外推等于再做明年利润。B 的历史/同业 PE 分位数据包已拒绝倒推（与农行五年 PB 同类缺口）。本轮试算降级：**FY2025 扣非 EPS × 当前 TTM PE 的 0.8 / 1.0 / 1.2**（假设带，现价被构造为中性），并附三年已实现归母相对 FY2025 的价宽。

Profile 能变成输入的：白酒「销量×吨价、直销/i 茅台」→ 量价结构；乘用车「补能/销量」→ 月度销量；白电「内销外销、高端化毛利率」→ 分部毛利率，台数仍缺；CXO「在手订单、后期项目」→ 订单与毛利率。批价、以旧换新、生物安全法案不是本模板数字槽。

## 5. 结论与适用边界

年报够当年量（茅台/比亚迪）、毛利率、三年利润；**不够 PE 分位、美的台数、药明月度**。比亚迪月度销量可盯，单车毛利仍要等季报。试算是可行性演示，假设已标明，不是产品估值。不能推出已可实现 volume_pe。防过拟合：不要为白酒批价或面板式报价去接付费资讯。
