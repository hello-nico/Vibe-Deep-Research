# 铜金与锂电成本数据可得性（2026-10-20）

## 1. 问题

铜金（紫金）与锂电钴镍（宁德、华友）做吨利润 / 单位利润，成本与数量能否从现有 provider 或公开免登录源取得。对应 [铜金与锂电成本数据可得性](../../tasks/active/铜金与锂电成本数据可得性_Task_2026-10-20.md)。承接 [关注名单行业覆盖](../关注名单行业覆盖_2026-10-20/README.md)。与 pi2 电解铝/火电同一套「能用 / 部分 / 不能」计数，供用户在电力与铜金之间选第二条样板链。

## 2. 方法与数据集

匿名 HTTP，不登录、不付费、不读 `.env`、不开个股页。价格对照实取新浪日线（与 Stock `external_catalog.py` 同源：CU0/AU0/NI0/LC0）。成本项探测：上期所日周数据页与库存周报文件、LME/CME、USGS MCS 2025 PDF、WGC Goldhub、ICSG、SMM 历史价、Mysteel、动力电池联盟站、中汽协、工信部汽车页、巨潮公告列表与短 PDF。登录墙、403、验证码按 Stop Conditions 记「不能」。计分：能用 = 免登录可持续序列；部分 = 低频或需解析 PDF；不能 = 仅付费或匿名不可达。不跑模型。

## 3. 环境

2026-10-20。Python 3 标准库 + 本机 `pdftotext` 读已下 PDF。不改产品代码。

## 4. 结果

脚本客观计数（成本与数量，不含价格对照）：

| 链 | 能用 | 部分 | 不能 | 合计 |
| --- | ---: | ---: | ---: | ---: |
| 铜金 | 0 | 2 | 5 | 7 |
| 锂电钴镍 | 0 | 2 | 6 | 8 |
| 合计 | 0 | 4 | 11 | 15 |

价格对照另计 4 条能用：沪铜 2005-01-04–2026-10-19（5298 日）；沪金 2008-01-09–2026-10-19；沪镍 2015-03-27–2026-10-19；碳酸锂期货 2023-07-21–2026-10-19。期货不是现货、精矿或电芯价。

部分 4 条：上期所库存周报页 200、dat 文件 404，且为交割库存；紫金 2023 产量公告与 2026H1 摘要可下（矿产铜 53.4 万吨、矿产金 47 吨，含联营权益、初步核算）；华友、宁德仅年报/半年报列表 200，摘要无产销表，产量搜索 0 条。

不能：TC/RC、C1、AISC、LME/COMEX 库存（403）、电池级锂现货、钴盐、硫酸镍、正极、电芯均价、联盟装车量（cbea 403）。SMM 历史页写「请登录后查询」。USGS 只有产量储量。WGC/ICSG 有登录入口。逐项见 [results.csv](results.csv)。

接上能用项后：价格滑块可接四条期货；**吨成本与社会库存仍全缺**。铜金还缺 TC/RC、C1、AISC、社会库存，产量只到年/半年 PDF。锂电还缺全部现货与 ASP、装车量，产销只到年报 PDF。两条链的吨利润公式都接不上。

## 5. 结论与适用边界

执行方计数：成本数量能用 0。不能推出已可做铜金或锂电链模型。与电解铝 10-14「社会库存 / 加工费付费源必需」同类。电力对比留给 Claude 合并 pi2。LC/NI 期货不能代替电池级现货与硫酸镍。未评估条款是否允许产品内测转载 SMM。
