# 三季报校准回测

## 1. 问题

以最近一期已披露报告为输入，现有估值引擎按 Q3 各因素均价推算的单季利润，能否与实际财报对上，以及差额能否归因。
本轮回放神火、预测云铝，并冻结紫金、宁德、华友的披露前条件推算。最终是否达到产品验收标准，由 Claude 判定。

## 2. 方法与数据集

读取 Stock 主目录已合入的 `services/sensitivity.py::prepare` 与 `analysis/sensitivity.py::sensitivity`，没有修改或另写利润公式。
为避免神火 Q3 已披露的利润混入输入，探针用同来源 provider 的 FY2025、2026H1、2025H1 累计值，通过现有 `ttm_profit` 重建 TTM:2026H1；
最新集团净利润也回到 H1，所有 Q3 财务字段在 prepare 前剔除。分部收入、成本、税率假设、成本占比沿用已有模型，不按实际利润调参。

引擎输出仍是年化利润，探针统一除以四：`Q3推算 = TTM利润/4 + Σ 年化系数/4 × (Q3均价 − 同TTM区间锚价)`。
这额外假设季度均匀、销量与产品结构不变，无季节性校准，不能据此声称产品已有单季校准接口。股本与股票现价不进入利润推算；原函数反解元数据沿用已有中性倍数，不影响本表利润。

Q3 日线区间为 2026-07-01 至 09-30，各序列均有 65 个收盘值，取交易日算术平均，不用 10 月行情。锚期为 2025-07-01 至 2026-06-30。
煤价遵循已合入的 E2：H1 财报煤收入除销量得到不含税锚价，再按焦煤主连相对同 TTM 均价变化，弹性一、基差和煤种结构不变；是代理，不是公司 Q3 实际结算价。

## 5. 结论与边界

本轮证明不改引擎可以作有明确假设的单季线性回放；尚不能证明“财报到达即可靠归因”。神火残差 4.51 亿元没有证据可以拆净，单季均匀化与利润基数选择影响很大。
此外，单位成本、商品主连与实际售价的基差、少数股东比例、模型外业务、税率和费用变化都可能影响残差，只能列候选解释，不能分配因果金额。

建议先对盈利且利润不接近零的公司采用待确认分级：绝对相对误差不超过 10% 才进入“可接受候选”；10%–20% 只作人工差异复核；超过 20% 暂不据此自动判定模型兑现。
这是建议，不是已验证门槛，也不是产品规则。依据：神火实际利润的 10% 约 2.71 亿元，约等于本模型铝价 1,158 元/吨的单季利润影响；16.69% 的偏差已经明显影响解释。
利润近零、亏损、结构变化或大量因素缺失时，应报告金额差和失效原因，不套这个百分比门槛。
只有一个已披露样本，不能用它估计 90%/95% 置信区间；至少应等其他预登记对象披露、积累独立季度样本，并与 H1/2 等朴素基线比较后再定正式验收标准。

未触发 Task §7：未改引擎，实际 Q3 数字有一级原件及 provider 同源累计相减核对。误差偏大不是本 Task 的停止条件，也没有据此调常数。
Q1–Q2 已给回放与残差缺口；Q3 已有三家公司登记，但宁德、华友只能作条件推算。不能把登记数量等同于三份完整因素预测。
