# 申万候选模型适用性预判（2026-10-20）

## 1. 问题

加关注前，用公开年报判断 7 家候选的利润由什么驱动，现有「利润基数 + 价格 × 系数 + 倍数」能说清多少。对应 [申万候选模型适用性预判](../../tasks/active/申万候选模型适用性预判_Task_2026-10-20.md)。样本来自 [申万行业代表公司选样](../申万行业代表公司选样_2026-10-20/README.md)。模板见 [利润模板目录](../../decisions/proposed/利润模板目录_2026-10-12.md)。不加关注、不跑模型。

## 2. 方法与数据集

7 家 FY2025 年报，巨潮公开 PDF（免登录）。只读「管理层讨论与分析」（平安为「经营情况讨论及分析」），每家摘 2–4 条利润驱动原话与印刷页码，标可观测频率。判定标准（相对现有引擎，不是模板目录能否想象）：

- **能用**：主驱动有目录日度价格。
- **部分**：只能用财报变量，季度更新。
- **不适用**：利润生成机制不是「基数 + 价格 × 系数」（保险、地产结算等）。

不适用的替代表达（只建议，不设计）：平安看内含价值、新业务价值、综合成本率与综合投资收益率，不要用国债利率×系数代替负债与投资；保利看已售未结（报表合同负债，MD&A 无此原词）与结算节奏、结算毛利率，签约金额不解释当期利润。

## 5. 结论与适用边界

现有引擎对这 7 家**没有一家**主驱动落在目录日度价格上。京东方是周期商品、东阳光制冷剂有现货，但目录都没有；比亚迪的 LC 只覆盖电池外售，垂直整合后不能当整车主变量。价格×系数只解释有目录价的那一份，与 [估值引擎误差来源诊断](../估值引擎误差来源诊断_2026-10-20/README.md) 一致。

不能推出：已可加关注；已该扩目录价；收入利润率模板已实现。预判不是产品裁定。防过拟合：不要为这 5 家各接一个专用价格源。
