## 5. 结论与适用边界

农行最少输入里 ROE、现价 PB、净息差、股息、国债**够做 Gordon 演示**；五年 PB/ROE 分位、信贷成本、不良、拨备**不够**。平安最少输入 **年报够当年 P/EV 一点**，不够历史分位或把 NBV 增速映射到倍数。两边试算都是可行性演示，假设已标明，不是产品估值、不是投资建议。不能推出已可实现 bank_pb / insurance_pev。防过拟合：不要为 EV 历史去接付费终端。
