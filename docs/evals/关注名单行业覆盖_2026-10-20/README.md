已研究页的明显问题（只读接口，非视觉）：内部用语「归母 / 关键变量 / 警戒线 / 基数」普遍出现；华能蒙电、万华、农行无敏感性；神火 AL/AO 引用为 assumption，煤价非目录；宁德类型为 generic；云铝产量在回测中用桥接估计。

推荐电解铝之后先做的两条：**铜金**、**锂电与钴镍**。理由：都能复用「目录日线 + 单位经济型」，不依赖尚未完成的成本数据 Task；紫金驱动已 verified，华友/宁德已有 NI/LC。电力覆盖家数最多，但电价与动力煤与电解铝同一类缺口，不宜作为下一条样板。

## 5. 结论与适用边界

「先做铜金与锂电钴镍」是执行方按数据可得度排出的候选，**不是已裁定的产品路线**。不能推出：未研究五家的类型已确认；成本项今日已核实（成本 Task 未做）；链模型已可实施。港股小米只计入名单，不进入 A 股研究接口。10-14 摸底只覆盖铝与火电，铜金/锂电的库存与成本未摸底。
