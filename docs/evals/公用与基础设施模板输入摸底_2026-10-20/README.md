# 公用与基础设施模板输入（2026-10-20）

infra_yield（电量或用户 × 价格 → 收益率或 EV/EBITDA）最少输入从哪取、三档怎么造才不会把现价做成中性。对应 [公用与基础设施模板输入摸底](../../tasks/active/公用与基础设施模板输入摸底_Task_2026-10-20.md)。代表：长江电力、华能国际、中国移动。不加关注、不调 ensure。

## 2. 方法与数据集

8700 只读 `data-packet?as_of=2026-10-20`、`page-research`（两家电力）、`/market/quotes`。国债：已登记 `eastmoney.treasury_yield` / EMM00166466。Profile：`801161.SI` 电力、`801223.SI` 通信服务。对照 [银行与保险](../银行与保险模板输入_2026-10-20/README.md) 与量价毛利审阅：三档须锚定理论或同业倍数，不用「当前 PE × 0.8/1.0/1.2」。逐项 [results.csv](results.csv)。

## 3. 环境

2026-10-20。Backend 127.0.0.1:8700。移动已关注、无 page-research。无模型。

## 4. 结果

同业 PE/PB 分位与五年历史分位三家都是数据包 lens **gap**（不足三家已核对 801161/801223 成分；不能倒推）。本轮三档用 **股息贴现 P = DPS / (r − g)**：DPS 取年报方案，r = 十年国债 + ERP，g 与 ERP 为标明假设。现价只用来定位，不进入公式。

假设：g = 2%；ERP 6% / 5% / 4% → r = 7.65% / 6.65% / 5.65%（国债 1.6497%，2026-10-19）。悲观 = 高折现。

**长江电力**：PE 20.07、股息率 3.41%、TTM 利润 362 亿。发电量与电价 readings 无。page-research 类型 leveraged_cyclical_utility，档「合理」（商品引擎口径），与本股息公式「高于乐观」**不互相覆盖**。

**华能国际**：PE 10.01、股息率 5.28%、DPS 0.40。上网电价与煤价无 readings；研究把二者当跟踪项。普通股权益 645 亿 vs 净资产 1380 亿（永续债）。

**中国移动**：PE 16.75、TTM 利润 1318 亿、FY2025 capex 1570 亿。DPS/股息率/股本 gap。未 ensure。

Profile 能变成输入：电力「发电量、上网电价、煤价/折旧、分红/股息率」——后两项数据包有，前三项无。通信「派息率、资本开支、第二曲线收入」——capex 有，派息率与 ARPU/用户无；核心问题六条偏分红与算力，没有 ARPU 槽。

## 5. 结论与适用边界

水电/火电 **DPS + 国债够做 Gordon 演示**；发电量、电价、煤价、同业 EV/EBITDA **不够**。移动缺股息输入，不能试算。现价不参与造档，故不恒为中性。试算是可行性演示，ERP/g 非观测，不是产品估值。不能推出已可实现 infra_yield。电力现用商品周期引擎是另一口径。防过拟合：不要为利用小时或 ARPU 去接付费资讯。
