# 申万同业横截面可得性（2026-10-20）

## 1. 问题

东财按申万二级取成分与 PE（TTM）、PB 横截面能覆盖多少行业、V1 剔除后样本够不够。对应 [申万同业横截面可得性](../../tasks/active/申万同业横截面可得性_Task_2026-10-20.md)。V1：剔除非正、PE>100、PB>15，有效 ≥5 才给分位。

## 2. 方法与数据集

成分：8700 冻结 `GET /api/v1/industries?taxonomy=SW2021` 与 `/{code}/constituents`（131 个，as_of 2026-08-12，来源 akshare/swsindex）。倍数：腾讯 `qt.gtimg.cn` 字段 39 PE TTM、46 PB（产品报价同源）；东财 push2delay 全 A `clist` 本轮 HTTP 502，重试仍 502，未用于倍数。板块对照：同接口 `fs=m:90+t:2` 亦 502；方法按 `industries.py` `build_sw_eastmoney_crosswalk`（名称去 ⅠⅡ + 银行四档手工 BK1283）。不加关注。明细 [results.csv](results.csv)。

## 3. 环境

2026-10-20。Backend 127.0.0.1:8700。腾讯 HTTP 批 20 只、失败重试。无模型、不读凭据。

## 5. 结论与适用边界

冻结申万成分 + 腾讯快照：**PE 112 / PB 123 个二级够 V1**。东财 clist 本轮 502，不能当作东财板块成分已通。稀疏行业（<5）应返回「同业样本不足」。不能推出已实现同业 provider。防过拟合：不要把东财 BK 当成申万二级。
