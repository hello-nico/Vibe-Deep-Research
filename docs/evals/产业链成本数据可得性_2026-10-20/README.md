## 2. 方法与数据集

C1 共 19 项。只读：Stock 外部目录（源码核对，无动力煤/阳极/电价序列）；新浪日线 ZC0/JM0/AL0/AO0（与 provider 同源）；Backend GET `/wiki/companies/{000933,000807}.SZ/data-packet?as_of=2026-10-20`；巨潮公告；统计局流通领域、能源局用电量稿、上期所日周数据、瑞达公开 PDF、CCTD/生意社/中电联/IAI/交易中心。不登录、不注册、不付费、不打开个股页、不 POST ensure。
判定：能用=免登录且可持续序列；部分=低频稿件或需解析 PDF/HTML；不能=仅付费终端或现价序列已断。

## 5. 结论与适用边界

执行方客观结论（**待 Claude 判定链模型可否升级为利润引擎**）：接上本轮「部分」项后，仍缺：公司逐期实付电价与自备/网电用量；氧化铝自用量与单位成本；预焙阳极价与公司阳极单耗；神火 2026H1 原铝产销吨；煤单位成本（非售价）；行业吨完全成本/社会库存/开工率的免登录序列；电厂日耗与库存；分省工业电价时间序列。没有一项达到「能用」的免登录可持续成本序列。吨利润/度电利润不能靠现有 provider 自动算。不能推出已接入产品，也不能用付费终端数字。
