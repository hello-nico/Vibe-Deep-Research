# 预期对比真实数据抽查（2026-10-20）

## 1. 问题

已研究公司的真实回包，经产品 `expectations()` 后，估值节三行与分歧句会不会让人看糊涂或看错。对应 [预期对比真实数据抽查](../../tasks/active/预期对比真实数据抽查_Task_2026-10-20.md)。

## 2. 方法与数据集

11 家 `page-research` 非空（与个股页预期对比 §2 同一批）。8700 只读 packet / quotes / research-results。用桌面 `expectations`、`scenarioTable`、`parseSensitivity`、`verdictLine`。不打开未研究公司个股页、不触发研究。逐家 [results.csv](results.csv)。

## 3. 环境

2026-10-20。Backend 127.0.0.1:8700。无模型。

## 4. 结果

| 公司 | 三行要点 | 糊涂/看错 |
| --- | --- | --- |
| 神火 | 机构 4.12（4 家）；中性价 28.53；沪铝 22,117 vs 22,970 | 机构 FY2026E、模型 TTM:2026Q3；查看数据写出 TTM |
| 云铝 | 机构 4.45；**暂无三档价**；沪铝几乎现价 | 悲观档亏损 `price` 空，`scenarioTable` 要求三行都有价，整表丢掉 |
| 长江电力 | 三方每股收益差不到 5% | 期间不同；隐含「发电量比对比期低约 0.5%」 |
| 华能蒙电 | 机构 0.34（1 家，样本少） | 行「暂无市场在赌的价格」，分歧句仍比「股价隐含」且写「三方」 |
| 紫金 | 中性价 35.92 偏低；行暂无隐含 | 旧凭据 implied value 空；分歧句仍用现价÷倍数当「股价隐含」 |
| 宁德 | 机构 20.84（8 家）；中性价 282.51 | 期间不同（FY vs TTM） |
| 华友 | 机构 4.70 比隐含 2.93 **高 60.3%** | 期间不同叠加，容易当成同年预期差 |
| 万华 | 中性价 69.60；行暂无隐含 | 无敏感性凭据；档内悲观 TTM、中性 FY2026E |
| 海螺 | 机构 1.13（2 家，样本少） | 期间不同 |
| 农行 | 机构 0.82（2 家）；中性价 6.35 偏高 | 同行暂无 vs 句有「股价隐含」 |
| 华能国际 | 机构 0.70（2 家） | 期间不同；电价「低约 0.3%」 |

11/11 有机构 FY2026E。4 家样本少（1–2 家）。7 家机构年与模型利润期间不同。4 家行写暂无隐含、分歧句仍出现股价隐含每股收益。无总利润口径折股本案。无「归母/警戒线」。查看数据里的 `TTM:2026Q3` 是内部期间写法。

## 5. 结论与适用边界

会看糊涂的主要是：**期间不同却比每股收益**、**云铝整表消失**、**隐含行与分歧句不一致**、**华友 60% 差**。不能推出页面已可验收。抽查不是视觉验收。
