# 公用模板三档锚定验证（2026-10-20）

## 1. 问题

infra_yield 能否用公司自身的股息率分位造三档，替代「国债 + ERP 扫描」的 Gordon。对应 [公用模板三档锚定验证](../../tasks/active/公用模板三档锚定验证_Task_2026-10-20.md)。上游 Gordon：长江 17.70/21.51/27.40，华能 7.08/8.60/10.96。

## 2. 方法与数据集

分红：东财 F10 `BonusFinancing/PageAjax` 实施方案「10派X元」及派现日（长江、华能、移动）。日线：东财 `push2his` kline `klt=101` **fqt=0 不复权**收盘（与现金 DPS 同口径）；长江/华能自 2021-01，移动自 2022-01 上市。逐日近 12 月 DPS = 派现日落在 (日−365, 日] 的每股现金合计；股息率 = 该 DPS ÷ 当日收盘。分位 P25/P50/P75。三档价 = 最新 TTM DPS ÷ 分位（高股息率→悲观价）。不加关注、不 ensure。逐项 [results.csv](results.csv)。

## 3. 环境

2026-10-20。东财公开 GET。8700 只读 coverage 核对移动年报是否已在库。无模型。

## 4. 结果

与 Gordon 并排：长江 Gordon 整段低于自身分位（17.7–27.4 vs 28.0–30.4），因 ERP 4–6% 远高于已实现股息率约 3.4%，现价在 Gordon 上「高于乐观」、在分位上「中性」。华能现价 7.48 低于两条口径的悲观价；分位更低是因为 2024–2026 DPS 从 0.20 升到 0.40，现收益率高于历史分位。移动 Gordon 上游未算；F10 可补 DPS。

**主口径：自身近 12 月股息率分位。** 理由：分子分母都来自该公司已派现与不复权收盘，现价不参与造档。Gordon 作利率旁证，不当前档；ERP 非观测。华能序列不足三年，分位只能当弱证据。

**移动 DPS gap：** coverage 已有 FY2025 年报与 2026H1，不是没入库。数据包 `dividend_per_share`/`shares` 为 gap：提取只认表行「每10股派息数」，移动年报口径可能不同；`share_capital` 4684 亿与行情约 217 亿股冲突，股本失败则股息率不能算。东财 10派（2026-09-30 派 2.51、2026-06-05 派 2.20）可作 A 股现金 DPS，未 ensure、未改提取。

## 5. 结论与适用边界

自身股息率分位能给三家可比较的三档，且现价不恒为中性。不能推出已实现 infra_yield。华能分红上台阶后分位滞后。日线不复权；东财 F10 不是年报原句。防过拟合：不要为复权或港股 DPS 去接付费终端。
