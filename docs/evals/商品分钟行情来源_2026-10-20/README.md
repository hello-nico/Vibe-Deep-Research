# 商品5分钟行情与美债来源验证（2026-10-20）

## 1. 问题与裁决

依据[Task及补充裁决](../../tasks/archived/商品分钟行情来源验证_Task_2026-10-20.md)：内测范围使用新浪为主、东财为备；最新口径改为每5分钟一次，日盘与21:00起夜盘各连续至少60分钟。**仅限内测，正式发布前换授权源**。用户内测风险裁决不代表供应商已授予许可。

## 2. 方法与环境

本机Python3匿名请求，无账户、Cookie、密钥、付费接口。一个进程、互斥锁、串行执行新浪批量五品种再东财批量五品种，每轮相距300秒，无即时重试。401/403/429后不再请求该源，不换代理、不绕过限制；其余失败留原始证据。已采的早期单点初探保留，未形成每分钟连续序列，不再追加每分钟采样。

当前状态：**complete**。计划与实际窗口见本地schedule.json；日盘完成=True，夜盘完成=True。上午剩余交易时间不足60分钟，先留上午5分钟样本，下午13:30–14:35另取14点完整窗口，不拼接午休冒充连续。夜盘21:00–22:05取14点；计划覆盖65分钟，避免边界请求耗时波动使精确接收跨度不足60分钟。碳酸锂无夜盘，保存返回值但不纳入夜盘实时成功率。

每次记录UTC精确发出/接收时刻、HTTP状态、有限非秘密响应头、原始字节与SHA256；延迟=收到时刻−来源时间，传输耗时另列，不是独立测得的交易所到源延迟。未校验本机NTP误差。新浪保留raw_date/raw_clock；夜盘若raw_date为未来交易日，将21点后时间归到接收日历日并标记转换规则，不隐去原字段。

## 4. 字段、证据与边界

全部原始证据在.local/minute-quotes-probe/，不放入公开eval：five-minute.jsonl、raw/、five-minute-summary.json、schedule.json。新浪代码AL0/AO0/CU0/AU0/LC0，响应0基字段1时间、8最新价、17日期；东财已匿名验证113.alm、113.aom、113.cum、113.aum、225.lcm，字段f2最新价、f12/f13身份、f14名称、f124 Unix秒。初始化补码响应eastmoney-five-mapping.bin及精确请求时间保留。

新浪AL0页面与东财主连alm曾指向不同合约；本轮确认各源自己的主连标识，不等于确认两源同一到期合约。主备切换前必须核实实际合约与口径，不能把两源价差直接解释为行情误差。f124是源标注的更新时间，尚未独立证明为交易所逐笔成交时刻；本报告数据龄为该源时间到接收时间之差，不是交易所原始成交延迟。5分钟采样只证明该轮询档的可用性，不证明源的逐秒刷新率或云端可访问性。

[新浪协议§10.1](https://finance.sina.com.cn/roll/2021-05-12/doc-ikmxzfmm2033220.shtml)、[东财协议§6.2](https://about.eastmoney.com/home/protocol)及[法律声明](https://about.eastmoney.com/home/disclaimer)的限制仍客观存在，按用户补充裁决仅在受邀内测范围继续；数值限流上限与SLA未核实，不做压力测试。[上期所时间表](https://www.shfe.cn/specialtopic/investor/trade/)和[广期所碳酸锂合约](https://www.gfex.com.cn/gfex/sytslqhhy/202307/9ad927b8ec4c458594e172fd1ada2a9b.shtml)为时段依据。

美国10年期收益率独立初探：[财政部官方日度XML](https://home.treasury.gov/policy-issues/financing-the-government/interest-rate-statistics/interest-rate-xml-files)匿名HTTP200，2026-10-19 BC_10YEAR=5.15%，是日度CMT，非盘中逐笔收益率。传输约1.815秒不等于行情延迟；XML日期/updated不能当成交时刻。FRED CSV初探超时，未列为已验证备用；原始treasury-request.json及XML保留。

## 5. 推荐与分档降级建议

内测候选主源新浪、备用东财；是否通过60分钟窗口须以完成标记和成功率判定。**仅限内测，正式发布前换授权源**。两源主连合同身份尚需对齐。美债日度推荐财政部XML，无已验证独立备用；盘中美债未验证。

建议（待Claude决定，不是本轮已实现产品行为）：每个来源×品种独立管理刷新档与最后成功时间；5分钟档一次超时/缺值/解析错/失鲜进入10分钟，10分钟档再次失败进30分钟，30分钟档再次失败进1小时。401/403停止自动重试并提示权限，429遵守Retry-After且至少退到下一低频档，不切源规避限流；失鲜超5分钟保留缺口，若两源交易时段普遍超5分钟按§7停测。非交易时段不累计失败、不升级请求频率，保留最近价并标时间。连续3次在当前档成功且无访问限制后，才建议逐级恢复一档；切主备前校验合约，不能混算。

仅5分钟档会被实际采样，10/30/60分钟档触发阈值是建议、未实测。小样本成功率不保证长期稳定或发布许可。若出现失败，以逐次原因决定网络、解析、身份、失鲜或访问限制归属，不靠加频重试掩盖。

## 6. 一条命令与门禁

Vibe主目录运行：`python3 .local/minute-quotes-probe/collect.py --date 2026-10-20`。会立即按下一5分钟边界开始上午样本，安排下午完整日盘与21:00夜盘；同一进程串行、持锁防并发，已完成采样点不重发。后台PID与进度在schedule.json，退出状态在collector.log；不得同时另开重复采样器。

重算既有证据（不联网）：`python3 .local/minute-quotes-probe/collect.py --date 2026-10-20 --report-only`。官方美债重验：`python3 .local/minute-quotes-probe/probe.py treasury`；旧probe.py sample保留历史停止提示，不作为新采样入口。

采样进程在日盘完成和夜盘完成后自动用实际结果生成本README、回填Task§9固定六字段，并运行`node scripts/verify-docs.mjs`，日志留指定.local目录。日盘先交接并等待夜盘，不把计划当完成。禁止产品代码改动、提交/push、读取.env/凭据或访问5930；其它并行目录不动。
