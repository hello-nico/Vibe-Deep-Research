共用 `chain_formulas.py` 写三环节完整方程：

```text
铝吨毛利 = (铝价 − 1.93×氧化铝价)/1.13 − 13500×电价 − 阳极人工等
氧化铝吨毛利 = 氧化铝价/1.13 − 矿石耗×矿价 − 碱耗×碱价 − 能源等
煤吨毛利 = 煤价/1.13 − 开采 − 加工 − 运输
公司归母 = (各环节吨毛利×相应产量 + 其他)×(1−税率)×归母比例
```

1.93 和13,500来自[瑞达原始研究报告](https://www.rdqh.com/upload/files/base/x/8/21933.pdf) PDF p10，是行业参考单耗，非公司实耗；13%增值税为商品统一口径假设。神火新疆80万吨/年配4×350MW自备电，云南90万吨/年为网电；云铝绿色电力结构不能当自备电比例。两家实付电价、自用量、氧化铝独立成本等未取得，**完整方程返回缺口，不填零**；矿石/碱耗无足够回绑来源，亦不编常数。

计算误差前先写定 `method.md`：两模型共用固定2024H1锚，基数均为 `(FY2023+2024H1−2023H1)归母/2`，神火27.2510亿、云铝24.7983亿。税率、归母比例取2024H1合并利润表，固定税后归母系数分别0.684611、0.709502。不是拿目标期实际利润反校常数，也不是每期滚动 TTM。2024H1单列为锚内观察，从后续误差统计剔除。

模板复用真实保存请求的成本占比（神火AO40%；云铝AO35%、加工铜3%）与段名，调用现行 `unit_economics` 纯函数重建锚期系数；神火公司自有煤价三档默认0，云铝保留沪铜项。它是**同基数、同函数的历史结构重建**，不是当时研究版本的逐期预测记录；后来的驱动选择仍有回看偏差。

另算“固定成本篮子增量链”：锚期单位毛利由原件计算，以实际产量放大；仅铝/AO价格变化，电力、阳极、上游成本及煤单位毛利固定；其他项由共同TTM锚与锚期毛利之差固定。云铝AO价格补偿按自产量全部自用的上限，独立上游锚毛利吸收进铝成本篮子。**这些是可见的条件与不可识别项，不是新取得的公司事实**；完整链输出始终为null。本变体用于暴露结构误差，不满足V1/V2完整链成本辨识要求。

以上为第二轮冻结方法。R6—R8的计算前方法另存 `r6-r8-method.md`，没有改动旧单耗、税率、归母比、TTM锚、铝/AO/CU系数或成本份额。煤价从下列原件的煤炭产品收入与煤炭销量直接相除；H2先将收入、销量分别全年减H1，再相除。它是不含增值税的**全煤种混合实际售价**，不是纯无烟煤报价；不再除1.13。各半年均有实际输入，不需焦煤代理。

```text
P煤,t = 煤炭产品收入t / 煤炭销量t
补煤模板T1 = 原模板T0 + 锚期煤收入/P煤,0 × (P煤,t−P煤,0) × 税后归母系数
             = T0 + 锚期煤收入/100 × [100×(P煤,t/P煤,0−1)] × 税后归母系数
条件链C1 = 前轮条件链C0 + 当期实际煤产量 × (P煤,t−P煤,0) × 税后归母系数
```

模板新增项调用同一 `unit_economics`；已校验绝对价格与旧百分比变量两种表示相等。C1沿用按产量的链设计，与模板按锚期销量有库存/销量口径差异，不把该差异调成拟合系数。R8保持T0/T1/C0/C1预测不变，仅替换实际值为原件扣非归母；非经常项=归母−扣非，不重新标定扣非基数。

R7另列C2：在“有色行业合计仅含原铝、箔、冷轧”这一分项穷尽假设下，FY2025生产206.07−10.83−19.39=175.85万吨，销售204.94−10.74−18.44=175.76万吨；H2相应为88.74/88.62万吨。原件为神火FY2025 p18—19；同表FY2024生产189.15−9.68−16.62=162.85、销售189.41−9.79−16.73=162.89，两条均与独立原铝披露相符。**FY2025仍是表内拆分条件值，非独立直接披露**，仅用于C2另列重跑，不提高直接披露覆盖率，也不把销量代生产量。

## 5. 结论与边界

事实：R6实际煤售价项使神火2025年的模板高估收窄，但没有消除残差，其他两期绝对误差扩大；R8扣非不能一概改善误差。R7得到FY2025/H2表内拆分条件值，并重跑C2，但未补到2026H1直接铝量，Q3总利润仍不可算。C1/C2在各自与T1相同的可比样本上仍不优，故依§7精神**保守停止，不调常数**。这不是已完成完整链后的严格优劣闸门：完整链输入尚未识别，不能据此否定或确认完整产业链模型。

偏差：固定2024H1锚不等于产品每次研究滚动TTM；只有5个半年且神火可比后验样本2个，不能作稳定性承诺。V1写出完整方程但缺AO耗材常数和实际成本；V2完整公司链未识别，仅有明确假设的增量检验；V3完整链误差留空；V4只在现行模板验证算法；V5没有五档结论翻转价；V6没有神火Q3完整估算。因此**V1—V7未全部验收完成**，不能把离线命令结束写成任务通过。

本轮状态：R6完成五期实际煤价与误差归因，R8完成两家五期扣非对照；R7仅部分完成，FY2025/H2是条件拆分而非新取得直接披露，2026H1实际原铝量与Q3总校准仍缺。剩余还有公司逐期用电、AO内部自用/独立成本/抵销、煤单位成本、非经常项逐项归属及五档结论确定边界。由Claude审阅决定补正式披露或另行授权假设，codex1已停。本轮未修改产品、Stock代码或并行任务文件，未读凭据、写用户层/Wiki/成果、打开产品个股页、重启5930或提交/push。
