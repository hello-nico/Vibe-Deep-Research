# 观察信号 Jev 判定（2026-10-26）

## 1. 问题

观察（why / 加强 / 削弱 / 推翻）配一条消息，Jev 三选一「加强 / 削弱 / 无关」的把握与稳定性如何。对错由 Claude 标注，本评测不算准确率。对应 [观察信号Jev判定验证](../../tasks/active/观察信号Jev判定验证_Task_2026-10-26.md)。

## 2. 方法与数据集

51 对（观察 × 消息），每对 3 次措辞（原文、条件换序、条件加「若出现」前缀），共 153 次。问法冻结于 `.local/observation-jev/question.json`，出结果后未改。

观察：议题 `tracking_items` 11 条（长江电力 7、华能 3、万华 1）；不足部分用宁德、神火个股页证伪条件构造 6 条，`obs_kind=constructed_from_research`。每条观察配该公司近 60 天公告、新闻、对账各 1 条（8700 `feed`、`quarter-reconciliation`）。逐行来源见 [results.csv](results.csv) 的 `msg_url` / `msg_published`。

## 3. 环境

2026-10-26。`typesafe-ai/jev`，密钥只用 shell `AI_GATEWAY_API_KEY`。未改产品代码。

## 7. Claude 标注与准确率（2026-10-26）

标注口径：只按消息标题能判断出的结论（与 Jev 所见一致）；标题看不出方向的相关消息记「无关」可接受，并标为 ambiguous（8 条）。明细 `labels_claude.csv`。

| 指标 | 结果 |
|---|---|
| 原始问法总体准确率 | 42 / 51（82%），主要来自「无关」 |
| Jev 判为加强或削弱的 | 8 条，**全错（0 / 8）** |
| 其中输入为「对账 status=gap」（无新季报、无信息）的 | 7 条：Jev 以 0.41–0.69 的把握瞎猜方向 |
| 真有方向的样本 | 2 条（万华前三季度净利 +71% → 加强；神火现金多 118 亿 → 加强），Jev **都没判出** |
| 0.8 门槛自动采纳（原始问法） | 22 条，全是「无关」，**22 / 22 正确** |

判定：
- Jev 只适合作「无关」预筛：≥0.8 的「无关」可直接丢弃，省掉后续 Agent 判断；加强 / 削弱方向不能交给 Jev，要交给 Agent（带观察条件与消息正文）。
- 本轮样本偏弱：消息只有标题；观察条件多是长江电力持股结构类，几乎碰不到消息；「对账 gap」本不该作为消息输入（产品里也不该把 gap 卡送去判定）。若要再评估方向判断，需带正文、选有方向的真实配对重做。
