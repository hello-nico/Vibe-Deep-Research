# 财报日历来源（2026-10-20）

## 1. 问题

关注公司下一份定期报告、业绩预告与快报的预约披露日能否自动取得、从哪取、准不准，供跟踪显示下次校准日期。对应 [财报日历来源验证](../../tasks/active/财报日历来源验证_Task_2026-10-20.md)。

## 2. 方法与数据集

关注页只读接口 `GET /finance-api/client/watch` 与 `/client/research` 合并去重，共 17 家（A股 16，港股 1）。未打开个股页。
主测指定披露平台巨潮 `hisAnnouncement/query`（实际定期报告/预告/快报公告日）与上交所「定期报告预约情况」页、深交所披露目录；备用东财 `RPT_PUBLIC_BS_APPOIN`（预约日+实际日）、`RPT_PUBLIC_OP_NEWPREDICT`、`RPT_FCI_PERFORMANCEE`。
核对 2026 三季报（报告期 2026-09-30）与 2026 年报（2026-12-31，若已预约）。已披露的预约日对实际日；东财实际日再对巨潮公告日。不登录、不付费、串行、间隔 0.35 秒。

## 3. 环境

本机 Python 3，日期 2026-10-20T11:14:14+08:00，工作台 127.0.0.1:5930 只读关注接口。无账户、Cookie、密钥。SSL 对部分交易所站点不稳定，失败会重试。

## 5. 结论与适用边界

执行方客观候选（**待 Claude 判定推荐主备**）：预约日目前只有东财 `RPT_PUBLIC_BS_APPOIN` 能自动覆盖全部关注 A 股；实际披露日应用巨潮公告核对。交易所预约时间表页面存在，但本轮没有稳定 JSON。2026 年报预约尚未公布。必须预告由当期是否触发主板/创业板条件决定，不是 17 家固定名单；快报非强制。条款见东财用户协议，巨潮为证监会指定披露网站。不能推出产品已接入，也不能推出云端长期可用。
