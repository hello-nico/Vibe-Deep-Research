**7 模板：通用部分 / Profile 提供部分 / 示例**

| 模板 | 通用（方法与三档） | Profile 提供 | 示例 |
| --- | --- | --- | --- |
| commodity_pe | 价×量−成本 → EPS × PE 分位 | 具体商品、单耗、扩产矿、副产品 | 电解铝/工业金属：通用=铝价×产量−成本→倍数；Profile 问铜铝钼价、玉龙等投产、副产钼/硫酸 |

| backlog_pe | 订单×结算毛利 → PE 或 EV/backlog | 船价、新签、回款 | 航海装备Ⅱ：通用=手持订单结算；Profile 问交付节奏与钢成本 |

| insurance_pev | 三档 NBV/投资假设 → P/EV | EV、NBV、综合成本率（平安 p41/p45） | 保险Ⅱ |
| realty_nav | 三档结算或 NAV 折溢价 | 结转规模、结算毛利率（保利 p12） | 房地产开发 |
| infra_yield | 三档电量/ARPU × 利率或 EV/EBITDA | 发电量、电价、用户 | 电力 / 通信服务（通信 6 条核心问题全是叙事，ARPU 靠通用框架） |

## 5. 结论与适用边界

通用框架决定「用 PE 还是 P/EV」；Profile 只填该行业的变量名与问题，不能代替倍数规则。现有引擎只覆盖 commodity_pe 有目录价的子集。今日没有任何模板最少输入全「能用」。不能推出已可实现 31 套模型或已把 Profile 接进估值。防过拟合：不要为 no_source 三行业补研报窗口。
