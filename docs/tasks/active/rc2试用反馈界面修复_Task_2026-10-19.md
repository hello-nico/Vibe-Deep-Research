状态：2026-10-19 晚 claude3 写定（用户全权委托推进），来源为用户在 5930（rc.2）的试用截图。待 claude2 实施。

权威：[UI 自解释](../../contracts/product-ui.md)、[设计说明](../../design.md) §7 审阅清单。

## 1. 目标

修掉试用中暴露的五处界面问题：状态标签看不懂、点标签会意外收起、“查看数据”漏出原始占位符、
问助手带上别页的上下文、资料页提问入口重复，以及带新闻标签时点发送要等十几秒。用户第一眼能看懂，不用想“这块是干什么的”。

## 2. 现状（Claude 核实）

- U1 关注页“接下来盯什么”卡片右上角标签“更稳 / 打折扣 / 不成立”：`desktop/src/verticals/finance/lib/companyNarrative.ts:240–265` `trackingState`。
  含义：当前值未越过警戒线为“更稳”；越过且观察窗口未过为“打折扣”；越过且已过为“不成立”。界面没有任何说明。
- U2 同一卡片：整个卡头（含标签）是展开/收起按钮（`components/CompanyNarrative.tsx:187–189`），用户点标签后下方说明文字消失，以为是故障。
- U3 关注页（长江电力）“它靠什么赚钱 → 查看数据”展开后显示原文
  `境内水电收入{segment:product:境内水电行业.revenue}、成本{segment:product:境内水电行业.cost}…`：数据引用占位符没有替换成数值。
  `pages/CompanyPage.tsx:40` `Detail`；占位符解析需执行方定位（`lib/companyPacket.ts:100` 有 segment 标签映射，可作线索）。
- U4 跟踪页“正在盯的”首行悬停提示被容器裁切，只露出“…有大的波动”，并压在条目标题上。
- U5 问助手上下文串页：在资料页打开“长江电力关于控股股东增持股份结果的公告”后，回到动态 → 关键变量 → 问助手，
  输入框上方仍挂着“长江电力…公告”标签，与当前页（沪铝/神火/云铝）无关。相关代码 `desktop/src/verticals/finance/assistant/`。
- U6 资料页 PDF 选中一段后，同一段文字同时出现在：PDF 高亮、阅读器底部“追问范围：第 1 页 … 就此追问”条、
  问助手“已选原文”展开块；另有文档标题标签与“问问这个页面”说明卡。入口与信息重复。
- U7 问助手带新闻（URL）标签发送：`assistant/prompt.ts:268` `bindAssistantPrompt` 先同步 `fetchCitedUrl`（`:68–80`，`POST /documents/fetch-url`，
  外部 jina-reader，超时 `BIND_TIMEOUT_MS` 15s），抓完才发 prompt。实测 14.3s，期间无提示；抓完后首字约 2.4s（`.local/askassist-latency/report.md`）。

  上游扩展点：preload 在 `<html>` 设 `data-platform="darwin"`（apps/desktop/src/preload-platform.ts）；ui-conversation 用它预留标题栏与拖拽区。

## 3. 冻结决定

D1 U1 不用状态词，也不用“警戒线”等行话（human-checklist 2026-10-19）。卡片只写这条判断靠什么成立，例“毛利率保持在 55% 以上”。
  正常时不显示任何状态。条件被打破时在数值下加一句：“毛利率降到 54%，低于 55%，这条判断可能不成立了”；
  对应期报告已出仍不满足：“三季报已出，毛利率仍低于 55%，这条判断不成立”。取不到当前值时不显示。文案集中在一处常量。
D2 U2 卡头不再整体可点：展开/收起只由明确的箭头控件触发；默认全部展开，各卡一致。
D3 U3 页面展示的研究文字中，`{…}` 数据引用一律解析成带单位与期间的数值；解析不到的显示“（数据缺失）”，不得漏出原始占位符。
  页面与问助手快照共用同一解析函数。
D4 U4 悬停提示不被裁切、不遮挡标题（用 DSH 原生提示组件或可溢出容器，见设计说明 §7）。
D5 U5 问助手的页面上下文只属于当前页：切换页面时清掉上一页自动带入的标签；用户手动 @ 选中的条目同样不跨页保留。
D6 U6 资料页只保留一个显式提问入口（human-checklist 2026-09-16：选文追问须用户显式发起）：选中文字后在浮动工具条（复制旁）给“问助手”，
  点了才把原文放进问助手“已选原文”（默认收起成一行）；删除阅读器底部“追问范围 / 就此追问”条；面板标题已是文档名时不再显示文档标题标签；
  “问问这个页面”说明卡关掉后不再出现。
D7 U7 URL 类标签发送时不再预抓正文：只写身份行（标题、URL、来源、时间，沿用 `identityLine`），注明“正文未预读，需要时自行读取”；
  “已在发送时读取”的提示只覆盖确实已读取的对象。资料库文档（`document:{id}` 钉版本，见 my-materials 契约）保持现状。不加预取缓存。
D8 U8 仅在 `html[data-platform='darwin']` 下：产品外壳顶部留出窗口按钮带，左栏与页面标题都不与红黄绿按钮重叠；该带可拖动窗口，
  按钮、链接仍可点。Web（5930）无此属性，外观不变。只用 CSS 与上游属性，不改 DSH 包。
