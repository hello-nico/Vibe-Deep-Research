2026-10-26 claude 写定，交 pi3。Stock worktree `.worktrees/pi3-userchain`（git worktree add --detach，基于 HEAD 3b676ac）；不提交、不重启、不读凭据、不写真实用户数据。依据：Checklist 2026-10-20「产业链是用户对象」、2026-10-26「对话写回与闭环收口」；[产业链用户对象现状](../../evals/产业链用户对象现状_2026-10-26/README.md)。前端另立 Task。

## 1. 目标

产业链成为按用户保存、带版本可撤回的对象：初始为空，由用户点「新建」或点对话推荐才建；建链时由公共结构生成骨架。

## 2. 现状（pi3 摸底）

- 公共链：`backend/app/services/valuation_templates.py:61–116` `chain_list` / `chain`（节点公司 = 申万成分），`api/v1/valuation_framework.py:11–21` 只读接口。保留不动。
- 用户层参照：Topic `research_topics.py:612–638`（revision 冲突 409）、个股研究 `page-research` 与 `/revert`（`company_data.py:164`），均 `require_user`。
- 对话推荐只有 question / indicator / company（`dsh/src/suggestion-tools.mjs`），无建链。

## 3. 冻结决定

U1 存储：用户产业链按用户隔离（`require_user`），字段：id、来源公共链 id、名称、环节（复制自公共骨架：环节名、所属申万行业、估值方法、共同驱动与逐段传导）、链上公司（只放用户已关注且属于该链环节的公司；其余不放）、版本号、更新时间、来源（新建 / 对话会话 id）。每次修改升版本，可撤回上一版。
U2 接口：列出、读取、从公共链建（`POST`，带公共链 id；同一公共链已建则返回已有）、改（加减公司、改名）、撤回、删除。
U3 推荐：给定公司，返回它可能所在的公共链（按申万成分）及「已建 / 未建」——供个股页「推荐所在链」，不再自动挂链。给定用户链，返回同链环节里用户未关注的公司候选（按申万成分，最多若干家，不全量列出）。
U4 对话推荐第四类 `suggest type="chain"`：带公共链 id、名称、一句为什么；vibe-check 校验同其他推荐（不含文字数字限制以外的新规则）。工具与提示词说明的文字由 Claude 另改，本 Task 只加类型、校验与 model-surface 快照。
U5 不做对话读写链工具（下一步）；不改公共链数据。
