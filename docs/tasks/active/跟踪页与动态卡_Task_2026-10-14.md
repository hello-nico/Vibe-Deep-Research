## 1. 目标

1. 「洞悉」改为「跟踪」：用户交出去的事情的回执。第一版两块：正在盯的（研究里自动产生的关键变量）、研究（每家公司一句结果，点开看步骤）。「定期」一块等 T8b。
2. 动态的关键变量卡改轻：标题写事情本身，第二行只写碰到哪些关注公司、方向；金额点开才看到。
3. 用户看一眼就知道每块拿来干什么；不出现任何技术细节（数据版本、凭据、重试、重启、系数、编号）。

## 3. 冻结决定

R1 **导航与路由**：「洞悉」改名「跟踪」，路径改为 `/tracking`；`/insights` 重定向到 `/tracking`；`/insights/topics/:topicHex` 议题页路由保留（不进导航，已有链接仍可打开）。
R2 **跟踪页**（新文件 `pages/Tracking.tsx`，替换 `MyResearch` 在导航中的位置）：页首只有标题「跟踪」，无副标题、无分段。两块，组名在卡片外：
  - **正在盯的**：读 `loadTrackingVariables`。每个变量一行：圆点 + 名称（粗）+ 一句最新情况 + 碰到的关注公司简称，右侧灰字为最新数据日期。
    - 一句最新情况：最近 20 个交易日内有卡片的写「{日期} {涨/跌} {幅度}，已提醒」；没有的写「本周没有大的波动」；`no_data` 写「没有公开行情，跟着财报更新」；`gap` 写「暂时取不到行情」。
    - 点一行展开，复用现有 `Detail` 显示各公司影响（第二层可以有金额）。
    - 有卡片的变量排前；行多于 6 条时其余收进「显示另外 N 项」。
    - 原 `Coverage` 的「还没研究的公司」放在本块末尾一行灰字，带「去关注」链接；「未覆盖的变量」并入列表（即 `no_data` 行）。
  - **研究**：读 `GET /finance-research-tasks?limit=50`，每家公司只取最新一条，按 `updated_at` 倒序，最多 10 行。
    - 行：状态圆点 + 公司简称（粗）+ 一句话，右侧灰字时间。
    - 一句话：`running` →「第 N 步，共 6 步 · 名称」并带细进度条；`interrupted` →「正在接着上次的进度继续」；`completed` →「完成，估值「{五档}」」（五档读该公司个股页研究的 `valuation.grade`，读不到就只写「完成」）；`failed` → 记录的 `reason`；`cancelled` →「已中止」。
    - 点开显示六步：名称 + 状态；`read_report` 步附 `outputs.title`，`key_variables` 步附 `outputs.variables` 用顿号连接；其余输出一律不显示。下面一个「去个股页」按钮。
    - 没有任何记录时：一句「关注公司后，研究进度和结果会出现在这里」+「去关注」。
R3 **洞悉其余标签去向**：
  - 待处理、议题、任务：从导航撤下，不再有入口（议题页路由保留见 R1）。
  - 记录：`NotesPanel` 搬到资料页，作为资料页分段「记录」（与现有资料列表并列）。
  - 记忆：`MemoryPanel` 搬到设置页，作为设置页分段「记忆」，原样保留，等 T9 重做。
  - `MyResearch.tsx` 删除；仍被引用的辅助函数随搬迁移到新位置或 `lib/`。
R4 **研究状态统一读任务记录**：`dsh/client.tsx` 与 `dsh/task-activity.ts` 中公司研究（`kind: 'research'`）的状态改读 `/finance-research-tasks`；报告任务（`kind: 'report'`）逻辑不动。之后 `lib/reportTasks.ts` 里只服务公司研究的函数与 `RESEARCH_START_GRACE_MS` 若已无引用则删除。
R5 **动态卡改轻**（`VariableDesk` 的 `Cards` 与 `lib/trackingVariables.ts`）：
  - 标题（粗）：「{名称}{一天 / 五天累计}{涨 / 跌} {幅度}（{涨跌百分比}）」，例「沪铝主力一天跌 445 元/吨（−1.9%）」。
  - 第二行：「关注中：{公司简称…} · 对利润偏{正面 / 负面}」；各家方向不一致时写「对利润影响方向不同」。
  - 「展开」后才显示每家公司的全年利润影响与中性价变化（沿用现有文字与配色）；「讨论」「看个股页」按钮保留。
  - 动态页「关键变量」分段只留卡片；`Table` 与 `Coverage` 移到跟踪页（R2），动态页不再显示变量表。
  - `cardQuestion` 不改。
R6 不做：「定期」块（T8b）；「开始观察」与用户层跟踪项表（随 T12b）；问助手改造；新增后端接口。
