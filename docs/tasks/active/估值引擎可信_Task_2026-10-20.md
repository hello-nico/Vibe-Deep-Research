## 1. 目标

个股页的利润试算、三档估值与「市场在赌的价格」由 Backend 算得可信：煤价进模型、对比期与基数同口径、三档有序、给出现价隐含价与跳档价。

## 2. 现状（Claude 核实）

- 模型：Stock `backend/app/analysis/sensitivity.py` `sensitivity`；取数 `services/sensitivity.py` `prepare`、三档 `combination_defaults` / `scenario_defaults`、位置 `reference_position`。
- 神火 10-20 重新研究：基数已滚到三季报口径（年化 71.17 亿），但「对比期均价」仍为上半年 24,325 元/吨（锚期取分部期间 `period`，与 TTM 基数不同口径）。
- 公司自有百分比变量三档为 0（`scenario_defaults`），神火无烟煤价格不起作用；回测 R6：补财报实际吨煤售价后神火四期 MAPE 37.3% → 20.3%（`.local/chain-model-backtest/r6-r8/coal-prices.json`）。
- 三档：中性 = 当前价、悲观 / 乐观 = 历史利润 20% / 80% 分位日，当前价在高位时乐观 ≤ 中性；回测候选 B 以 min(Q20, 当前) / max(Q80, 当前) 保证有序（`.local/chain-model-backtest/scenario-candidates.json`）。
- 隐含价：主变量线性反解已有（`extra.implied`）；跳档价没有。回测 `implied-and-flips.json` 已给反解方法与神火、云铝数值，可作测试期望。

## 3. 冻结决定

E1 对比期均价与基数同口径：TTM 基数的锚期均价取同一 TTM 区间的日均价；回落年化时取对应期间。写入 extra 并在 assumptions 说明。
E2 煤价：公司自有「煤价」类百分比变量改为价格变量：锚值为最近一期财报煤炭收入 ÷ 煤炭销量（不含税实际售价）；期间日度变动用焦煤主连 `cmdty:DCE.JM` 相对变动作代理，标「代理，待校准」并写明弹性假设（Checklist 2026-10-13）。取不到财报售价时保持现状并给缺口原因。只做煤，不泛化其他自有变量。
E3 三档改用候选 B：中性 = 当前价组合；悲观 = min(Q20 日利润组合, 当前)，乐观 = max(Q80 日利润组合, 当前)，保证悲观 ≤ 中性 ≤ 乐观；当前在区间外时允许某档等于中性并在 method 写明。
E4 隐含价与跳档价：extra 增加 `implied`（保留）与 `flips`：主价格变量在其他变量与倍数固定时，使现价落到 `reference_position` 各区间边界（接近中性 ±10%、悲观价、乐观价）的价格；超出变量合理区间的标无效，不删除。
E5 测试：神火、云铝用回测冻结输入做期望值（三档有序、隐含价与回测一致到 1 元/吨、跳档价与回测 B 候选一致）；煤价锚与代理标注；对比期与基数同口径。

E6（10-20 用户确认，Checklist「五档估值结论由数字约束」）：Backend 在 sensitivity 结果里给出基准档 `grade_base`（由 `reference_position` 的 zone 映射：below_pessimistic → 明显低估、pessimistic_to_neutral → 偏低、near_neutral → 合理、neutral_to_optimistic → 偏高、above_optimistic → 明显高估）；
   Stock 插件保存研究时校验模型五档与基准档相差不超过一档，偏离时必须有 `grade_reason` 一句，否则拒收一次（`dsh/src/company-page-tools.mjs`，在 pi1 已合入的禁用词校验旁边加；此项允许改 dsh/）。测试：同档放行、偏一档有理由放行、偏一档无理由拒收、偏两档拒收。

E6 补充确认（10-20 用户）：允许修改 `backend/app/services/company_page_research.py`，在 Valuation 增加可选 `grade_reason`，使偏档理由随研究保存；保留现有保存校验。
