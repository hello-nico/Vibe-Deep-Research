## 3. 冻结决定

- **D1（P1-1）**：`read_industry_profile` 增加两种入参，`industry_code`（如 801711.SI）或 `symbol`（如 600585.SH，按公司所属申万二级行业），读取当前版本。原来的 `profile_ref` 仍可用，用于引用时钉住版本。三种入参必须且只能给一种。返回值带上当前的 `profile_ref`，方便引用。
- **D2（P1-2）**：保存研究时，本次没有敏感性、而已有研究里有，就不拒收：新研究沿用上一版的敏感性（凭据、驱动、档位计算都用上一版），并在研究里记下「敏感性沿用 {上一版的 report_period}」，页面能读到这一项。上一版也没有敏感性时，照现有规则处理。提示词里对应的那句由 Claude 改，本 Task 只给草稿。
- **D3（P1-5）**：company_research 的工具清单加入 `read_industry_profile`，只读。
- **D4（P2-1）**：删除四个退役角色，包括它们的提示词、工具清单、快照和测试。Vibe `binding.ts` 里对应的映射一并删掉；那些 pageKey 已经没有页面，删掉不会影响任何入口。删除前全仓搜索引用，有活引用就停下回报。intel（资料阅读）保留。
- **D5（P2-3）**：行情目录只在一处定义（Backend 已有的登记表，或 dsh 里的一处常量，由执行方选一处），研究提示词和工具说明都由它生成，不再手写。本 Task 不增加动力煤，系统里没有这条序列。
- **D6（P2-5）**：从 deep_research 的工具清单移除 `stage_extraction` 和 `topic_list`、`topic_get`。主对话里没有议题路由；先确认主对话提示词和其他代码不依赖它们，如有依赖就停下回报。抽取入库机制本身不删，其他角色照常使用。

- **D10（10-28 Claude 裁决，解除 §7 停止项三：D2 的数字一致性）**：沿用上一版敏感性时，只沿用利润系数（各变量每单位变动对利润的影响、拆段与档位设置），不沿用任何按旧股价或旧行情算出的存值。
