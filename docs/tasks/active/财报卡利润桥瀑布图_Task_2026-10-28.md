## 1. 目标

动态财报卡展开后，先看到一张利润桥瀑布图：左端是上季单季净利润，中间是各项增减，右端是本季单季净利润。原来的逐项文字收进「看数据」。

## 2. 现状（Claude 已核实）

- 卡片数据来自 Backend `GET /wiki/companies/{symbol}/quarter-reconciliation`，前端类型见 `desktop/src/verticals/finance/lib/quarterRecon.ts:8-25`：
  - `items[]` 每项有 `name`、`previous`、`current`、`impact`（元，正数表示对净利润有利）；
  - `rest` 是「其他」；
  - `previous` 和 `actual` 是上季和本季的单季净利润；
  - 各项之和等于本季与上季的差。
- `reconCards()`（`quarterRecon.ts:86`）现在把 items 转成 `details: string[]` 文字，再由 `feedStream.ts` 的 `reconStream` 转成 `StreamCard.details`，在 `pages/VariableDesk.tsx` 的 `StreamItem` 里展开显示。也就是说，结构化数据在 `reconCards` 这一步就丢了。
- `MECHANICAL`（所得税、少数股东损益）不做首句结论，但在明细里列出。
- 现有 `compare` 组件在 `dsh/vibe-node.tsx:104`，可以参考它的零基线条形画法。
- 设计规矩在 `docs/design.md`：
  - 动态卡不描边、不加底色；
  - 橙色只用于进行中、选中和当前值；
  - 涨红跌绿是行情用色，利润增减另行约定，见 M3；
  - 原则 9：浮层不能被挡。

## 3. 冻结决定

- **M1**：`ReconCard` 带一份结构化的桥数据：`bridge: { start, end, steps: { name, impact }[] }`，单位为元。
  - `steps` 由 items 加「其他」组成，按影响的绝对值从大到小排列；
  - 影响小于总变化 3% 的项合并进「其他」；
  - 没有 items、只有价格模型的卡，不出桥。
  - 只有 `reconCards` 一处产出桥数据，其余地方只读不算。
- **M2**：展开后第一块是瀑布图，用纯 SVG 或 CSS 画在 React 里，不引入图表库：
  - 横向条形，每行一项：左边是名称，右边是带正负号的亿元数；
  - 条从上一项的累计点开始；
  - 首行「上季」、末行「本季」是实心条，从零开始；
  - 刻度全图共享、零基线可见。
- **M3**：增加的项用墨色、减少的项用浅灰，不用红绿和橙色；首末实心条用墨色。依据是 design.md：品牌橙不用于数据。
- **M4**：图下面一行灰字，写现有的口径说明「科目取自利润表，单季 = 累计值相减」。原来的逐项文字、价格模型估计、披露前走势，都收进图下的「看数据」折叠，内容和措辞不变。
- **M5**：窄屏（390px）不出现横向滚动，名称过长时省略并带悬停提示。浅色、深色主题都要清楚。
- **M6**：不做兼容。测试里断言 `details` 文字的地方，按新结构改。
