### A 线接口变更

#### 最新裁定的实现补足（以文末 Claude 两项裁定为准）

旧 A 线提议中的 result_cell EPS、扁平 base_profit、params.equity_output、Q3 单季和必填 hash/sessionId 请求字段均由文末「接口补齐」「零变动锚点」取代；不保留第二套协议。数字 version 单调增加；撤回 `{}` 可用，可选 expectedResearchVersion 仅保护携带它的请求；会话来自 `X-Vibe-Session-Id`，不接受模型参数里的身份。

- `implied` 增加可选 `multiple: ScalarAssumption`，因为 `multiple_scenario` 仅为档名，独立 sensitivity 请求没有倍数可反解。未给倍数时返回 null 与 gap；drivers 写回从新给或上一版该档倍数注入，显式冲突拒绝。反解主变量为首变量，其他变量固定 current。
- coal 的 `coal_price.vat_inclusive=true` 时条件必填 `params.vat_rate`（画像或报告）；否则不除增值税，不凭空推定税率。
- generic 的数据包成本绑定键为 `operating_cost`（原始营业成本），不从毛利率倒推。generic 固定零百分比 current/anchor 不需要行情来源；这两个零为模型坐标原点，其他模型的 current 保持行情/原文绑定。
- 句中无效占位剔除后若整句为空，保存为「暂无可核对数据」，并保留剔除 warning；避免保存后无法读回的空叙事。计算占位只接受可回读的有限数值叶子。
- 新变量若没有可继承的有效 quote/quoteSource，drivers 更新返回 422；不静默保存失去原话来源的更新。
- current 的日期保留来源语义：报告数字保留原报告期间；行情保留最后实际交易日，不强制把周末/假日或报告期改成上海当日。行情单元不得在数据包日期之后，保存成果的取数/请求时间亦不得在未来；缺少可核对时间元数据明确拒绝。页面 source_label 显示实际期间，不声称未取得的今天行情；anchor 仍匹配基数期间。
- 原印刷金额在数字回读后按明确单位转换为元；其他单位拒绝。新增 source-free assumption 与 source-only result_cell 的 Quantity 例外仅用于 sensitivity，旧运算仍要求其原完整轴；scenario_price 只开放 calculation_output 派生 EPS。

#### R3 镜头的稳定键（2026-10-12）

- `lenses.ytd_yoy.revenue`、`lenses.ytd_yoy.net_profit_attributable`，可选 field_id 分别为 `lens:ytd_yoy.revenue`、`lens:ytd_yoy.net_profit_attributable`，单位 `%`。按当年已取得的最新连续完整单季，从一季度起合计，对上年相同季度区间；当前年或同期季度缺失、口径不齐、同比分母非正时返回 gap，不把未披露或缺失季度当零。

- 两镜头沿用数据包现有 `value/unit/period/scope/status/inputs/input_field_ids` 形态，不加平行字段来源格式。

#### R4 / R9 绑定与缺省补全（2026-10-12）

- `document_number` 输入继续使用现有完整 Quantity（`name/value/unit/currency/period/scope/basis/source`）；value 必须是原文原单位的字面数，Backend 核对后才转换模型单位。仅给 block 而不给数字无法在多数字原文中定位。`result_cell` 可仅给 `name/source`，Backend 从持久成果回绑值与轴；不接受调用者改写 sensitivity 派生 EPS 的值。
- `base_profit` 保留 `{name, source: packet_field, annualize}`；annualize 允许 FY、H1、Q1、Q2、Q3，必须匹配实际字段期间；季报 ×4 只用于单季，不把九个月累计当一个季度。数据包新增 `fields.latest_net_profit_attributable` 供最近披露报告使用：年报原值、中报累计、一季报单季、三季报由已存 Q3 累计减 H1 得单季；这是 R4 年化基数所需字段，不改变旧年度字段含义。
- 股本与现价由 Backend 从该公司上海当日包的 `shares`、`price` 绑定，调用方不再提供数字。`params.vat_rate` 必填（document_number 或 value_from）；模型同样要求有来源的所得税率，不把未说明的税负默认成零。所得税/VAT 用百分比原文时 Backend 归一为小数，原数与单位留在绑定里。
- 隐含反解请求新增 `implied: {var_id, multiple}`，multiple 使用现有 `ScalarAssumption`；缺这一项时 `implied` 为 null 并说明缺口，不猜倍数；系数为零或现价缺口时也返回明确缺口。省略的情景变量按 current，未知 var_id 拒绝。
- 模型变量键：电解铝为 `cmdty:SHFE.AL`、`cmdty:SHFE.AO`；火电为本公司 `:<electricity_price|fuel_cost|electricity_volume>`；煤炭为本公司 `:<coal_price|coal_volume>` 或行情目录中的煤价编号；generic 为本公司 `:<price_pct|cost_pct|volume_pct>`。不为混合业务凭空加未登记变量系数。电解铝/火电/煤炭使用 `params.equity_output`（权益年产量/发电量），火电与煤炭还需报告绑定的 `price`、`unit_cost` 以算量系数；generic 的 `revenue`、`cost` 只绑定该公司当日 packet_field，并明确税后经营变化作为归母变化的线性近似及少数股东分配未建模限制。
- 行业常数 `value_from` 严格走现有画像/hash 所有者；凭据保留常数值、键、画像 hash、来源与限制。单耗 1.93 的原始依据为本 Task 用户确认的神火原型参数，标为行业模型假设，不伪装成本公司核验事实；公司实耗应优先绑定报告原文。
- R9 EPS 写法为 `{name, source:{kind:"result_cell", result_id:<sensitivity 凭据>, row:0|1|2, column:"eps"}}`。只开放 sensitivity 的 `extra.scenarios` EPS 单元；三档必须来自同一公司、同一凭据且与行的场景名一致。其他任意 calculation 路径不能作为 EPS 来源。

#### R8 版本与出处字段（2026-10-12）

- GET 研究增加顶层 `researchVersion`（当前研究记录的逻辑版本 hash）与 `canRevert`；写驱动及撤回请求必须带 `expectedResearchVersion`，防止同一资料版本上的并发覆盖。更新请求另带 `sessionId`；`confirmedAt` 由服务器生成，不接受调用者伪造时间。
- `changedFrom` 为顶层对象 `{origin:"conversation", sessionId, confirmedAt, reason}`。沿原研究块 envelope 原子保存 `previous` 单个上一版及本次 `page_research_changed` 事件；previous 去掉它自己的 previous，避免递归膨胀。现有 Wiki 发布历史保存历次完整版本；事件不在 GET 中展示。不新建表或第二存储 owner。
- 更新/撤回沿用 hook token 权限与已有发布锁；版本冲突 409；未保存敏感性、无法回读计算或原文、缺上一版均明确拒绝，不部分改写研究。撤回保留原研究日期与依据版本，资料过期仍返回 stale；单次上一版恢复后不提供隐式 redo。
- current 保持锚点还是同步重基利润的语义已提请用户判断。相关子项在答复前不按「改 current 后利润仍归零」的行为实现，其余计算、校验与镜头继续。

## 2026-10-12 · Claude 裁定：零变动锚点（回应 A 线 R8 取值语义，更正前文）

结论：选「保持行情锚点、更新情景取值」，并更正一处公式：**零变动锚点不是 `current`，而是基数期间的变量均值 `anchor`**。
理由：`base_profit` 是某一期间（如 2026H1 年化）的实际利润，对应的是该期间的平均价格，不是今天的价格；以今天价格为零点会把「今天价格下的利润」错当成基数利润。神火原型即以上半年均价为零点（今天价格 → 年化约少 7.64 亿元）。

- 每个变量三个值：`anchor`（必填，基数期间均值，Quantity；行情类可绑定已保存行情窗口的期间均值 `result_cell`，或原文月均价 `document_number`，或 `basis: "assumption"` 并写明算法）、`current`（今天，绑定行情或原文，只作滑块初始位置与「按今天价格」的利润）、`scenarios` 取值。原「接口先行」中的 `reference` 改名为 `anchor`，含义如上。
- 公式统一：利润(x) = `base_profit` + Σ `coef_per_unit` × (xᵢ − `anchor`ᵢ)；结果新增 `profit_at_current`（按今天价格）。三档、`implied`、页面滑块都用这一式；页面仍只做这一加总与 ÷ 股本。
- R8：对话里的「按铝价 21000」写入 `scenarios`（或用户明确要改的倍数），`anchor` 与 `current` 都不被对话改写，基数不重设。若用户要换基数期间（如三季报出来后），属于整份替换时新的 `base_profit` + 新 `anchor`，由研究流程按新报告绑定，不由一句对话改锚点。
- `generic` 模型：`anchor` 为 0%，`current` 为 0%，不变。
影响：A 实现 `anchor` 与 `profit_at_current`；B 在 SOP 与 update_company_drivers 说明里写清锚点来源；C 的页面公式由 `current` 改为 `anchor`，滑轨标「基数期均价」并另标今天。

- **五节**：生意、关键变量（`profit_formula` 与 `variables` 合并，公式行在上、滑块在下）、现金、估值、跟踪，标题按 design.md。每节：问题标题 → 回答句 → 专用图 → 关键数（≤3，回答句里已嵌的字段不重复）→「查看数据」收起其余指标、`details` 与缺口。整节无数据时不渲染；数据包未到时先留骨架。
- **句中数字**：`{field_id}` 与 `{calc:result:…<路径>}` 由页面按字段或凭据取值，加粗等宽，悬停显示期间、口径与来源；缺口或读不到凭据显示灰色「暂缺」，不留花括号与键名。
- **专用图**：构成条；关键变量节的公式行 + 滑块（真实单位，滑轨标「基数期均价」与「今天」，右侧年化归母净利、相对基数变化、各变量贡献正负条〔红增绿减〕、每股收益、现价对应市盈率，下方一行假设）；无敏感性凭据时回退单季营收与归母净利柱图；去向条（缺项灰色虚线）；估值区间带（现价橙色实心点，滑块调整后的中性价空心点，每档「变量取值 → 利润 → 倍数（依据）→ 目标价」，另给「按中性倍数…现价相当于市场在赌某变量约某值」）；跟踪卡（当前值、警戒线、观察窗口、状态胶囊，点开看支柱与证伪条件）。
- **利润公式**：利润 = `base_profit` + Σ `coef_per_unit` × (取值 − `anchor`)，滑块初始位置是 `current`，初始利润与 Backend 的 `profit_at_current` 一致（测试断言）；每股收益 = 利润 ÷ `shares`。贡献、利润变动统一按亿元显示。
