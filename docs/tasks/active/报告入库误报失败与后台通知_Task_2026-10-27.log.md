## 根因与实现

- 东财公告 `fromisoformat()`、巨潮 `fromtimestamp()` 原来生成无时区时间；`DocumentMeta` 未规范化，新建与幂等跳过的旧文档在 `_ingest_candidates` 混排时抛错。
- 时间 Owner 收在文档模型：`document_datetime` 将无时区值解释为上海本地时间，带时区值保留瞬间后转换；`DocumentMeta` 读入与 `RemoteDocument` 构造均规范化。provider 自己在增量比较前规范化，巨潮时间戳明确指定上海时区。没有修改周期报告排序键来掩盖根因。
- Backend job 增加公司名、中文报告名供展示；名称只读现有覆盖目录，缺失不影响入库。已在无凭据环境中核对华能国际、华能蒙电、国电电力三家目录名称。
- `research-state` 在发起用户问题仍活跃时沿用 next-turn；结束后调用现有 `agent.inject`，不唤醒。两路均追加独立 plugin record，Vibe 由 exclusive 投影显示一次结果，模型上下文消息不再产生原生执行请求标题；错误原文只在详情里展示。
- 安装版 DSH 严格 JSON 校验暴露原消息 optional 字段带 undefined 的问题；在消息构造处清除，两个投递分支共用同一 JSON 安全消息。
