## 1. 目标

产业链页按三步顺序展示，所有行业都用同一套做法，不再为某个行业写死逻辑：
1. 行业现在在哪：周期位置，或者景气与瓶颈；
2. 上下游和利润在哪；
3. 重点公司。

## 3. 冻结决定

- **C1 页面顺序**：页首 → 第一步「行业现在在哪」 → 第二步「上下游和利润在哪」 → 第三步「重点公司」 → 试算 → 管理。三个小节的标题用问题句，按 design.md 的写法。原有的「链条」「共同驱动」并入第二步，原有的「链上公司」就是第三步。
- **C2 第一步「行业现在在哪」**：按环节分行，每个环节读自己行业画像里的 `cycle`。
  - 周期型：
    - 有结构化价差（`margin_logic.spread`，带 a、b、ratio）、日线也取得到的，就用现在这套分位算法，算出价差在近 N 年的分位，配底部—中位—高位刻度；
    - 没有价差、但 `watch_indicators` 里有 `series_id` 的，就算这个指标自己的分位；
    - 都没有的，只写一句「这个环节的周期指标系统里暂时没有序列，看 {where}」。
    - 再各附一句季节性（当前月份是旺季还是淡季，取 `seasonality`），以及离最近一个历史顶或底有多远（取 `history`，没有就不写）。
  - 成长型：写景气阶段和瓶颈，各一句，取 `bottlenecks` 和 `adoption`。
  - 每句话都要能点开看出处（refs）；来自检索的标「约」。画像里没有 `cycle` 的环节，只写一句「这个行业的周期资料还没整理」，不报错。
- **C3 删掉写死的逻辑**：
  - `CYCLE` 常量和「必须同时有铝价、氧化铝」这个条件删掉，周期位置一律按 C2 从画像生成，铝也走同一条路（工业金属画像里已有价差公式 1.93，带出处）；
  - 试算的价格变量不再写死沪铝，改为取这条链上「最多家公司的利润模型共同用到的那个价格变量」；一个都没有就不出试算。
- **C4 第二步「上下游和利润在哪」**：
  - 保留现有的链条（环节横排、箭头上写传导的价格）和共同驱动；
  - 新增一句「利润现在集中在哪个环节」：按各环节当前价差或毛利指标的分位判断。只有能算出来才写，算不出来不写；不靠模型猜。
  - 成长型环节写「瓶颈在：……」。
- **C5 第三步「重点公司」**：保留现有的链上公司行。每家公司标出它所在环节在第一步里的位置，用短标签，例如「周期底部」「瓶颈环节」。不加买卖建议，排序不变。
- **C6**：不改 Backend 计算口径。如需新的只读接口（例如批量取几个行业的画像），按现有接口风格加，单独写测试。不做兼容。design.md §5「产业链页」同步改写。
