## 1. 目标

1. 个股页从「指标墙」变为「先答问题、再给数据」：五节，每节问题标题 + 一句带数字的回答 + 一个专用图 + 收起的其余数据。
2. 数字仍由代码绑定，但能回到句子里（句中数字槽）。
3. 关键变量一节可拖动：变量取自公司自述的利润驱动或与用户讨论确认的变量，按真实单位调节，实时看到利润、每股收益与中性价的变化。
4. 估值建立在利润解释上：三档目标价 = 三组关键变量取值下的利润 × 按行业与周期位置给出的倍数。

## 2. 现状（Claude 核实）

- 页面每节平铺全部 fieldIds 为指标卡，每卡带期间与出处胶囊；正文禁数字，回答句写不出「毛利率却有 54%」。
- 数据包已有：收入、成本、毛利率、归母净利、现金流、资本开支、单季镜头、股本、预测每股收益与情景三档。行业驱动（电量、电价、销量、单位成本）多为缺口。
- 外部行情目录已有沪铝、氧化铝等期货（`backend/app/market/external_catalog.py`），可存为研究成果；`calculate_metrics` 已支持 `result_cell`、`document_number`、`packet_field` 三类来源绑定。
- 原型验证：神火按「权益产量 ×（铝价 − 1.93 × 氧化铝价）÷ 1.13 ×（1 − 所得税）」得铝价每 1000 元/吨约 9.96 亿元，数据全部来自半年报与当日行情。

## 3. 冻结决定

R1 **句中数字槽**：研究文字可写 `{field_id}` 或 `{calc:<result_id>.<key>}` 占位，页面按字段或计算凭据填入并悬停显示期间与出处；占位以外仍禁阿拉伯数字（窗口与日期字段除外，同 T7.2b）。无效占位按 T7.2b R1 剔除并给 warning。
R2 **问题标题**按 design.md 表；研究 JSON 不改六节键名，`summary` 即回答句（≤80 字，含占位）。页面把 `profit_formula` 与 `variables` 合为一节「关键变量动一下，利润变多少」：公式行在上、滑块在下，页面共五节。
R3 **派生数由 Backend 算**：数据包新增两个镜头——年内累计同比（单季合计对上年同期，收入与归母净利）、资本开支后现金（经营现金流 − 资本开支，标明未扣分红）。不另做其他精度工作。
R4 **敏感性 = 每单位利润系数**：新增 `calculate_metrics` 运算 `sensitivity`，输入为模型选的模型名、变量与参数，输出每个变量「每变动一个单位对年化归母净利的影响（元）」、基准值、年化基数与口径说明，存为计算凭据。
  - 变量用全局编号：行情类用行情目录编号（如 `cmdty:SHFE.AL`），公司自有变量用 `<代码>:<键>`（如 `000933.SZ:coal_price`）；跟踪与产业链页（T7b、T12）按编号复用。页面只做系数 × 变动量的线性相加。
  - 模型登记在 Backend（首批）：`aluminum_smelter`（铝价、氧化铝价；参数：权益产量、单耗、外购比例、增值税、所得税）、`thermal_power`（电价、燃料成本、电量）、`coal`（煤价、产量）、`generic`（价格 %、单位成本 %、量 %，只用数据包收入与成本）。
  - 变量当前值：行情类绑定已保存的外部行情成果（`result_cell`）；公司实际均价、产量、权益比例绑定报告原文数字（`document_number`）；行业常数（如单耗 1.93）写在行业画像里，凭据记录来源。
  - 基数：最近一期年化归母净利（半年报 × 2、季报 × 4、年报原值），凭据写明。银行不适用，不画。
R5 **研究 JSON 新增** `sensitivity: {resultRef, drivers: [{key, name, quote}]}`；`quote` 为公司原文的利润变动原因一句（≤80 字，可带数字，原样引用，需 `document_number` 可回读）。缺失或计算失败时该节用单季柱图兜底。
R8 **对话写回变量**：按 Checklist 已确认规则——普通对话讨论出关键变量或取值后，经窄工具 `update_company_drivers` 自动写回该公司的 `sensitivity`（来源标「对话确认」+ 日期 + 会话），Backend 重算系数与三档；页面变化处悬停提示来源对话，可撤回（恢复上一版），并在动态留一条记录。
R9 **估值三档来自利润解释**：有敏感性模型时，悲观、中性、乐观各是一组变量取值（模型说明依据，如期货曲线、周期低点与中枢），利润 = 基数 + Σ 系数 × 变动，每股收益 = 利润 ÷ 股本，倍数按行业与周期位置给出（周期高点利润配低倍数，写一句理由），由 `scenario_price` 每股模式计算并引用 `sensitivity` 凭据。无模型时沿用 T7.2 做法。
  - **现价隐含变量**：`sensitivity` 同时给出「中性倍数下，现价对应的主变量取值」（线性反解），估值节回答句写「现价相当于市场在赌铝价约 X 元/吨」。
R6 **跟踪卡状态由页面判断**：当前值对阈值，未越线「更稳」，越线未到窗口「打折扣」，越线且窗口已过「不成立」。SOP 加一句：警戒线设在当前值之外，已越线的写进回答句。
R7 **页首**：thesis + 五档结论 + 判断变化行（无变化写「研究于某日，资料未变化」）。

**通过标准**：保存 ≥5/6；敏感性有效（非 generic）≥3/4 家适用公司（华能、长江、宁德、万华、神火中适用者）；回答句含占位且无裸数字；token 中位 ≤60 万。
**用户验收（浏览器）**：五节先答问题；滑块手感与神火样张一致；第一层每节关键数 ≤3。
