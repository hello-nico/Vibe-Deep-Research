## 1. 目标

1. 个股页从「指标墙」变为「先答问题、再给数据」：五节，每节问题标题 + 一句带数字的回答 + 一个专用图 + 收起的其余数据。
2. 数字仍由代码绑定，但能回到句子里（句中数字槽）。
3. 关键变量一节可拖动：变量由定期报告的管理层讨论与分析和敏感性附注判断，或与用户讨论确认；有行情的按真实单位调节，没有的按百分比调节，实时看到利润、每股收益与中性价的变化。
4. 估值建立在利润解释上：三档目标价 = 三组关键变量取值下的利润 × 按行业与周期位置给出的倍数。

- 页面每节平铺全部 fieldIds 为指标卡，每卡带期间与出处胶囊；正文禁数字，回答句写不出「毛利率却有 54%」。
- 数据包已有：收入、成本、毛利率、归母净利、现金流、资本开支、单季镜头、股本、预测每股收益与情景三档。行业驱动（电量、电价、销量、单位成本）多为缺口。

## 3. 冻结决定

R1 **句中数字槽**：研究文字可写 `{field_id}` 或 `{calc:<result_id>.<key>}` 占位，页面按字段或计算凭据填入并悬停显示期间与出处；占位以外仍禁阿拉伯数字（窗口与日期字段除外，同 T7.2b）。无效占位按 T7.2b R1 剔除并给 warning。
R2 **问题标题**按 design.md 表；研究 JSON 不改六节键名，`summary` 即回答句（≤80 字，含占位）。页面把 `profit_formula` 与 `variables` 合为一节「关键变量动一下，利润变多少」：公式行在上、滑块在下，页面共五节。
R3 **派生数由 Backend 算**：数据包新增两个镜头——年内累计同比（单季合计对上年同期，收入与归母净利）、资本开支后现金（经营现金流 − 资本开支，标明未扣分红）。不另做其他精度工作。
R4 **敏感性 = 每单位利润系数（修订一）**：`calculate_metrics` 运算 `sensitivity` 由模型给「拆段 + 变量 + 原话 + 三档 + 倍数」，Backend 取数并计算，一次产出 sensitivity 与 scenario_price 两份凭据。完整请求见过程记录「2026-10-13 修订一」。
  - **系数来源顺序**：公司披露的敏感性（`disclosed`，引原话）→ 模板 + 财报参数 → 模板 + 默认值（标「待校准」）。同一变量既有披露又能用模板算时，用披露值，模板值作对照，相差超过 30% 时给 warning。
  - **三个经营模板**：①单位经济型 `unit_economics`（产品价、原料价或单位成本、量）、②收入利润率型 `revenue_margin`（量%、价%、毛利率 pp）、③规模费率型 `scale_rate`（规模%、费率 bp）。本轮只实现①与 `disclosed`。
  - **账面重估**：汇率、利率等披露系数标 `revaluation`，一次性、不年化，页面单列，不计入三档利润。
  - **取数**：段收入与成本取 provider 主营构成（东方财富 F10 `zygcfx`，按产品或按地区，由请求 `split` 指定），最近一期并年化；有行情编号的变量由 Backend 取当前值与基数期间均价，按真实单位给系数；没有行情的变量按 1% 给系数；利润基数、股本、现价、归母比例取数据包。
  - 变量编号沿用：行情类用目录编号（如 `cmdty:SHFE.AL`），公司自有用 `<代码>:<键>`。
  - **宽松核对**：原话（去空白）能在该文档解析文本中找到且含所给数值记「已核对」，否则记假设并给 warning，不拒收。缺税率用 25%（假设），归母比例在亏损或无法计算时用 1 并给 warning。
R5 **研究 JSON 新增** `sensitivity: {resultRef, drivers: [{key, name, quote}]}`；`quote` 为公司原文的利润变动原因一句（≤80 字，可带数字，原样引用，需 `document_number` 可回读）。缺失或计算失败时该节用单季柱图兜底。
R8 **对话写回变量**：按 Checklist 已确认规则——普通对话讨论出关键变量或取值后，经窄工具 `update_company_drivers` 自动写回该公司的 `sensitivity`（来源标「对话确认」+ 日期 + 会话），Backend 重算系数与三档；页面变化处悬停提示来源对话，可撤回（恢复上一版），并在动态留一条记录。
R9 **估值三档来自利润解释**：有敏感性时（修订一起由 Backend 随 sensitivity 一次生成 scenario_price），悲观、中性、乐观各是一组变量取值（模型说明依据，如期货曲线、周期低点与中枢），利润 = 基数 + Σ 系数 × 变动，每股收益 = 利润 ÷ 股本，倍数按行业与周期位置给出（周期高点利润配低倍数，写一句理由），由 `scenario_price` 每股模式计算并引用 `sensitivity` 凭据。无模型时沿用 T7.2 做法。
  - **现价隐含变量**：`sensitivity` 同时给出「中性倍数下，现价对应的主变量取值」（线性反解），估值节回答句写「现价相当于市场在赌铝价约 X 元/吨」。
R6 **跟踪卡状态由页面判断**：当前值对阈值，未越线「更稳」，越线未到窗口「打折扣」，越线且窗口已过「不成立」。SOP 加一句：警戒线设在当前值之外，已越线的写进回答句。
R7 **页首**：thesis + 五档结论 + 判断变化行（无变化写「研究于某日，资料未变化」）。
