## 1. 目标

一份可点击的静态原型，让用户比较并拍板动态与跟踪页的新结构。

## 2. 现状（Claude 核实）

- 动态页顶部「行情 / 资讯」两个标签；「行情」下先是财报对账卡（新季报，按钮：展开、看公司），后是价格变动卡（按钮：展开、看公司、讨论）。
- 跟踪页上半「正在盯的」（研究自动带出的价格与指标，可「显示另外 N 项」），下半「研究」（各公司研究进度与结果）。
- 关注页列表已有每家公司的状态点与「资料截至」。
- 视觉规范见 `docs/design.md`；现有页面截图可从 5930 取（用户在用，只读）。

## 3. 冻结决定（Claude 推荐方案，原型按此做，备选写在页脚）

P1 动态：去掉「行情 / 资讯」标签，一条按时间的流；每张卡统一结构：类型小标签（财报 / 价格 / 公告）→ 一句发生了什么 → 碰到哪家公司、哪个判断 → 影响一句话 → 按钮「看公司」「讨论」（展开收进卡片点击）。
P2 跟踪：只留「正在盯」；每项标来源（研究带出 / 你加的）；每项可「不再盯」（只停提醒，不改研究模型）；顶部「添加」可搜价格或指标；说明对话里也能点「开始观察」。
P3 研究进度移到关注页：列表行内显示进行中步骤或「有新资料 · 重新研究」，不在跟踪页。
P4 页脚列出备选：保留两个标签但改名为「财报」「价格」；研究进度留在跟踪页底部折叠。
P5 数据用真实快照（8700 只读：tracking/variables、quarter-reconciliation、feed）写死在 HTML 里，不调用接口；不出现内部词。
