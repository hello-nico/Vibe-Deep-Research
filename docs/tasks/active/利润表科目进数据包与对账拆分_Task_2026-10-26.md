## 3. 冻结决定

L1 在**现有** provider 的同一张利润表里补映射：资产减值损失、信用减值损失、销售费用、管理费用、研发费用、财务费用、投资收益、所得税费用、少数股东损益、营业利润（校验用）。先用华友、紫金、神火真实回包核对列名与口径；某 provider 没有的列就缺口，不猜、不接新源。
L2 进 `provider_snapshots` 与 `lenses.single_quarters`：单季 = 同来源累计值相减，与归母单季同口径；两源冲突照现有冲突规则处理。
L3 对账服务与卡片按原 Task S2–S4 实施（科目变化按对归母影响方向列示；少数股东单列；剩余叫「其余（量、价差与成本等）」；注明价格影响与减值可能部分重叠；结论句先说最大一项；`ui_wording` 通过；同步 `docs/design.md`）。
L4 校验：华友 Q3 单季资产减值应约 −9.88 亿元（1–9 月 12.96 − 上半年 3.07，来自对话读原表）；对不上就停下报告。
