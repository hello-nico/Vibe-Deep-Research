## 3. 冻结决定

V1. 视觉按[协议](../../design.md) §1–§5 落地。令牌写进 `index.css` 亮暗两套：墨色、外框、内容区、卡片四个基础值，其余按协议比例用 `color-mix` 派生；原 hsl 变量改为映射到新令牌，`.glass` 去掉渐变、阴影和模糊。与协议冲突时以协议为准；协议需要改，先在交接里提出，不在代码里另立规则。
V2. 公共组件放 `desktop/src/verticals/finance/components/ui/`：`ObjectCard`（三行骨架）、`GroupCard`（组名在外、一行一项）、`Panel`、`Metric`、`StatusDot` / `StatusPill`、按钮变体（主、次、文字、图标）、表格容器样式。页面改用这些组件，删掉页面私有的卡片与按钮样式。
V3. 外壳：左侧图标栏（图标加两字标签）放在外框上；右侧内容区为近白大圆角面。页首只保留标题与右侧动作，删掉面包屑与「VIBE FINANCE / WORKSPACE」；「问助手」改为页首右侧的次要胶囊按钮，功能不变。免责声明改为页尾一行灰字，只在研究类页面出现。
N1. 六个入口与路由：
- 对话 `/`：现深度对话。
- 动态 `/feed`：过渡页，分段「资讯」「市场」承载现有资讯雷达与大盘行情内容，只换外壳与样式，不改数据逻辑（T8b 换成结论流）。
- 洞悉 `/insights`：过渡页，承载现有「我的研究」内容（议题、证据墙、待确认项），只换外壳与样式（T8b 替换）。议题页改为 `/insights/topics/:topicHex`。
- 关注 `/watch`：见 N2。个股页为 `/watch/:symbol`，内容沿用 `CompanyPage`。
- 资料 `/my-reports`；设置 `/settings`。
N2. 关注：自选与研究名单合并为一张表（协议「表格」）加卡片视图（协议「对象卡 · 个股」）。「添加关注」同时加入自选与研究名单；「移出关注」在「⋯」里，两处都移除，只动 Client 选择，不删 Backend 知识。不因关注启动研究，首次打开个股页触发研究的规则不变。
N3. 旧路由重定向：`/watchlist`、`/research` → `/watch`；`/research?company=<slug>` → `/watch/<symbol>`；`/daily-review` → `/feed?tab=market`；`/intel`、`/intel/:tab` → `/feed?tab=intel`；`/my-research` → `/insights`；`/my-research/topics/:topicHex` → `/insights/topics/:topicHex`。
- 行业研究 `/sectors`、产业研究 `/sectors/profiles` 与 `/signals` 从导航撤下，路由保留（个股页行业链接仍可进入），页面同样换新样式。
N4. 卡片数据：个股卡走势线用现有行情接口能批量取到的收盘序列；取不到就留出这一行的位置，不新增 Backend 接口。行业卡用关注名单里本行公司数、`/industries/profiles` 画像状态与更新时间。
N5. 深度对话与 DSH 面板只改我们自己的外层容器与令牌映射，不用 CSS 覆盖 DSH 内部结构。
