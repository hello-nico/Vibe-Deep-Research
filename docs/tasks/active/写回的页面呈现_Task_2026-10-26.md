## 1. 目标

对话里写回的东西在页面上看得见、说得清来源、能撤回：个股页改动处标「来自 M-DD 的对话」、动态里有一条写回记录卡、候选因素可以纳入 / 排除 / 观察。

## 2. 现状（Claude 核实，后端均已合入 Stock 主目录）

- 写回记录：`GET /api/v1/feed/research-events?symbols=`；pi3 正在补 `grade_before`、`grade_after`、`research_version`、`summary`（[写回记录带档位变化](写回记录带档位变化_Task_2026-10-26.md)，未就绪时按其 E1 字段用夹具）。
- 撤回：`POST /api/v1/wiki/companies/{symbol}/page-research/revert`（只能退一版）。
- 候选因素：`GET/POST /{symbol}/driver-candidates`、`PATCH /{symbol}/driver-candidates/{id}`（候选 / 纳入 / 排除 / 观察；「纳入」只标待研究，不自动跑研究）。
- page-research：sensitivity drivers 带 `origin: conversation`、`sessionId`、`confirmedAt`；论点 / 支柱写回带来源会话；`changedFrom` 已有。
- 动态小点（`lib/feedAttention.ts`）已把「对话写回导致档位变化」算作判断变化，但动态里还没有对应卡片。

## 3. 冻结决定

W1 动态写回记录卡（类型「对话」）：第一句 summary；档位变了写「估值从 A 变为 B」并置顶、底行加「判断变化 · 」（与财报卡同规则，使小点与卡片一一对应）；底行按钮「看公司」「打开对话」「撤回」（撤回只对该公司最新一次写回可用，其余显示灰字「已有更新的版本」）。
W2 个股页：来自对话的变量取值、论点或支柱旁一行灰字「来自 M-DD 的对话」，可点开回到该对话；页首判断变化提示里写「因 M-DD 对话调整」。
W3 候选因素：个股页「接下来盯什么」之后一组「对话里提到的因素」，每项一句为什么，三个胶囊「纳入」「排除」「观察」；纳入后显示「已纳入，下次研究会算进模型」并给「重新研究」；排除需一句理由（输入框，可空），之后不再显示；观察转成跟踪页观察项（调用现有开始观察能力，执行方核实最小路径）。
W4 Vibe `desktop/dsh/finance-ui/research.mjs` 放行上述接口（只加缺的）。
W5 用词按 design.md 与 ui_wording；不出现「写回」「候选」「driver」等内部词，界面说「对话里调整」「对话里提到的因素」。同步 design.md。

4. 与规格的偏差及理由：
- 「观察」：规格要转成跟踪页观察项。Backend 建观察项需要三组判断条件（加强、削弱、推翻）和校验过的依据引用，候选因素里没有这些，页面不能凭空编；所以只把状态标为观察，显示「已标为观察」，建跟踪项仍走对话里的「开始观察」。
- 「排除」理由：规格说可空，Backend 强制必填，所以不填时记「暂不需要」。
- 论点、支柱的来源只能取研究读口的 `changedFrom`（最近一次对话调整）与各节的 `changes`，没有逐条的来源；所以按「该节有变化且最近一次调整来自对话」标注，不是逐句溯源。
- 个股页「重新研究」复用本页已有的入口；打开对话用宿主已有的 `openSession`。
