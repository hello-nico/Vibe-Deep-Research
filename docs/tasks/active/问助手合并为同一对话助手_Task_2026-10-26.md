# 问助手合并为同一个对话助手（Vibe 前端）

2026-10-26 claude 写定，交 claude2。Vibe worktree `.worktrees/claude2-assistant`（git worktree add --detach，基于 HEAD bcf19003）；不提交、不重启、不读凭据。依据：Checklist 2026-10-14「问助手就是右侧面板里的同一个助手」、2026-10-26「对话写回与闭环收口」；[关联现状](../../decisions/proposed/对话个股页产业链关联现状_2026-10-26.md)。

## 1. 目标

个股页问助手、动态卡「讨论」与主对话是同一个助手：同一套提示词与写回能力，带着当前对象与页面快照。

## 2. 现状（Claude 核实）

- `desktop/src/verticals/finance/assistant/binding.ts`：个股页与 `feed:variables` 绑定 `company_wiki` 角色（Stock `consumers.mjs` COMPANY_PROMPT + ASK/AGENT_PROMPT，旧英文提示词，不能写回、不能推荐开始观察），有 ask / agent 两模式；产业链页 `chain:` 无绑定（「本页没有问助手」）。
- 主对话为 `deep_research` 角色（DEEP_PROMPT，可 `update_company_drivers`、推荐开始观察）。
- 页面快照现靠模型先调 `read_page_context`。

## 3. 冻结决定

A1 个股页、动态「讨论」改为使用 `deep_research` 角色，绑定当前公司（boundTarget 或等价机制）；去掉 ask / agent 模式切换（10-14 已定）。
A2 页面快照由宿主每轮随用户消息注入，不再要求模型先调 `read_page_context`（1017 不可靠）。
A3 个股页面板保留本对象的继续研究、重新研究与撤回入口（10-14）。
A4 产业链页暂不接（按 10-20 顺序后做），保持现状。
A5 若需要 Stock 侧改动（例如 deep_research 支持绑定公司、注入快照的消息格式），**停下**，在 §9 写清需要什么接口，由 Claude 派 pi 做；不在本 Task 改 Stock。

## 4. 范围

Vibe `desktop/src/verticals/finance/assistant/\*`、`components/ui/FinanceAiDock.tsx`、相关页面与测试、`docs/design.md`。
