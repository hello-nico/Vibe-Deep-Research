### 度量定义、限制和人工评分

解析器接受类 JSX 引号/裸字符串属性，不执行 JS；表达式、重复属性、错配/未闭合单独失败。可解析比例为已闭合且语法合法的开标签数 / 全部开标签数；未知组件与属性另计（不把语法可解析冒充受支持）。分母为空返回 null，不假造 100%。

数字度量扫描属性中的阿拉伯数字（含小数、符号、百分比、科学记数形式）；合法 ref 里的年份/哈希当标识，不计数。`grid cols=2` 按 C2 总规则仍计为字面数字，没有擅自加入布局数值豁免。step 可以附 ref（承接 C2 数字须带 ref），数字步骤无 ref 另报违规。中文数词、单位语义、属性里的自然语言与合法枚举适配还未用真实样例检验。

块外字数采用去空白的 Unicode 字符数，排除所有围栏块；未去 Markdown 标点或引用链接，因此不是浏览器渲染后的可见字数。正文完整只证明最后 assistant/message 在最后一步、之后无工具调用、块外有文字、围栏闭合、turn/end=completed、未 interrupted；不能判断正文内容是否充分，或真正 UI 是否折叠。

工具日志只投影 preset、request/header 的 provider/model、tool/call 名称和步骤、assistant/message 的 text/usage、assistant/attempt 的 usage、turn/step 结构字段。不读 system/user 文本、推理、工具参数/结果/meta。只解析清单指定的新会话日志，不遍历历史目录。压缩日志沿既有脚本 zstd 子进程规则，解压错误闭合失败。

引用按出现次数作分母、按去重后请求：成果 GET `/research-results/{id}`，验证 result_id 与 payload；其余 POST `/wiki/refs/resolve`，只取 status=resolved，不输出原证据。Task 的 `/refs/resolve` 在现行 Backend 实际带 `/wiki` 前缀。只允许本机无认证 HTTP 地址，不读 token，不允许跳转。该路由契约经源码核对和 mock HTTP 测试，尚无真实 ref 可回读，未调用实际 Backend。
