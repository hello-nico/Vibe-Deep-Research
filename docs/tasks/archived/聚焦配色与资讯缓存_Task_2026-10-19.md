## 3. 冻结决定

R1 先改 `docs/design.md`：写明「聚焦不用品牌色。文本输入（input、textarea、select）聚焦只靠自身描边或阴影变化（描边升到墨色 20%），不加外框；按钮与链接仅键盘聚焦（`:focus-visible`）显示 2px 墨色 20% 外框」。再改 `index.css:149` 的全局规则为上述两条，删除品牌色；问助手输入框聚焦时阴影略加深即可，不加外框。全仓搜 `--brand` / `--primary` 用于 focus、ring 的位置一并改为中性（不改按钮填充色、链接色、进度条等非聚焦用途）。
R2 资讯缓存只做在前端：`lib/api.ts` 内模块级内存缓存，键为「接口 + 规范化代码列表 + limit」，30 分钟有效；`feedItems` 先查缓存。`api.news` / `api.announcements` 增加 `{ force?: boolean }` 选项，页内「刷新」按钮传 `force: true` 并覆盖缓存。失败结果不缓存。页面显示「更新于 HH:MM」（取缓存写入时刻）。不改 Backend。
R3 C 段只读诊断：找出该次研究的任务记录（Backend 任务记录接口或插件任务存储），给出 `settlement_reason` 原文与触发路径（代码行），判断属于预期跳过（例如无新资料需整理）还是失败；不改代码。
