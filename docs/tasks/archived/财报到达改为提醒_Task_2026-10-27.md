## 1. 目标

删除财报到达自动重研；新一期财务数据到了、研究还停在旧一期时，只提醒，用户点了才研究。

## 2. 现状（Claude 核实）

- 自动重研：`desktop/dsh/finance-ui/report-arrival.mjs`（定时检查、补跑、startRun），在 `host-state.mjs:8`、`:1180-1183` 挂载；codex1 今天已把判断改为读 `/market/report-periods`。

- 个股页已有「有新资料 · 重新研究」提示（研究过期只看会改数字的资料）。

## 3. 冻结决定

D1 删除：`report-arrival.mjs` 的定时检查、补跑与自动启动研究，及 host 中的挂载、相关环境变量与测试。不留开关。
D2 「有新报告」判断唯一来源：`/market/report-periods` 的最新一期 rank > 研究所用 `report_period`。个股页页首与动态财报卡都读同一个判断（host 或 lib 一处实现，两处调用）。
D3 动态财报卡：未重研时写「三季报已出」（按实际期名）并带「重新研究」按钮，不解释研究用的是哪一期（原写法：「三季报已出，研究还按半年报」，2026-10-27 按用户文案要求修订）；用户点了之后，进度与结论照现有显示（含「判断变化」置顶）。导航小点：有未看的「新报告待重研」或「判断变化」时亮。
D4 个股页页首：同一判断为真时提示「三季报已出 · 重新研究」（按实际期名），与现有「有新资料」合并为一处，不并列两条。
D5 新增公司首次研究的自动开始不在本 Task 范围，保持现状。
