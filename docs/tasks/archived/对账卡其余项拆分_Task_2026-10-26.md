# 对账卡「其余」拆成报表科目（确定性）

2026-10-26 claude 写定，交 claude2。Stock 与 Vibe 各开 `.worktrees/claude2-reconsplit`；主目录冻结；不提交、不重启、不读凭据、不触发研究。依据：[华友三季报对照](../../decisions/proposed/华友三季报_专业分析对照_2026-10-26.md) 方向 A 与 D 实验问 1。

## 1. 目标

对账卡不再只写「其余 −1.15 亿元来自量和成本等」，而是把能从利润表直接算出的科目列出来（如资产减值、信用减值、期间费用、投资收益、所得税），剩下的才叫「其余」。

## 2. 现状（Claude 核实）

- `GET /api/v1/wiki/companies/{symbol}/quarter-reconciliation`（Stock `backend/app/api/v1/quarter_reconciliation.py`）：环比 = 本季单季归母 − 上季；价格解释 = Σ 系数 × 均价变动 ÷ 4；`rest` 为差额。
- 华友 Q3：环比 −2.07 亿，价格 −0.92 亿，rest −1.15 亿。对话从三季报与半年报原表算出 Q3 单季资产减值 −9.88 亿元（1–9 月 12.96 − 上半年 3.07）等，说明这些科目可由累计值相减得到。

## 3. 冻结决定

S1 先核实：数据包 / provider 是否已有利润表科目累计值（资产减值损失、信用减值损失、销售/管理/研发/财务费用、投资收益、所得税、少数股东损益）。有则用；**没有就停下**，§9 写清缺哪些、哪个 provider 可能有，不自行接新源。
S2 单季值 = 同来源累计值相减（与现有归母单季同口径）；按「本季 − 上季」给出各科目变化，按对归母影响方向列示；剩余 = 环比 − 价格解释 − 已列科目，仍叫「其余（量、价差与成本等）」。少数股东影响按其单季变化单列。
S3 卡片文案：先一句结论（最大的一项），展开后逐项；不新增内部用语，`ui_wording` 通过；同步 `docs/design.md`。
S4 价格解释与科目之间可能重叠（价格下跌引起的存货减值）：卡片注明「价格影响与减值可能部分重叠」，不做去重。
