# 估值引擎误差来源诊断 log

## Claude 审阅（2026-10-20，claude）

- 结论：通过。31 季对照、5 组毛利桥、扣非恒等式均有原件证据；未调参。
- 判定：一次性损益不是主因（神火、云铝、紫金扣非后误差不降）；价格系数错误无法单独识别。主要缺口是销量、产品结构与单位成本（含耗用、品位、电价等非价格部分），季度数据大多不披露。
- 含义：「价格 × 系数」只能解释利润里价格那一份，不能当季度利润预测器。校准按讨论记录 §4 做成「实际 vs 按价格推算的差额，差额里价格能解释多少，其余写量与成本等、报告未披露」，不做误差判优或自动改系数。
- 可补数据：神火煤炭实际吨售价与销量（半年报可得），值得接入替代焦煤代理；其余公司量价桥先不做。
