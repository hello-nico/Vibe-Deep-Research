# M1 · 首页与盘面取舍

日期：2026-09-08。范围：本地界面与导航；本地已实现本轮源码改动，未提交、未推送、未发布。
先做功能和界面，不改研究方法或后端引擎。本文件是本轮工作记录。

## 用户决定

- 首页保留上方 chat，去掉「研究工具，一站直达」。
- 「每日复盘」改成「大盘行情」。截图圈掉的三块去掉：顶部数据块状态条、关注股票、Agent 当日复盘。大盘指数、全球市场及未圈掉的盘面数据保留。关注股票不放在本页，自选只走侧栏「自选股」。
- 「多空辩论」「回测」模块从产品面去掉。
- 本轮不重排其余侧栏顺序，不改 `/daily-review` 路径。截图「放到上面去」按「自选入口只留自选股页」理解，不是把自选股菜单上移。
- 产品对外名称改为 Vibe Finance；「本地金融研究工作台」去掉「本地」，改为「金融研究工作台」。不改配置文件名、数据目录和安装包可执行文件名。
- 大盘行情去掉顶部「业务日」条。各块标题共用同一套 section head：说明在左，时间统一为「更新于」并靠右。全球市场文案改为「非实时行情」，卡片内不再逐条写取数时间。

## 行为与边界

- 首页只留 `FinanceHomeAgent` 与页脚免责声明，不再渲染功能分类网格。
- 侧栏「每日复盘」改为「大盘行情」，仍进入 `/daily-review`。页面标题与副标题不再写交给 Agent 做复盘。
- 大盘行情页不再提供本页加自选、不再提供「让 Agent 复盘今天」。资讯页若仍写「到每日复盘加自选」，改为指向自选股。
- 侧栏、可达路由和首页快捷入口不再出现多空辩论、回测。旧地址 `/debate`、`/backtest` 跳转首页，不在本轮删除页面文件或后端实现。
- 红涨绿跌、指数取数、未圈掉的情绪 / 成交 / 板块资金块保持原行为。
- 界面、README、官网、Agent 文案中的 Vibe Research 改为 Vibe Finance。`vibe-research.config.json`、`.vibe-research-root`、`~/.vibe-research-desktop` 和 `VibeResearch.app` 可执行名本轮不动。
