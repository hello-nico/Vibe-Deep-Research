三个接口带现用 `/api/v1` 前缀：

```text
POST /api/v1/wiki/companies/{symbol}/coverage/ensure
GET  /api/v1/wiki/companies/{symbol}/coverage?as_of=2026-10-10
GET  /api/v1/wiki/companies/{symbol}/data-packet?as_of=2026-10-10
```

coverage 返回 `symbol / as_of / items / diagnostics / period_policy`；每项含 `period / report_type / status / reason`，有原件时含 `document_ids`，排队时含 `job_id`。只在 ensure 调用时补件；读取不恢复任务、不写入。2026-10-10 所需期间为 FY2025、2026H1、2026Q1、2025Q3（独立 Q1/Q3 报告；中报另外列出）。按法定披露截止日选择，不能证明某家公司提前披露的最新期。

data-packet 返回 `symbol / as_of / financial_period / identity / fields / readings / industry_drivers / lenses / diagnostics / sources`。fields 每格含 `field_id / metric / value / unit / period / scope / ref / page / status`；gap 含 reason。原件值附版本、全文 hash、块编号、原行列；派生值 ref/page 为 null，附实际 `input_field_ids / inputs / formula`，可沿输入回到原件。readings 保留原年度与比较期，不以重述比较列覆盖原年度；股本优先最新中报期末普通股数，年度原值仍在 readings。

读取仅使用已保存且 hash 校验的报告、provider 快照和成果。保存成果的 `adjustment=none`、收盘类型、交易日及每股人民币单位同时满足才接纳现价；前复权序列拒绝作为现价。不会在 GET 中调用写入快照的 provider helper，也不调用模型。

### 金标、陷阱与 §7 停止项

T7-G 的全部 71 个 found 格子参数化回归；输出必须一致或 gap，mismatch 使测试失败。固定原文与真实读取分别得到 **39 consistent、32 gap、0 mismatch**；一致率为 39/71（54.9%），不能把 32 gap 写成通过取数。比较按单位归一，保留原证据精度；数据包 readings 中的指定期间值参与比较，顶层 shares 使用较新的 H1，不能和 FY2025 金标直接错比。

三类陷阱各有专门测试：2.20 元/10股 → 0.22 元/股；含利息的“分配股利、利润或偿付利息”行不认作实付分红；原年度与后来比较期重述值分列、原值不被覆盖。另有季度表不能污染年度行、银行集团/本行重复列、银行 Capex 断行、现价复权轴、估值偏差与计算失效域测试。

第一次金标运行 2 failed / 75 passed：华能蒙电 FY2025/FY2024 售电量误从低精度叙述提取。一次有效修复恢复 FY2024 精确表格列，仍有 FY2025 的舍入值 540.76 亿千瓦时无法匹配金标 54,076,472,600 千瓦时。按 §7 停 FY2025 power_sales，年度舍入叙述不再作为该字段输出；未继续多轮逼规则通过。FY2024 精确表仍保留。FY2025 行保持 gap，不写入事实、不修改金标。

累计转单季代码已具备同期间、同单位、同边界和显式 `accounting_basis` 校验；真实报告读取尚未恢复能证明同会计口径的成对输入，所以本轮真实单季均 gap，成功减法只有夹具证据。五年历史收益/净资产及不复权价格轴未齐，按 §7 估值分位返回 gap；未将今日 EPS 向历史投射。
