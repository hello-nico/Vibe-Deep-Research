## 3. 冻结决定

K1. **行情观察存成果**：`observe_market` 每个尺度的结果保存为不可修改的行情成果（沿用现有成果链与 `operation_id` 幂等，不自动出图），返回与 `generate_market_result` 相同的摘要加成果引用；需要图时用成果引用生成或嵌入，不再重复取数。工具描述写明"要出图直接用 generate_market_result，不必先观察"。凡挂 `observe_market` 的角色同时挂 `read_research_result`。
K2. **目录紧凑**：`source_get_index` 默认返回一、二级标题树，块 ID 去掉同一文档重复的解析版本前缀（返回一次前缀与短 ID，工具入参同时接受短 ID 与完整 ID）；更深层级按标题展开。原文与块身份不变。
K3. **公司页按节**：`wiki_read` 默认返回页面目录、研究块与关键事实摘要（每项含引用）；增加按节读取参数取完整系统块。准入、哈希与版本校验不变。
K4. **事实优先**：工具描述与 `DEEP_PROMPT` 中写明顺序：先用已准入事实与已保存成果（带证据引用，可回原文），缺少所需数值或需要上下文措辞时再读原文段落。不改变"数字回到证据"的规则。
K5. **少一步报错**：`source_read_blocks` 可直接接受 `source_scan_sections` 返回的标题块 ID，由服务端换算段落范围；越界时报错信息列出本轮可读范围。
K7. **外部网页正文**：`fetch_source_url` 提取正文时去掉导航、页脚、版权、推荐链接等网页杂项，并设长度上限（超出部分按段落截断，返回已读范围与续读方式）；保留下来的正文逐字不改，快照与哈希规则不变。
K6. 原文段落本身（`source_read_blocks` 返回的正文、表格）不截断、不改写。
