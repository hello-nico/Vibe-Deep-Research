# 聚焦配色与资讯缓存 · 过程记录

## Claude 审阅与补修（2026-10-19）

- 用户验收：合入后问助手输入框聚焦仍是橙框。Claude 在 5930 实测计算样式：`outline: rgb(228,88,33) solid 2px`。
- 根因：Tailwind `.outline-none` 给出 `outline: transparent solid 2px`，DSH 注入的全局 `:focus-visible { outline-color: var(--dsw-focus-ring-color, <品牌橙>) }` 为其上色；我们未设该令牌，且自家规则用 `:where()`（优先级 0）压不过。claude2 只改了自家规则，未在运行页核对计算样式。
- 补修（Claude，`desktop/src/index.css`）：主题令牌 `--dsw-focus-ring-color: var(--line-3)`（DSH 扩展点，DSH 自带控件聚焦一并中性）；文本输入 `:focus-visible { outline: none }` 去掉 `:where()`。
- 复核：5930 实测输入框 `outline-style: none`，按钮键盘聚焦为 2px 墨色 20%；元素截图无橙框。npm test 475 通过仅 #34。
- 教训：界面修复必须在运行页读计算样式或截图确认后再交用户验收，测试与源码断言不能证明视觉。
