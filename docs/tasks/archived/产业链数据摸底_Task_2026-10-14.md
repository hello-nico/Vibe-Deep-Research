## 1. 目标

回答一个问题：原型第 04 屏每一节要的数据，用现有数据源能拿到多少，频率和年限各是多少。结果决定产业链页现在做，还是先补 T18 长周期行业数据。

## 2. 样本

两条链：电解铝（铝土矿 → 氧化铝 → 电解铝 → 铝加工）、火电（动力煤 → 发电 → 售电）。

## 3. 要查的数据（按原型各节）

| 节 | 数据项（电解铝 / 火电） |
|---|---|
| 利润在哪个环节 | 各环节价格或成本：铝土矿进口价、氧化铝价、电解铝价、铝加工费；动力煤价、上网电价、售电价差。能否算出各环节吨（度）利润 |
| 利润公式 | 电解铝：氧化铝单耗、吨铝电耗、阳极与人工成本；火电：度电煤耗、燃料成本占比、容量电价 |
| 周期位置 | 上面吨（度）利润能否回溯 10 年，求分位；不能时最长几年 |
| 高位或底部信号 | 电解铝社会库存（周）、产能与开工率、海外复产；电厂日耗、电厂库存、用电量 |
| 链上公司弹性 | 链上上市公司名单与所属环节；各公司产量或装机（定期报告或 provider） |

## 4. 要查的来源（逐一核实，不臆测）

1. Stock provider：`backend/app/providers/`（`hithink.py`、`industries.py`、`market.py`、`company_segments.py` 等）现有接口能给什么。
2. 外部价格目录：Stock `dsh/src/research-values.mjs` `externalSeriesCatalogText()` 已登记的序列，及其历史长度（经 Backend 行情接口实际取一次看起止日期）。
3. 现有行业数据：`backend/app/services/industry_snapshots.py`、`nbs_industry_sources.py`、`industry_profiles.py`（申万产业研究）里已有的字段。
4. 公开来源：国家统计局、行业协会、交易所公开数据等免费可取的；只记录是否可取、频率、年限、取法，不接入。付费来源（如 SMM、Mysteel）只记名称与是否必需。

调用 Backend 只用只读接口（`http://127.0.0.1:8700/api/v1` 的 GET）。
