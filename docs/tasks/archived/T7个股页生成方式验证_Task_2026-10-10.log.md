### 结论、边界与证据等级

**不成立**：本轮未证明任何一种方式能稳定满足 V1 全部原型效果。华能蒙电最终 A 三次平均 51.00/70，B 三次平均 54.33/70；B 长江电力 50/70；B 华友钴业最后一次模型调用失败、没有成页，计 0。所有最终成页都缺年度经营价格弹性、股息率、三档价格区间与剩余现金，每变量 3–5 期可比趋势也未达标。分数用于定位，不把平均分当作验收门槛。

建议下一轮选择 **B 数据包路线**：代码先取齐并绑定可核对的报告字段、单位、期间与口径，模型负责七节判断、解释与缺口检索。原因是结构更明确、同行 PE 和现金流倍数更完整，且本轮华能步骤由 A 平均 12.67 降至 B 的 2；效果仍不合格，低 token 或快不能替代效果验收。替代路线是在缺计算能力时交付明确缺口的部分研究页，不能声称已达到原型；是否降低原型要求由 Claude/用户决定，本轮没有变更标准。

先读两仓 AGENTS、README、Vibe `docs/task-protocol.md`、本 Task 全文及 T7 实现过程记录末尾「用户首轮真实验收 · Claude 轨迹分析」，按 task-driven-dev 技能执行。Stock 产品代码、上一轮 T7 未提交改动及无关改动未编辑；Vibe desktop 未编辑。仅新增 Stock `artifacts/t7-spike/` 脚本/产出，以及本 Task §9 和本过程记录。无提交、暂存、push、容器操作、迁移、回填写入或工作台重启；未读写或打印凭据。

真实证据：模型通过产品现用 DSH `llm.prepareCall` 配置调用，选择 `deepseek-official / deepseek-flash / high`；Backend 8700 真实只读取数，原文段落逐字保留，公开报告中的数字现场回读。隔离证据：A 使用现有角色提示词/原生工具的 disposable research fixture 和手动工具循环；B 用实验 JSON 结构和两个纯计算原语。暂存仅捕获到文件，未运行产品正式 settlement、持久化或前端展示。本轮不是完整产品生命周期、全量数字核验或视觉验收。

A 的 `wiki_read` 只读 financial/operating/valuation facts；`fetch_company_data` 代理到绑定公司的 provider-snapshot；page-read 保留 basisVersion 但不发送已有研究正文；移除入库、逐项 stage_extraction 与生成新成果的工具，避免正式写入。这会限制同行/报价发现，A 的失败不等于正式产品完全没有数据。A 计算用正式 `adaptPrimitiveRequest` 解包，再以原文跨度检查和 Backend 纯原语执行；没有正式 source axes 校验和可持久回读的 calculation ref。B 的 calculate_packet 仅 multiple/fcf_proxy，工具所接单位/scope 仍由模型申报，未实现可信字段轴绑定；B 得分不代表这些计算已通过正式生产接口。

### 运行批次、修正与停止条件

先做只读资料/会话投影与 V5 重放，再启动独立临时 DSH 调用桥；既有工作台端口 5930/5941 未重启。模型数据包限定为公司公开报告、financial/operating/valuation facts 和 provider，未向模型发送关系、个人研究笔记或已保存研究正文。最初组合创建/联网执行曾被自动审批拒绝，理由是可能外发内部资料；按 Task 已明确授权的数据包范围收窄后重新提交，审批通过，无剩余审批阻塞。拒绝的组合动作没有执行。

试探 v1 错误地设置了 16k 输出上限（实验桥设置，非产品默认）。A1/A3 到上限未成页，A2 error；B1 成页，B2 error，B3 到上限未成页。保留所有输出，不纳入同配置最终比较。移除实验上限，新桥使用产品默认输出限制。v2 A 的实验原语封装解包错误，A1/A2 被中断，A3 已有候选；改为复用正式 adapter 后跑最终 A v3 三次。v2 B 三次华能及两家跨类型探索均有候选，但发现漏选分红段落、legacy 年报及财务段落，且年度期间文字不同被实验检查误拒；修正 collector 与年度期间规范后跑最终 B v4 全五次。

不以此前华友 v2 的成功替换最后一次 v4 失败；不再重试模型来挑成功样本。最终华友第 2 次模型调用返回 `MALFORMED_RESPONSE`，第 1 次已完成，未产出最终 JSON；没有可抽查的最终三个数字，也不能核验该公司的最终效果。已取数与前一次探索 JSON 保留为辅助证据。

修正后 collector：华能 7 份资料 / 695 原文块，华友 10 份 / 605 块，长江 9 份 / 381 块。这些是筛选后的原文块数量，不是报告全部正文或全面字段覆盖。未触发“一半以上 V1 因 Backend 无数据”停止条件：大量缺项属于实验漏取/映射、期间口径与计算契约，不能笼统判成 Backend 无数据；因此完成另外两家公司尝试。未超过一工作日，未遇到需要读取/修改凭据的步骤。
