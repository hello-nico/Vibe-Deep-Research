## 1. 目标

白酒、汽车、家电、CXO 等公司按 volume_pe 给出三档、现价位置、五档基准档、驱动与换档条件；同时建成「同业倍数横截面分位」公共来源，供后续地产、订单模板复用。

## 2. 现状

- Stock `backend/app/services/financial_valuation.py`（bank_pb、insurance_pev，`FINANCIAL_TEMPLATES`、`financial_result`、`calculate_template`）；`backend/app/analysis/dispatch.py` 分派。
- 同业：`company_data_lenses.py` `peer_comparison` 只有中位数与排名，要求数据包里 ≥3 家已核对同行，四家代表全部 gap。
- 东财板块成分接口已在用：`backend/app/providers/industries.py`（push2delay clist）。pi1 用东财横截面取过同业 PE/PB 分位（见地产 eval）。

## 3. 冻结决定

V1 同业倍数横截面：新 provider 按申万二级成分取东财同一快照的 PE（TTM）与 PB，剔除非正值与 PE > 100、PB > 15 的离群值；有效样本 ≥ 5 家才给 P25/P50/P75，否则返回缺口「同业样本不足」；结果带样本数、剔除数、快照时间与成分来源；按日缓存。等级为 sourced。
V2 volume_pe：利润基数 = 近 12 个月扣非归母净利润（报告期与个股页 page_period 一致）；三档价 = 基数 × 同业 PE 的 P25 / P50 / P75 ÷ 股本；不用「当前 PE × 系数」。
V3 驱动：从所属二级 Profile 与年报读数取量、价（或单价）、毛利率三类，给出方向与敏感度（毛利率每变 1 个百分点对中性价的影响；量或价每变 10% 对中性价的影响）；读数缺的写缺口不估。换档条件 = 现价落到档边界时隐含的利润基数（或 PE），可反解。
V4 grade_base、统一结果结构、研究保存校验（最多偏一档）照阶段 B。
V5 模板登记 JSON 与生成脚本由 commit 窗口在另一 Task 统一改，本 Task 不碰 `valuation_templates.json` 与 `generate_valuation_templates.py`，需改的文字写在 §9。dsh `consumers.mjs` 也不碰。
V6 测试夹具：茅台、比亚迪、美的、药明（数值取 eval 与 8700 只读回包），覆盖三档有序、样本不足缺口、换档反解、亏损公司返回缺口。
