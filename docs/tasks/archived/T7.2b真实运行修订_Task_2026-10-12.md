## 3. 冻结决定

R1 **拒收只留危险项**：公司不一致、六节/支柱结构缺失、正文（thesis、summary、details、pillar、falsifier.text、basis、conditions）含数字或动作词、fieldIds 全部无效、scenarioRef 无法回读。
  其余照存：无效的单个 fieldId/calculationRef 剔除；阈值单位不符时剔除该阈值。被剔除项写入响应 `warnings[{path, reason}]`，保存仍算成功。
R2 **观察窗口**：`falsifiers.*.window` 与 catalysts 日期字段允许数字（日期、报告期），仍禁动作词。
R3 **阈值两类**：`threshold = {kind, value, unit}`，`kind` 取 `level`（单位须与字段一致）或 `yoy_pct`（单位固定 `%`，指同比变化）。缺 kind 按 level。
R4 **引用只认 field_id**：sections、pillars、falsifiers 只收 field_id；收到 `source_ref` 形态时 warning 写「此处只填 field_id」。精简视图保留 source_ref（裁定 4 不变）。
R5 **数据包缓存**：Backend 按 symbol + as_of + 资料版本 + 当日最新快照时点缓存已构建的包（进程内即可），命中直接返回；ensure 或资料变化后失效。目标读包 ≤1 秒。
R6 **先显后补**：页面先显示首读数据包（缺口照常显示），需要补数时后台 ensure，完成后静默刷新；不阻塞首屏。
R7 **评级字样**：关注资料列表及个股页显示第三方研报标题时，去掉评级尾巴（如「；维持买入」「首次覆盖：增持」类片段），原件与链接不变。只改显示。
