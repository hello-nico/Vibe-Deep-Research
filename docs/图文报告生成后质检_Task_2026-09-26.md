## 1. 问题

- 资料时间线等图由报告 Agent 按图库样式自己写 SVG，标签坐标也是它算的。时间点靠近时文字互相压住（用户截图：2026-03 到 2026-09 之间 3 个点的标题和日期重叠）。
- `SKILL.md` §八“交付前自检清单”第 3 条已要求检查“标签会不会重叠”。但 Agent 看不到渲染结果，这条自检等于没做。
- Backend 保存报告（`backend/app/services/wiki_reports.py` `validate_report_html`）只查非空、大小、引用格式，不看渲染效果和内容是否合理。
- 同日农业银行报告在研究页数据被清空后照常生成，得到“一个读数，八项空白”。数据源问题已另修，但报告层面也没有任何拦截。

## 2. 冻结决定

1. **渲染检查（2026-09-26 用户确认）**：
   - 在 Stock Backend 引入 Playwright + Chromium（约 150MB，仅本机依赖），保存报告前用无头浏览器按 1200px 与 800px 两个宽度渲染 HTML。
   - 不等待入场动画：渲染时模拟“减少动态效果”（`prefers-reduced-motion: reduce`），并注入样式把 `animation`、`transition` 时长设为 0，元素直接落在最终位置；布局稳定后，执行下列检查。关闭动画**只作用于检查用的临时渲染页**：保存的报告 HTML 原样保留，用户查看时的入场动画与特效不受影响（2026-09-26 用户明确要求保留动画）。测试须断言：检查前后报告 HTML 的 sha256 不变。
   - 渲染在隔离页面里进行：禁止网络，只加载报告自身内容。
2. **检查项**（均为确定性规则，不调用模型）：
   - **文字重叠**：可见文字元素（SVG `text`、带文字的 HTML 元素）两两的边界框，交叠面积超过较小者的 30% 即违规。
   - **溢出与截断**：文字超出所在 SVG 的 `viewBox` 或父容器的可见区域。
   - **空图**：图表容器（`.fig` 或 `svg`）里没有画出任何数据元素。
   - **脚本错误**：渲染期间控制台出现报错。
   - **内容空洞**：带引用的数据元素少于 3 个，且正文“待补充”超过 5 处。
3. **退回重做**：
   - 首次保存有违规时，返回 422，`code = report_quality_failed`。明细逐条写出：检查项、元素文字前 40 字、宽度、坐标。
   - `dsh/src/report-tools.mjs` 把明细交回报告 Agent，提示“只修这些位置，不改其余内容”，最多重试 1 次。
   - 第二次仍违规：允许保存，报告记录 `quality_warnings`；前端在报告顶部显示灰色提示“这份报告有 N 处排版待核，可重新生成”。
   - “内容空洞”不走重试，直接拒绝生成，提示“研究页数据不足，先刷新资料或发起公司研究”。
4. **技能说明补规则**（`dsh/resources/lieflat/SKILL.md` §二或 §八）：
   - 时间轴、散点等带标签的图，相邻标签水平间距小于 90px 时，上下交替排布；仍放不下时，把 45 天内的点合并成一个点，标签写“N 份”。
   - 这条是减少退回次数的预防措施，不替代第 1、2 条的检查。
5. 旧报告不回溯检查。深度对话里的图表不在本 Task 内。

## 4. 验收

- **自动**：
  - Backend pytest；Stock DSH `pnpm test`；Vibe `npm test`、typecheck、`node dsh/build-ui.mjs`；`git diff --check`。
  - 夹具测试：
    - 重叠标签被拦下；
    - 间距足够的同一张图能通过；
    - 空 SVG 被拦下；
    - 脚本报错被拦下；
    - 第二次违规时保存并带 `quality_warnings`。
- **回放**：对 `workspace/wiki-reports/` 下现有报告（只读）逐份跑检查，列出每份的违规数。用户截图里那份时间线报告必须检出重叠；抽 3 份用户认为正常的报告，不得误报。结果写 §8。
- **耗时**：单份检查不超过 3 秒（两个宽度合计，含浏览器启动），写入 §8。报告生成总耗时对比改动前后各测 2 份，写入 §8。
- **用户验收**：重新生成一份此前时间线重叠的报告，时间线标签不再重叠；如出现“排版待核”，提示可见。

## 5. Stop Conditions

- 回放中误报超过 1 份：停止，回填误报样例与规则阈值，不自行放宽。
- Chromium 在本机无法无网络启动，或单份检查超过 10 秒：停止，回填。
