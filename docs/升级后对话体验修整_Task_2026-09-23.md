# DSH 升级后对话体验修整

状态：2026-09-23 已实施，待用户视觉验收。Claude Code 规划，Cursor 实施并回填 §8。**执行方只跑自动检查，不做浏览器 / 真实流程测试**，效果由用户验收。不提交、不 push。

权威：[产品对象模型与交互 v1](产品对象模型与交互_v1_2026-09-23.md) §4（界面原则）；[DSH 升级 Task](DSH升级到0.1.7_Task_2026-09-23.md)（0.1.7 已切换，基线 `baseline/dsh-0.1.7-alpha.2`）。

## 1. 问题（用户 2026-09-23 实测）

1. **问助手不能边等边打字、不能打断**：运行中输入框不可用，也没有停止按钮。应与深度对话一致：随时可输入，点「发送」才真正发送，运行中可停止。
2. **问助手过程列表出现重复“执行记录”**：`lib/taskTrajectory.ts:244` 对未识别的事件类型一律生成标题为「执行记录」的步骤；0.1.7 新增的结构类事件（轮次 / 步骤 / 请求头等）因此逐条上屏。
3. **问助手工具名英文**：`web_search` 显示英文，`TOOL_LABELS` 缺该项。
4. **状态文案重复**：`components/TaskTranscript.tsx:150-158` 同时显示「执行中」与「· 生成中」。
5. **深度对话头部“标准模式”标签**：0.1.7 的 Agent 预设标签，产品不需要。
6. **对话引用标签样式变丑**：0.1.7 的引用标签结构变化，产品 `conversation-citations.css` 未对齐，地球图标与标题分两行、灰底大块。

## 2. 冻结决定

- 问助手面板后续（T3）会统一为原生对话视图；本 Task 只做最小修整，不重做面板。
- 不改 DSH 包本体；优先用配置 / slot，其次产品 CSS。不新增补丁，除非无其他办法（届时停下说明）。
- 引用的数据与点击行为不变，只改外观。

## 3. 范围

### A. 问助手输入与打断（`components/ui/FinanceAiDock.tsx` 及其会话调用）

- 运行中输入框保持可编辑；「发送」按钮在运行中改为同位置的「停止」（方形图标 + “停止”），点击调用与深度对话相同的会话中止能力；停止后恢复「发送」。
- 运行中若用户已输入内容：输入框下方显示一行灰字“当前回答结束后可发送”，发送按钮暂不可用（不做插话 / 排队，留给 T3 原生视图）。
- 回车发送、Shift+回车换行保持现有行为。

### B. 过程列表去噪（`lib/taskTrajectory.ts`、`components/TaskTranscript.tsx`）

- 未识别的事件类型**不生成步骤**（不再兜底为「执行记录」）；只展示用户消息、模型输出、工具调用 / 结果、错误与中止。
- `TOOL_LABELS` 补 `web_search: '网页搜索'`，并核对 0.1.7 研究插件实际注册的工具名，缺的中文名一并补上（与深度对话 E 批工具行共用这份映射）。
- 状态行只保留一个状态词：运行中显示「生成中…」，结束显示「已结束」，失败「未完成」；去掉「执行中 · 生成中」叠加。

### C. 去掉「标准模式」

- 先查 0.1.7 `ui-agent-preset` 是否可通过 profile / `cordis.patch.yml` 配置关闭头部预设标签；可以则用配置。否则在 `dsh/native-dsh.css` 用限定于 `#dsh-conversation` 的选择器隐藏该标签（选择器写明对应的 DSH 元素，附注释）。不影响预设本身的功能。

### D. 引用标签外观（`components/conversation-citations.css`）

规格写死：

- 行内单行：图标与标题同一行，`display: inline-flex; align-items: center; gap: 4px; vertical-align: baseline`。
- 尺寸：高 20px，字号 12px，左右内边距 6px，圆角 6px，左右外边距 2px；标题最长 200px，超出省略号。
- 外部来源：图标 12px（地球），背景 `hsl(var(--muted) / .6)`，文字 `muted-foreground`；悬停背景 `muted`、文字 `foreground`。
- 内部依据（研究页、年报等）：文字与图标用主色，背景 `hsl(var(--primary) / .08)`。
- 多个标签之间只保留 4px 间距，不显示“、”分隔；跟在句末时与正文同一行自然换行，不单独占行。
- 暗色与亮色主题都用变量，不写死颜色。

2. **保留原始错误**：`userFacingRuntimeError` 在命中类别或返回兜底时 `console.warn('[runtime-error]', error)` 一次；界面文案不变。
3. **收窄匹配**：鉴权类只保留 `unauthorized|invalid api key|authentication|\b401\b`（去掉宽泛的 `api[_ -]?key`）；中止类只保留 `aborted|cancell?ed`（去掉单独的 `abort`）。
4. **修饰键点击不拦截**：`components/ConversationCitations.tsx` 的 onClick 开头加 `if (event.button !== 0 || event.metaKey || event.ctrlKey || event.shiftKey || event.altKey) return;`，保证 Cmd/Ctrl 点击仍按链接打开新窗口。
5. **去掉哈希类名选择器**：`dsh/native-dsh.css` 删除 `span.SVAs4q_label`、`.cubgiG_seat`、`.cubgiG_menuAnchor`，只用 `[data-slot=…]`。若仅靠 data-slot 盖不住“标准模式”，保留最少的哈希类名并加注释“DSH 升级后需核对”，同时在回填中写明，由 Claude 补进升级检查清单。
