# 契约：问助手（Ask 即答 / Agent 深查）

状态：反映 2026-10 的当前实现；产品即将重构，重构时整体改写，不作为重构的约束。（2026-10-04 从 M9.9 §2–§4 提取，按 T3-b 右侧面板更新）。README 模块表引用它，故补为契约。
上位：[系统职责与数据归属](system-ownership.md)、[研究知识](research-knowledge.md) §2 写入协议。

## 1. 两种模式

| 模式 | 能力 | 写入 |
|---|---|---|
| Ask（默认，即答） | 只用本轮固定的上下文；**只开放一个只读工具 `read_page_context`**（读取宿主暂存的本轮页面快照与 @ 读取结果） | 不写 |
| Agent（深查） | 先用同一份上下文，只补本问的缺口；不默认扩窗口、跨对象、外搜 | 允许，但必须走写入协议；允许写入不等于每次写入 |

全面研究归「我的研究」与「深度对话」，不归问助手。

## 2. 固定上下文（发送时由宿主暂存，模型经 `read_page_context` 读取）

1. **页面快照**：本页已加载并展示的数据，带来源与取数时点（缺则写「未标注」）；不新增请求。是本轮输入，不进证据层，不被后续新数据覆盖。
2. **引用读取**：@ 的有正式身份的对象确定性读取并绑定版本与时点；失败、仅摘要、未解析分别表达。
3. **身份与问题**：本轮引用身份、当前页面、模式、用户问题。

上下文有上限，优先保留与 @ 相关部分，截断处写明。

- 当前资讯/公告列表无 @ 时最多 20 条；大盘快照行业最多 15 条、成交额股票最多 20 条；有 @ 时优先选中条目。Ask 列表不附网页地址，Agent 列表附已有 URL，正文读取仍由宿主完成。见 `desktop/src/verticals/finance/assistant/snapshot.ts:216–221,306–365`。
- 页面取数失败只允许同端点、同对象、同参数的成功快照回退，不新增数据也不改旧取数时点；没有好值则照实失败。`orchestrator/src/service.ts:450–470` 限制回退只在页面查询，不扩到研究与体检。
- 当前大盘页提示显示原快照日期/HH:MM，接口名与 HTTP 原因只留数据用于排查、不上屏；源码见 `pages/dailyReviewStatus.ts`。这与旧 Checklist 要显示失败接口名的描述不同，契约记录现状，重设计归 T8。

## 3. 角色独立

- 问助手与深度对话独立：深度对话没有模式，不承担问助手角色。
- 角色由 Stock `consumers.mjs` 登记表定义，每个角色字面列出自己的工具与提示词，**禁止 spread 其他角色的工具数组**；收到未定义的模式直接报错，不回退。
- 五个助手角色：market、intel、industry_profile、company_wiki、industry_wiki；通用研究纪律不用于页面助手，深度对话/我的研究及其他专用研究任务按下文实际装配区分。
- 未定义助手角色的页面不显示问助手入口（我的资料、资料阅读、首页等）。
- 列表页绑定 Wiki 角色但目标为空时，拒绝全部维护写工具。

### 现行提示词与维护纪律分层

- 产品 persona 提供所有会话共用底线，具体内容以[不变量](invariants.md)为准；Stock `consumers.mjs` 登记角色提示词与工具，不能把提示词当执行授权。
- 页面助手只带页面任务及 Ask / Agent 契约；`native-research-tools.mjs` 组装时移除通用 `stock-research:discipline`。Ask 带固定上下文只读规则；维护规则只在 Agent 模式出现，写入沿正式提案协议。
- 深度对话与我的研究使用研究纪律及各自的任务提示；公司研究有专用任务步骤。报告角色移除通用研究纪律，加载报告纪律、模板目录及绑定底稿，不承担普通对话研究；后台整理使用独立冻结快照与受限工具。
- 深度对话、我的研究与页面角色任务提示词主体为英文；公司专用研究的五步提示当前为中文，对外沿 persona 用自然中文。工具参数和失败语义归工具定义，分析方法按需读取；Pi 的实验纪律独立维护，不作为产品运行时另一条执行链。上述接线见 Stock `consumers.mjs`、`native-research-tools.mjs:189–194`、`research-tools.mjs`。

## 4. 界面

- 问助手在统一右侧面板中打开，面板内是 DSH 原生对话；与议题会话、任务过程共用面板，同一时刻显示一个。
- 输入、发送、停止与引用沿原生对话；过程视图只读，关闭时释放会话引用而不取消执行。尺寸与响应式现状见 [产品界面](product-ui.md)「会话面板的现行接线」。问助手回答可显式保存为 Backend 的 ask 类研究记录，不自动研究或关联议题。
