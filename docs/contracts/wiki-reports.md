# 契约：公司 Wiki 生成与图文报告

状态：反映 2026-10 的当前实现；产品即将重构，重构时整体改写，不作为重构的约束。（2026-10-04 从 M9.5 A、C、E 节与后续决定提取）。
上位：[系统职责与数据归属](system-ownership.md)、[研究知识](research-knowledge.md)。

## 1. 缺页公司的研究入口

- 详情缺页时主操作为「开始研究」：启动以该公司 Wiki 为产出的有界后台任务（公司研究是后台任务，不是深度对话）。
- 开始前核对 Backend 真实缺页；目录读取失败不得误判为不存在。
- 同一公司执行中重复点击回到已有任务；失败可重试；成功只在 Backend 正式可读后显示；已有部分成果保留并说明。
- 普通聊天不强制建 Wiki；本入口由用户主动启动。

## 2. 报告的两层

对话中的独立 `vibe` / `<html title="…">` 块复用报告安全检查、数字核对、CSP/引用桥及 `ReportFrame` 的 `sandbox="allow-scripts"`、`srcDoc`。报告页原有样式、消息校验、尺寸与版本行为保持不变。对话只呈现 Stock 校验事件内的包装 HTML；缺事件或整块拒绝时隐藏图，保留正文；单个回答最多一张。

对话引用限定本轮成功工具结果的集合，provider 和计算 result 使用结构化 value/unit 校验，可换算单位并显示最多两位小数；非唯一标量不当作单一数值。数字直接标注在 data-ref 元素上，不画刻度轴，未绑定文字只允许年份、Q1–Q4 标签。对话只接受静态 HTML/CSS/SVG，拒绝自定义脚本、on*、javascript: 及可生成数字的 CSS content（含变量、属性和计数器）；CSP 仅允许宿主引用/高度桥的脚本哈希。运行时不依赖 Playwright，版式在开发自查和用户验收中核对。宿主按来源窗口过滤高度消息，并按已核对 ref 集合处理引用点击；注入主题色变量，内容高度夹在 80–20,000px。

| 层 | 内容 | 失败时 |
|---|---|---|
| 底稿（确定性模板） | 读取 Wiki 已有内容即可展示，四类各有阅读顺序 | 模型故障时仍可阅读 |
| 生成版（Agent） | 输入固定 Wiki 内容版本、已保存成果与引用映射、该类底稿与所需 skill 片段；输出针对该份内容的交互 HTML | 保留底稿或此前报告，提供重试 |

- 有同内容版本的报告直接复用；显式「重新生成」才重做；同一请求并发合并。
- Wiki 更新后旧报告保留版本标识并提示可更新，不包装为最新（过期只提醒、不失效）。
- 生成只负责表达：不补造事实、不在报告阶段广泛检索、不修改 Wiki 判断、议题或用户记忆。
- 所有数值来自输入数据或确定性计算；图表与精确数据表共用数据。
- 生成后质检（结构、引用、数字核对、渲染）失败则降级并保留记录；结构校验不证明研究判断正确。

## 3. 归属

- DSH 拥有生成执行与模型；Backend 拥有持久报告成果、所依据 Wiki 版本快照与来源绑定；产品只保存选择。
- 报告是有版本的表达成果，不是第二份知识真相；原 Wiki 内容、引用和历史始终可访问。

## 4. 生成 HTML 的隔离

- 在隔离容器中展示，不得访问主页面 DOM、凭据、任意网络或任意导航；依赖用受控本地资源。
- 来源点击经校验后的引用映射交给依据面板；容器消息校验来源窗口、报告身份、动作与参数。
- 图表数据、文本与资料中的指令都不能扩张生成权限。

## 5. 后台执行

- 报告生成是真实 DSH 子 Agent，只暴露报告工具，固定 slug、`input_hash` 与来源快照；不继承无关聊天、不触发知识沉淀、不回灌主线。
- 查看过程用只读任务视图（无输入框），不调用普通 `openSession`，不改当前聊天；关闭面板不取消任务。
- 报告会话不出现在最近对话与历史中（按正式任务绑定识别，不靠标题匹配）。
- 重试是有独立记录的新尝试，保留旧轨迹与成果。

## 6. 验收层级

- 缺页→开始研究→Backend 可回读：`ui-journey-smoke`。
- 报告复用、版本提示、隔离：`integration-probe`；视觉由用户 `manual-acceptance`。
