# 不变量

状态：2026-10-04 起生效；产品行为类条目（1–8）随重构调整，工程类（13–18）长期有效。共 18 条，每条都对应一个已经发生过的问题或已确认的决定。
「门禁候选」一列标出能否写成机器检查：能的，后续按「审查意见变门禁」逐步落地。

**模型可见面快照**：Stock `dsh/test/model-surface.test.mjs` 为每个角色与模式固定插件贡献的提示词段落和工具定义（`dsh/test/snapshots/model-surface/`）。提示词、工具描述或参数一改，测试失败；审阅差异后用 `UPDATE_MODEL_SURFACE=1 pnpm test` 刷新。快照只覆盖 Stock 插件贡献的部分，DSH 自带段落、研究纪律文件与 Vibe 宿主的 `read_page_context` 不在其中。
