上位：[系统职责与数据归属](system-ownership.md)。

## 1. 归属

| Owner | 责任 |
|---|---|
| Stock Backend | 数据、计算、来源绑定；不可变成果的持久化（PostgreSQL）；成果与对象的关联写入 |
| Agent / 研究 skills | 按问题选择分析与表达，调用正式工具；不编数据、不心算、不跑任意脚本 |
| 产品成果组件（`ResearchResult`、`MarketChart` 等） | 受控图型与布局、图数切换、下载、来源交互；不重复做财务计算 |
| DSH | 执行、取消、持久消息身份；消息只保存成果引用 |

- 不建独立 Artifact 数据库；Client SQLite 不保存研究结果。

## 2. 成果生命周期

- 成果是不可变的：数据、计算输入与结果、来源、数据期间或截至日、受控展示配置。
- 校验并保存成功才挂到消息；失败、取消、损坏不得显示完成。一个回答可以有多个成果。
- 同一生成请求重试返回同一结果；显式更新产生新结果，旧对话不改值。
- 历史重开默认恢复当时的数据快照；对象报告注明所用数据日期，不静默刷新数字。
- 关联对象删除不连带删除历史成果；缺源显示实际缺口；损坏与不存在返回可区分的错误。
- 浏览、图数切换、下载都不触发研究写入。关联到议题或 Wiki 走研究关联的提议→确认流程。

## 3. 显示规则

- 每张图都保留驱动数据，可切换「图表｜数据」；关键数字与分析文字直接可见。
- 金额通常用亿元，明细可用元；千分位与合理小数位；原始证据精度不变。
- 当前 `ResearchResult.tsx:125–154` 提供图表/数据切换与 PNG 图表、CSV 数据下载，不提供成果展开按钮；显示范围可选全部、最近 20 或 60 个交易日，只裁剪已保存数据、不重新计算。
- 图注显示截至日和口径，金融图显示单位，行情图说明精度与范围；来源标记绑定原快照及获取时间。下载图附同一口径、范围和来源；缺口沿成果 payload 原样显示，不补造值。
- `MarketChart` 使用现有金融组件的交互，数值可在图内查看；对话内嵌结果沿已登记的 Markdown 补丁，图直接位于对应正文位置，消息仅存成果引用。图表操作与图注随 S1 研究组件目录重做，本段不把未来组件当成当前能力。
