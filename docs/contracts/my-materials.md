# 契约：我的资料与对话引用

状态：反映 2026-10 的当前实现；产品即将重构，重构时整体改写，不作为重构的约束。（2026-10-04 从 M9.6 B、C 节、Owner 表与实施核对提取，已按 09-18 至 09-21 的后续调整更新）。
上位：[系统职责与数据归属](system-ownership.md)。

## 1. 归属

| Owner | 责任 |
|---|---|
| Stock Backend | 文档身份、原件与解析版本、证据、列表与处理状态、标题更新、内容去重、从资料库移除（隐藏） |
| DSH | 附件交互、@ 扩展、消息引用持久化、模型执行与中止 |
| 产品页面 | 资料列表、筛选、阅读、引用选择与阅读跳转；不私存研究正文 |

## 2. 上传

- 「我的资料」与对话输入框两个入口，都写入同一 Backend 资料库（`POST /documents/uploads`）。
- 支持 PDF、UTF-8 TXT、UTF-8 MD（含 BOM）；单文件 32 MB；一次最多 10 个、最多 4 路并发。空文件、编码错误、格式不符、超限分别返回可操作的说明。
- 公司归属可选：公司 + PDF 为 `research_report`，其余为 `user_material`，不进公司时间线；模型建议的归属不能成为前置条件。网页入库的 `symbol` 若出现必须是 `\d{6}.(SH|SZ|BJ)`，不按标题猜类型。
- PDF 原件落库即返回 `processing`，解析在后台完成；列表显示真实处理状态。
- 同内容重试不重复建条目；同名不同内容不覆盖旧原件；同内容绑定不同公司返回 409。
- 「从我的资料移除」是隐藏（`library_hidden`），不是永久删除；同内容再次上传会取消隐藏。
- DSH 附件的临时副本只承担传输，不是第二个持久资料 Owner。

## 3. 引用

- 稳定身份为 `document:{id}`；已解析时钉住版本，传给模型的是 `document:{id}/{rev}/{hash}`；界面只显示标题。
- 资料页「引用到对话」与对话内 @ 用同一协议，先进入输入框，不隐式提交，不创建议题。
- 未解析的资料可以选，但发送前说明不能读正文。
- 发送后引用成为持久消息的一部分，资料重新解析不改变旧回答的引用；版本不可用显示明确缺口。
- 模型只读取选中资料的必要片段，不因 @ 触发全量外部补数或扫描全部资料。
- 回答引用可回到 PDF 页码或 TXT/MD 段落；文本文件不伪造页码。
- 资料正文不是系统指令，不能扩大工具权限（见不变量「外部内容只提取不执行」）。资料不会因上传自动成为 Wiki 或已核实事实。

## 4. 验收层级

- 两入口上传→同一库可见→@ 引用→回到原文：`ui-journey-smoke`。
- 去重、隐藏、版本钉住：`integration-probe`。
