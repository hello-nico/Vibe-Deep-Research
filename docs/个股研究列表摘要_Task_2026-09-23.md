# 个股研究列表摘要

状态：2026-09-23 已实施，用户视觉验收通过。不 push。

权威：[产品对象模型与交互 v1](产品对象模型与交互_v1_2026-09-23.md) §4.4 预览卡字段（列表每行 = 展开的预览卡）；[Human Checklist](../human-checklist.md)「行业身份」相关决定（申万分类不等于统计局 41 行业）。

## 1. 目标

个股研究列表（`/research` 未选公司时）现在每行只有名称与代码，右侧大片空白。改为展示**研究视角的摘要**：所属分类、一句话经营模式、状态与资料截至日期。**不放行情数据**——行情属于自选股（市场视角），研究名单是知识视角，两页分工不重叠。

## 2. 冻结决定

- 字段与设计稿 §4.4 预览卡同一套，列表与卡片视图共用。
- **分类标签来自研究页 identity 块的申万二级分类**（`industry` / `industry_code`，如“化学制品”）。按 Checklist，申万分类不等于统计局行业：**不得链接到行业研究页 `/sectors/<key>`**；若该申万代码有已就绪的产业研究（`/industries/profiles` 中 `status === 'ready'`），标签链接到 `/sectors/profiles/<industry_code>`，否则为不可点的普通标签。
- 一句话经营模式取研究页 `research_blocks` 中 `operating_model` 的正文首句（去 Markdown，截断约 60 字加省略号）；没有则显示灰色“资料待补充”。不从 `operating_facts` 数字拼句子，不让模型现场生成。
- 摘要由研究后台列表接口一次返回，不在前端逐家读取研究页。

## 3. 研究后台（Stock-Research）

- `backend/app/api/v1/wiki.py` `GET /wiki/pages`：`kind=companies` 时每项追加 `summary`：`{ industry, industry_code, parent_industry, one_liner, as_of }`，均取自已加载的 `page.spec`（identity 块、`research_blocks` 的 `operating_model`、`spec.as_of`），缺失为 `null`。其他 kind 不变；不增加额外 gbrain 调用或锁持有时间。
- `operating_model` 的 `content` 可能是字符串或含正文字段的对象，两种都处理；首句按“。！？”或换行切分。
- 测试：有 / 无 `operating_model`、identity 缺字段、非公司 kind 不带 `summary`。

## 4. 工作台（Vibe）

- `pages/CompanyWiki.tsx` 列表视图每行两行布局：
  - 第一行：名称（现有样式）· 代码（等宽灰字）· 分类标签 · 状态标签；右侧依次为“资料截至 MM-DD”（12px 灰字）→ 现有 → ★ 移除。
  - 第二行：一句话经营模式，13px `text-muted-foreground`，单行省略；无则“资料待补充”（更浅一级灰）。
- **分类标签**：高 22px、圆角 6px、12px 字、`border` 描边 + 透明底；可点击时悬停描边转主色并显示指针。
- **状态标签**（只做现有数据能判断的两种，其余等 T4）：
  - 「研究中」：该公司存在运行中的研究会话（沿用页面现有研究状态来源）；主色浅底（`primary / .1`）+ 主色字。
  - 「图文报告」：该公司已有报告（`GET /wiki/reports?slug=` 有记录）；中性描边。为避免逐家请求，报告状态**仅在卡片可见时懒加载**（`IntersectionObserver`），失败静默不显示。
- **卡片视图**：同样字段，卡片内纵向排列：名称 + 代码 → 分类与状态标签 → 一句话（最多 2 行）→ 底部“资料截至”与操作。
- 行高与间距：列表行上下内边距 16px；名称行与摘要行间距 4px；整体仍用现有容器与分隔线。
- 不改搜索、筛选、排序与现有按钮行为。

## 6. Out of Scope

- 行情、估值等市场数据；待确认 / 草案 / 报告过期等状态（等 T4 对象状态接口）。
- 行业研究列表、议题列表的同类改造（本 Task 验收后按同一套字段另议）。
- 申万到统计局行业的映射。

## 7. Stop Conditions

- 研究页 `operating_model` 普遍为空或结构无法稳定取首句：保留“资料待补充”展示，记录实际结构，不改研究后台数据。
- `/wiki/pages` 追加字段导致耗时明显上升或需额外锁：停止，回填测量数据。
- 与其他工具同时修改同一文件：停止并告知用户。

## 8. 回滚

还原两仓相关文件；接口只增加字段，旧前端不受影响。
