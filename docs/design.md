# 视觉设计协议

工作台所有页面（关注、个股、行业、产业链、动态、跟踪、资料、设置、任务和以后新增的对象）共同遵守的视觉规格。改界面先改本文件，再改代码；不按截图逐页修补。

样张：Artifact「工作台卡片体系」（https://claude.ai/artifact/C3GiU3WjJiskExCYDTwEUc）与「工作台外壳样张」（https://claude.ai/artifact/MJrxZZqBLSsaSwYvuoefJQ）。研究页（个股、产业链）的叙事样张为 Artifact「华能蒙电个股页原型」（https://claude.ai/artifact/UAcygS9E3WAGzzmm2D9PDf）。样张与本文件不一致时以本文件为准。设计方法参考 grok bot（本地参考源码与参数见[视觉基础过程记录](tasks/archived/工作台视觉基础_Task_2026-10-10.log.md)），只借方法，不照搬外观。

状态：2026-10-10 用户确认方向；落地见 [工作台视觉基础](tasks/archived/工作台视觉基础_Task_2026-10-10.md)（UI-0，与 T8a 导航收敛合并实施）。落地前的页面逐步迁移，新页面直接遵守。

## 1. 原则

1. **近白底，细描边，不用阴影。** 外框（图标栏）浅灰，内容区近白，卡片白底加一圈淡描边；层次靠底色深浅和圆角，不靠阴影和分隔线。
2. **一个墨色派生所有灰。** 文字、底色、描边都是同一个墨色的不同透明度；不再单独定义灰、粉、浅橙。
3. **按钮靠底色，不靠边框。** 次要按钮是灰底全圆胶囊，主按钮是墨色；只有输入类控件（搜索、下拉）用细描边。一个区域最多一个主按钮。
4. **橙色只做三件事：** 进行中、选中、图表里的当前值。涨跌用红绿（A 股红涨绿跌）；对象类型色只用在小图标上。
5. **组名在卡片外，卡片里一行一项；同类卡片骨架固定、同行等高。** 缺内容时保留位置，布局不随数据跳动。
6. **第一层只放数和一句话。** 解释、条件、出处点开再看；不展示内部机制（计算标签、口径术语、版本号、系统提示横幅）。
7. **研究页先回答问题，再给数据。** 每节标题是一个问题，第一句是带数字的回答；数字嵌在句子和图里，不平铺成指标墙。

## 2. 颜色

所有颜色定义在 `desktop/src/index.css` 的亮暗两套变量里，页面只引用变量。

| 令牌 | 亮色 | 用途 |
|---|---|---|
| 墨色 `base` | `#161a22`（暗色 `#eceef2`） | 正文与主按钮；其余灰全部由它派生 |
| 外框 `chrome` | `#f6f7f8`（暗色 `#111316`） | 图标栏所在的最外层 |
| 内容区 `surface` | `#fcfcfc`（暗色 `#16191d`） | 页面底 |
| 卡片 `raised` | `#ffffff`（暗色 `#1c2025`） | 卡片、表格容器、弹层 |
| 文字 | 墨色 100% / 72% / 48% / 34% | 正文 / 次要 / 辅助 / 占位与空值 |
| 底色 | 墨色 6% / 10% / 16% | 悬停与标签 / 次要按钮与选中分段 / 按钮悬停 |
| 描边 | 墨色 8% / 12% / 20% | 行间分隔 / 卡片与输入框 / 悬停卡片 |
| 强调 `brand` | `#e3561f`；浅底为其 12% | 进行中、选中、图表当前值 |
| 语义 | 涨 `#d23c3c`、跌 `#1e9a57`、注意 `#c27c12`、信息 `#2f6fde` | 只表达语义 |
| 对象类型 | 个股蓝、行业紫、产业链青、资料橙褐 | 只用于小图标块里的图标或文字 |

派生写法：`color-mix(in srgb, var(--base) 12%, transparent)`。暗色主题只换墨色、外框、内容区、卡片四个值，派生比例不变。

## 3. 尺寸

| 项 | 规格 |
|---|---|
| 控件高度 | 按钮与搜索 32；小按钮、下拉、分段、图标按钮 28；状态胶囊与标签 22；状态点 7 |
| 圆角 | 卡片、表格容器、弹层 16；下拉、图标按钮、小图标块 8；标签 6；按钮与胶囊全圆 |
| 字号 | 页标题 24–26（600）；卡片与面板标题 14（600）；指标 22（600）；正文 13；辅助 12；代码 11 等宽 |
| 间距 | 4 · 8 · 12 · 16 · 20 · 24；卡片内边距 16–20；卡片间距 12；区块间距 28–44 |

数字一律等宽数字（`tabular-nums`）。

## 4. 外壳与页面骨架

1. 外壳：左侧图标栏放在外框上，六个两字入口（对话、动态、跟踪、关注、资料、设置），选中项用 10% 底色；右侧内容区为近白的大圆角面，1px 淡描边。
2. 页首：左侧标题，右侧搜索与一个主按钮；不放面包屑、橙色小标题和装饰性说明。
3. 主体：区块纵向排列；区块组名用 12–13px 灰字放在卡片或表格外的左上方，右侧可放一句说明或时点。
4. 桌面包（macOS）：只在 `html[data-platform='darwin']`（全屏即 `data-fullscreen='true'` 时除外）下，外壳顶部留一条窗口按钮带（36px），左栏与各页标题都从带下开始，不压红黄绿按钮；该带标 `data-window-drag`，可拖动窗口，带内没有控件。Web 没有该属性，外观不变。
5. 页尾：免责声明为一行灰字，不加框，只在研究类页面出现。

## 5. 组件

### 按钮与控件

- 主按钮：墨色底、白字、全圆，32px。
- 次要按钮：10% 底色、无边框、全圆；悬停 16%。小号 28px。
- 文字按钮：无底，次要文字色；悬停加 6% 底色。
- 图标按钮：28px 方形、8 圆角、无底；悬停加底色。
- 输入类：搜索全圆、下拉 8 圆角，都是 12% 描边加白底。
- 面板输入框（问助手）与 DSH 主对话输入框同款：无描边或墨色 8% 描边、柔和阴影、圆角与主输入框一致（16）；聚焦时不出现品牌色描边。这是原则 1「不用阴影」的唯一例外。
- 聚焦不用品牌色：文本输入（input、textarea、select）聚焦只靠自身描边或阴影变化（描边升到墨色 20%），不加外框；按钮与链接仅键盘聚焦（`:focus-visible`）显示 2px 墨色 20% 外框。
- 资料阅读页只有一个提问入口：选中文字后在浮动工具条（复制旁）出现「问助手」，点了才把原文放进问助手的「已选原文」（默认收起成一行）；阅读器底部不再设「追问范围 / 就此追问」条。面板标题已是文档名时不再另显文档标题标签；「问问这个页面」说明卡关掉后不再出现。
- 分段切换：无底文字，选中项 10% 底色。
- 开关：开为品牌橙，关为 16% 底色。
- 删除类动作进「⋯」菜单，不和常用动作并排。

### 分组卡

组名在卡片外；卡片里一行一项，左边名称和一行说明，右边控件或数值；行间 8% 分隔线。用于设置、个股页信息区、资料详情。

### 对象卡

三行骨架：`grid-template-rows: auto 1fr auto`，同类统一 `min-height`。

| 行 | 内容 |
|---|---|
| 头部 | 小图标块（30px、对象类型色）+ 名称（14px）与代码或类别（11px 等宽灰）；右侧关键数（现价与涨跌）或状态胶囊 |
| 主体 | 一句话（最多两行）+ 一条数据线；没有内容时显示状态胶囊或「关注后自动研究」，高度保留 |
| 底部 | 左：时点或关联；右：进入链接（灰，悬停加深） |

各对象的数据线：个股为近 60 日走势线（当前点用品牌橙）；行业为关注公司数、画像状态、更新时间；产业链为上游到下游的环节标签，利润最集中的环节用品牌橙浅底；动态卡没有数据线，主体只放一句话。需要提醒的卡片用品牌橙 45% 描边，同屏最多一张。

### 表格

装进描边圆角容器（白底、12% 描边、16 圆角）。表头 12px 灰字；行间 8% 分隔线；悬停行 6% 底色。

| 元素 | 呈现 | 原因 |
|---|---|---|
| 字段值 | 纯文字；数字右对齐、等宽 | 同列比较是主要用途，加框打断对齐 |
| 类别 | 有列头时纯文字；无列头列表里用浅底标签 | 列头已说明含义；无列头时用来区分属性与标题 |
| 状态 | 名称后 7px 圆点，悬停出文字，不单独占列，正常不显示 | 多数行正常，单列大片空着 |
| 默认币种、市场 | 不显示 | 不提供信息 |
| 行主动作 | 点整行或名称进入 | 每行重复大按钮是最大噪音 |
| 次要动作 | 行尾图标按钮，悬停该行才出现；删除进「⋯」 | 平时不抢视线 |

### 无列头列表

任务、动态、最近对话：标题前状态点，对象用品牌橙浅底标签，时间与用时用灰底标签，动作是行尾文字按钮。

### 面板与指标

页面每节一块面板：标题（14px）与右侧期间或出处，下面一句话结论，再下面是数据。指标：12px 灰标签 + 22px 数字；期间与出处放在悬停提示里，只在期间与同节其他数字不同时，标签后加一个期间胶囊。图表配色用墨色深浅表示一般项，品牌橙只标当前值或重点项。

### 状态

- 状态点：进行中品牌橙、未完成注意色、有新资料或提示墨灰（蓝色不在色板，只留给链接与对象类型小图标）、完成绿；正常不显示。
- 状态胶囊：22px，浅底加同色文字，用于卡片主体或工具栏旁。
- 同一状态在同一块里只出现一次；名单、工具栏、页内进度属不同层级。

### 加载、空与失败

- 加载：骨架条占住最终位置；研究类内容保留已验收的扫描动画。
- 空：一句话说明会出现什么、怎么产生，配一个主按钮；整节无数据时不渲染该节。
- 失败：已到的数据照常显示，失败部分一句话加「重试」；可选部分失败直接不显示，诊断进日志。

### 研究页叙事结构（个股、产业链）

1. **页首**：名称、代码、实时价格与涨跌；下一行一句话定性（研究的 thesis）；再下一行五档结论与最近一次判断变化（日期 + 资料 + 判断是否改变）；没有变化时写「研究于某日，资料未变化」。
2. **每节**：问题标题 → 一句带数字的回答 → 一个专用图 → 「查看数据」展开其余指标。第一层每节最多三个关键数；整节无数据时只留回答句或不渲染。
3. **句中数字**：正文里的数字由页面按字段填入，与正文同字号、加粗、等宽数字；悬停显示期间、口径与出处；缺口显示灰色「暂缺」，不留空。
4. **个股页五节**（问题文字可按公司类型微调）：

| 节 | 问题 | 专用图 | 无数据时 |
|---|---|---|---|
| 生意 | 它靠什么赚钱 | 构成条：各业务收入占比与毛利率并排 | 只留回答句 |
| 关键变量 | 关键变量动一下，利润变多少 | 公式行（利润 ≈ 各驱动项）在上，敏感性滑块（见第 6 条）在下 | 公式用行业通用式，滑块换单季营收与归母净利柱图 |
| 现金 | 利润是不是真金白银 | 去向条：经营现金流 → 资本开支 → 分红 → 剩余 | 已有项照画，缺项灰色 |
| 估值 | 现在的价格在赌什么 | 区间带：现价落在悲观—中性—乐观三档价的位置，回答句给出现价隐含的主变量取值（市场在赌什么）；每档写明关键变量取值 → 利润 → 倍数（倍数按行业与周期位置给出理由）；下方五档结论与市盈率、市净率、股息率三个数 | 无三档价时只显示五档与三个数 |
| 跟踪 | 接下来盯什么 | 跟踪卡：每个支柱一张，显示当前值、这条判断成立的条件与观察窗口；不用状态词与「警戒线」等行话：卡片写这条判断靠什么成立（如「毛利率保持在 55% 以上」），正常不显示任何状态；条件被打破时在数值下加一句白话，对应期报告已出仍不满足则说「这条判断不成立」；默认全部展开支柱与证伪条件，卡头不可点，只有右侧箭头能收起 | 只列支柱 |

5. **产业链页**沿用同一结构，各节问题与专用图在 T7b 定。
6. **敏感性滑块**（样张：Artifact「华能蒙电个股页 v2」https://claude.ai/artifact/GRU97VgRrf1qMkwDxFWjzN 的神火一块）：
   - 本节的本质是解释利润：利润由哪几个变量决定、各自弹性多大；估值建立在这个利润解释上，再按行业与周期位置给倍数。
   - 变量取自公司最近一份定期报告或业绩预告自述的利润变动原因，或用户在对话中讨论并确认的变量（标明「对话确认」与日期），最多三个；有行业模型时按真实单位拖动（元/吨、分/千瓦时），初始值为当前行情，滑轨标出上期均价；无行业模型时按百分比调价格、成本、量。
   - 右侧实时显示年化归母净利、相对基数的变化与各变量贡献（正负条，红增绿减），下方给对应每股收益与现价对应市盈率；估值节区间带同步出现调整后的中性价（空心点）。
   - 计算按 Backend 给出的每单位利润系数线性相加，页面不另写公式；口径与假设一行小字写在结果下方。银行等无适用模型的类型不画滑块。

## 6. DSH 渲染的界面

DSH 原生对话与面板只通过扩展点调整（见[产品界面契约](contracts/product-ui.md) §2），不用 CSS 覆盖 DSH 内部结构；统一观感优先调整我们自己的外层容器与令牌映射。

产品默认工作细节为原生 Compact：启动时仅在 Host 用户设置缺少 `ui-chat.transcriptView` 时补写 `compact`，保留已有选择。已完成思考不显示首行预览，用户仍可手动展开；流式中仍可能预览正在进行的思考段，不更改 DSH 渲染。

## 7. 审阅清单

改界面的 Task 在验收里引用本节，Claude 审阅时逐条核对：

1. 是否新增了页面私有的颜色、卡片、面板或按钮样式（应复用令牌和公共组件）。
2. 是否出现阴影、渐变、第二层色块、左边条、装饰编号。
3. 橙色是否只用于进行中、选中、图表当前值（聚焦也不用）；按钮是否靠底色而非边框。
4. 同行卡片是否等高；控件高度是否为 32 / 28 / 22。
5. 表格里状态是否占列、数字是否右对齐、是否每行重复按钮。
6. 第一层是否只有数和一句话，是否露出内部机制。研究页：每节是否先答问题、关键数是否不超过三个、期间与出处是否收进悬停。
7. 亮暗两种主题各截图一张核对。
