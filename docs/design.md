# 视觉设计协议

工作台所有页面（关注、个股、行业、产业链、动态、跟踪、资料、设置、任务和以后新增的对象）共同遵守的视觉规格。改界面先改本文件，再改代码；不按截图逐页修补。

样张：Artifact「工作台卡片体系」（https://claude.ai/artifact/C3GiU3WjJiskExCYDTwEUc）与「工作台外壳样张」（https://claude.ai/artifact/MJrxZZqBLSsaSwYvuoefJQ）。研究页（个股、产业链）的叙事样张为 Artifact「华能蒙电个股页原型」（https://claude.ai/artifact/UAcygS9E3WAGzzmm2D9PDf）。样张与本文件不一致时以本文件为准。设计方法参考 grok bot（本地参考源码与参数见[视觉基础过程记录](tasks/archived/工作台视觉基础_Task_2026-10-10.log.md)），只借方法，不照搬外观。

状态：2026-10-10 用户确认方向；落地见 [工作台视觉基础](tasks/archived/工作台视觉基础_Task_2026-10-10.md)（UI-0，与 T8a 导航收敛合并实施）。落地前的页面逐步迁移，新页面直接遵守。

## 1. 原则

1. **近白底，细描边，不用阴影。** 外框（图标栏）浅灰，内容区近白，卡片白底加一圈淡描边；层次靠底色深浅和圆角，不靠阴影和分隔线。
2. **一个墨色派生所有灰。** 文字、底色、描边都是同一个墨色的不同透明度；不再单独定义灰、粉、浅橙。
3. **按钮靠底色，不靠边框。** 次要按钮是灰底全圆胶囊，主按钮是墨色；只有输入类控件（搜索、下拉）用细描边。一个区域最多一个主按钮。
4. **橙色只做三件事：** 进行中、选中、图表里的当前值。涨跌用红绿（A 股红涨绿跌）；对象类型色只用在小图标上。
5. **组名在卡片外，卡片里一行一项；同类卡片骨架固定、同行等高。** 缺内容时保留位置，布局不随数据跳动。
6. **第一层只放数和一句话。** 解释、条件、出处点开再看；不展示内部机制（计算标签、口径术语、版本号、系统提示横幅）。
7. **研究页先回答问题，再给数据。** 每节标题是一个问题，第一句是带数字的回答；数字嵌在句子和图里，不平铺成指标墙。

## 2. 颜色

所有颜色定义在 `desktop/src/index.css` 的亮暗两套变量里，页面只引用变量。

| 令牌 | 亮色 | 用途 |
|---|---|---|
| 墨色 `base` | `#161a22`（暗色 `#eceef2`） | 正文与主按钮；其余灰全部由它派生 |
| 外框 `chrome` | `#f6f7f8`（暗色 `#111316`） | 图标栏所在的最外层 |
| 内容区 `surface` | `#fcfcfc`（暗色 `#16191d`） | 页面底 |
| 卡片 `raised` | `#ffffff`（暗色 `#1c2025`） | 卡片、表格容器、弹层 |
| 文字 | 墨色 100% / 72% / 48% / 34% | 正文 / 次要 / 辅助 / 占位与空值 |
| 底色 | 墨色 6% / 10% / 16% | 悬停与标签 / 次要按钮与选中分段 / 按钮悬停 |
| 描边 | 墨色 8% / 12% / 20% | 行间分隔 / 卡片与输入框 / 悬停卡片 |
| 强调 `brand` | `#e3561f`；浅底为其 12% | 进行中、选中、图表当前值 |
| 语义 | 涨 `#d23c3c`、跌 `#1e9a57`、注意 `#c27c12`、信息 `#2f6fde` | 只表达语义 |
| 对象类型 | 个股蓝、行业紫、产业链青、资料橙褐 | 只用于小图标块里的图标或文字 |

派生写法：`color-mix(in srgb, var(--base) 12%, transparent)`。暗色主题只换墨色、外框、内容区、卡片四个值，派生比例不变。

## 3. 尺寸

| 项 | 规格 |
|---|---|
| 控件高度 | 按钮与搜索 32；小按钮、下拉、分段、图标按钮 28；状态胶囊与标签 22；状态点 7 |
| 圆角 | 卡片、表格容器、弹层 16；下拉、图标按钮、小图标块 8；标签 6；按钮与胶囊全圆 |
| 字号 | 页标题 24–26（600）；卡片与面板标题 14（600）；指标 22（600）；正文 13；辅助 12；代码 11 等宽 |
| 间距 | 4 · 8 · 12 · 16 · 20 · 24；卡片内边距 16–20；卡片间距 12；区块间距 28–44 |

数字一律等宽数字（`tabular-nums`）。

## 4. 外壳与页面骨架

1. 外壳：左侧图标栏放在外框上，六个两字入口（对话、动态、跟踪、关注、资料、设置），选中项用 10% 底色；右侧内容区为近白的大圆角面，1px 淡描边。
2. 页首：左侧标题，右侧搜索与一个主按钮；不放面包屑、橙色小标题和装饰性说明。
3. 主体：区块纵向排列；区块组名用 12–13px 灰字放在卡片或表格外的左上方，右侧可放一句说明或时点。
4. 桌面包（macOS）：只在 `html[data-platform='darwin']`（全屏即 `data-fullscreen='true'` 时除外）下，外壳顶部留一条窗口按钮带（36px），左栏与各页标题都从带下开始，不压红黄绿按钮；该带标 `data-window-drag`，可拖动窗口，带内没有控件。Web 没有该属性，外观不变。
5. 页尾：免责声明为一行灰字，不加框，只在研究类页面出现。

## 5. 组件

### 按钮与控件

- 主按钮：墨色底、白字、全圆，32px。
- 次要按钮：10% 底色、无边框、全圆；悬停 16%。小号 28px。
- 文字按钮：无底，次要文字色；悬停加 6% 底色。
- 图标按钮：28px 方形、8 圆角、无底；悬停加底色。
- 输入类：搜索全圆、下拉 8 圆角，都是 12% 描边加白底。
- 个股页与动态「讨论」的问助手就是主对话的同一个助手：没有模式切换，面板里保留本页的「重新研究」与「撤回上次更新」入口；打开个股页新开会话，不沿用旧的即答会话。
- 面板输入框（问助手）与 DSH 主对话输入框同款：无描边或墨色 8% 描边、柔和阴影、圆角与主输入框一致（16）；聚焦时不出现品牌色描边。这是原则 1「不用阴影」的唯一例外。
- 聚焦不用品牌色：文本输入（input、textarea、select）聚焦只靠自身描边或阴影变化（描边升到墨色 20%），不加外框；按钮与链接仅键盘聚焦（`:focus-visible`）显示 2px 墨色 20% 外框。
- 资料阅读页只有一个提问入口：选中文字后在浮动工具条（复制旁）出现「问助手」，点了才把原文放进问助手的「已选原文」（默认收起成一行）；阅读器底部不再设「追问范围 / 就此追问」条。面板标题已是文档名时不再另显文档标题标签；「问问这个页面」说明卡关掉后不再出现。
- 分段切换：无底文字，选中项 10% 底色。
- 开关：开为品牌橙，关为 16% 底色。
- 删除类动作进「⋯」菜单，不和常用动作并排。

### 分组卡

组名在卡片外；卡片里一行一项，左边名称和一行说明，右边控件或数值；行间 8% 分隔线。用于设置、个股页信息区、资料详情。

### 对象卡

三行骨架：`grid-template-rows: auto 1fr auto`，同类统一 `min-height`。

| 行 | 内容 |
|---|---|
| 头部 | 小图标块（30px、对象类型色）+ 名称（14px）与代码或类别（11px 等宽灰）；右侧关键数（现价与涨跌）或状态胶囊 |
| 主体 | 一句话（最多两行）+ 一条数据线；没有内容时显示状态胶囊或「关注后自动研究」，高度保留 |
| 底部 | 左：时点或关联；右：进入链接（灰，悬停加深） |

各对象的数据线：个股为近 60 日走势线（当前点用品牌橙）；行业为关注公司数、画像状态、更新时间；产业链为上游到下游的环节标签，利润最集中的环节用墨色加深底（橙色只做进行中、选中、图表里的当前值）；动态卡没有数据线，主体只放一句话。需要提醒的卡片靠置顶与第一句话区分，不用描边色或底色。

动态是一条按时间倒序的流，没有「行情 / 资讯」分段。顶部是类型筛选（全部、财报、价格、公告），样式同分段切换：选中项灰底，其余纯文字；类型只是卡片上的小字，不是入口。四类卡片（财报、价格、公告、判断变化）结构统一：第一句发生了什么（加粗）；下面一行灰字「涉及：{公司} · {领域或驱动} · {影响一句话}」；底行左侧灰字「{类型} · {日期}」，右侧灰底全圆胶囊按钮「展开」「看{公司}」「讨论」（没有可展开内容的不出「展开」）。「讨论」都带这条卡片的标题与第二行打开问助手，不新开对话。判断变化卡（跳档或估值档位变化）置顶，筛选「财报」与「价格」时也出现，只靠置顶与第一句话区分，不加描边或底色。公告卡「涉及」只写公司与领域，不编支柱；「全部」里同一公司同一天的公告合并成一张（第一句用最重要的一份，非例行优先；底行「公告 · 日期 · 另有 N 份公告」，展开列出其余标题与原文链接），筛选「公告」时不合并；公告默认只显示可能影响估值的，筛选「公告」时列表上方有「查看全部（另有 N 条例行）」。卡片内容与数据来源不变，公开新闻不在这条流里。

财报到达对账卡：关注公司最近 14 天内披露了新的季度报告时（不管研究是否已经用上这份季报，价格部分始终按已存研究的系数算），动态流里出一张对账卡（类型「财报」），不描边，日期取披露日。第一层一句话：「神火三季报：单季净利润 27.05 亿元，比上季多 2.14 亿元」；有价格模型时再加半句「沪铝、氧化铝变化约带来 +1.20 亿元，其余 +0.94 亿元来自量和成本等，报告未单独披露」；展开看各价格的本季均价、上季均价与贡献，没算进去的因素逐个说明。解释的是环比变化，不写准确度，不写买卖建议；没有价格模型的公司只写与上季的差额。
对账卡主体全部来自利润表，按对净利润的影响列示（费用多了记负、亏损加重记负）：毛利变化（营业收入 − 营业成本）、资产减值、信用减值、投资收益、公允价值变动、销售/管理/研发/财务费用、所得税、少数股东损益；单季 = 累计值相减。「其他」= 比上季的变化 − 以上合计（税金及附加、其他收益、营业外等），应当较小，已列科目加其他等于环比。第一层先说利润表里影响最大的一项，后半句交代其他；所得税与少数股东损益是税前利润变化的机械结果，只在展开里列出，不做首句。价格解释是研究模型的税后估计，不参与加总，展开里单独一行「研究模型估计：价格变化影响约 x 亿元（税后年化系数折季），仅供参考」，没有研究模型不出。单季数据缺的科目如实说明并归入「其他」，不当零；末行注明价格影响与减值可能部分重叠，没有去重。没有利润表科目时卡片与之前一致。

Jev 判断：Backend 的 Jev 读到某条新闻碰到公司哪个估值驱动时，那一句改写成「涉及沪铝：对利润偏负面」（偏正面 / 偏负面 / 影响不明三种，不写利好、利空，不写买卖建议），有价格模型且有每步影响的保留数值半句「；每 +1,000 元/吨，净利润 +9.96 亿元」；Jev 没读到（首次读取、没开、失败）时仍用下面的关键词句。同一事件的改写合并成最早的一条，标题后加灰底标签「另有 N 篇报道」；同一事件的新进展加灰底标签「新进展」。公告默认只显示可能影响估值的，Jev 判为例行的收起，列表上方出现一个文字按钮「查看全部（另有 N 条例行）」，点开后例行的加灰底标签「例行」，按钮变成「只看重要的」。三种标签都是灰底，不用橙色，不描边。

驱动说明：动态里的新闻标题涉及公司价格变量时写原来的一句（「涉及沪铝：每 +1,000 元/吨，净利润 +9.96 亿元」）；公司没有价格模型时，涉及所属行业框架的驱动写「涉及净息差：影响利润和净资产，进而影响市净率」，同一条只写一句、价格变量优先，不判断方向、不读正文。驱动名取行业框架的名字（去掉括号注释），营业收入、净利润、毛利率、市盈率、市净率、股息这类结果指标不当驱动。

跳档提醒：关注公司的主价格接近或越过研究里的跳档价时，动态流置顶一张提醒卡（类型「判断变化」）（越过在前、接近在后，样式与普通动态卡一致，不描边、不加「接近 / 越过」标签，句子本身已说明），跟踪页对应价格那行的走势图同步标出（见「正在盯的」）；平时不出现。句式：越过写「沪铝跌破 22,500 元/吨，神火估值从偏高变为明显高估」，接近写「沪铝距 22,500 元/吨只差 1.2%，越过后神火估值会从偏高变为明显高估」；只写估值事实，不写买卖建议；原档取已存研究，新档由跳档边界推出，推不出时写「估值判断会改变」。

对话里调整的记录卡（类型「对话」）：在对话里改了价格影响的取值、论点与支柱，或对话里提到了新因素时，动态里出一张卡。第一句是调整了什么（一句中文，不出现「写回」「候选」「driver」）；档位变了时第三行加粗写「估值从合理变为偏高」，卡置顶，底行类型前加加粗的「判断变化 · 」（与财报卡同规则，导航「动态」小点与置顶卡一一对应）；档位没变写「估值判断没变（偏高）」；旧记录没有档位就不写。底行按钮「展开」（没有可展开内容的不出）「看公司」「打开对话」「撤回」「讨论」；撤回一次只退一版，只对该公司最新一次调整可用，更早的显示灰字「已有更新的版本」，撤回过之后更早的也不可用。
个股页里来自对话的内容旁标灰字「来自 10-26 的对话」，点开回到那段对话：价格影响滑块、论点、支柱与不成立的条件；页首判断变化行写「因 10-26 对话调整：…」并有文字按钮「打开对话」「撤回」。个股页「接下来盯什么」之后多一组「对话里提到的因素」：每项粗体名称加一句灰字为什么，三个小胶囊「纳入」「排除」「观察」；纳入后显示「已纳入，下次研究会算进模型」与文字按钮「重新研究」（纳入只做标记，不自动研究）；排除先展开一行输入框（理由可不填）再「确认排除」，之后不再显示；观察先只标为「已标为观察」（跟踪页的观察项需要判断条件，仍由对话里的「开始观察」建）；没有这类因素或读取失败时整组不出现。

正在盯的：跟踪页只留「正在盯的」，研究进度不在这里（在关注页列表的「研究」列）。默认全部折叠，每个价格只有一行：左边粗体名称，下一行灰字一句状态（平静句「近一个月没有大到需要提醒的变动」，与最近 20 个交易日的提醒窗口一致；有提醒写那一次；受影响的公司接在后面），右边同一行写最新价与当日涨跌（涨红跌绿；没有日行情或暂时取不到时右侧空白），行尾一个展开箭头。点整行或箭头展开，再点收起，不提供「全部展开」；展开状态按行记在本机。用户自己加的价格，名称后带灰底小标签「我添加的」，研究带出的不标。「不再盯」放在每行展开区的底部（灰底全圆胶囊，行上不放按钮，触屏也能点；只停止盯和提醒，不改研究模型，不删资料）；列表底部写「已不再盯 · N 项」，点开列出名称，每项一个「恢复」胶囊，没有就不出现。页首右侧主按钮「＋ 添加要盯的」打开一块搜索：输入框加价格名称胶囊（沪铜、焦煤、美元指数……），输入即筛选，点一个就加入，已在列表里的不再出现；失败在下面写一句灰字。展开里自上而下：迷你日线（从开始盯的那天起画，开始盯之前的日子补到 40 个交易日，开始盯的位置画一根竖的细点线，下方灰字「10-26 开始盯」）（约 300×64，细线墨灰，不画坐标轴与网格）——研究里存的跳档价画成水平虚线，线旁写「跌破 22,500 元/吨：神火估值从偏高变为明显高估」（方向与句式同「跳档提醒」；没有跳档价就不画线，离走势区间太远也不画线、只留文字），提醒过的日子画空心圆点，最新一天画品牌橙实心点（橙色只用在这个点上）；图旁灰字写「08-21 至 10-23 收盘」；图下是各家公司的影响明细。走势图有文字替代（名称、起止日期、最新价）；没有日行情时展开里只写原因、不画图。

下次报告要验什么：跟踪页「正在盯的」之后一组，标题「下次报告要验什么 · 3 家」（家数是有研究的关注公司数），不折叠、没有按钮。每家一行：左边粗体公司名，后接灰字「要看：净息差、不良率、净利润」（最多 4 项，取研究里证伪条件绑定的指标）；右边「三季报 · 10-30」（报告名用一季报、半年报、三季报、年报；预约日还没公布写「三季报 · 预约日待公布」）。没有公开行情、因此不在「正在盯的」里单列的因素（煤炭销售均价、钴价、电池售价、净息差等）都靠这一组按报告检查；列表之后、页底只写一句灰字「没有公开行情的因素按报告检查」，不再列举没有数据源的名单。读取失败或没有已研究的公司时整组不出现。

财报到达自动重研：关注公司披露定期报告后系统自动按新报告重新研究（只有在这次研究保存了新一版时才比较档位）。结论写在动态里那份财报的卡上，一份财报一张卡：第三行（比「涉及」略重的正文字号）完成且研究完成时间不早于披露日时写「已按三季报重新研究：估值从偏低变为合理」（加粗）或「已按三季报重新研究：估值判断没变（合理）」；该公司有进行中的研究写「正在按三季报重新研究（3/6）」；都没有不写，没有上一版档位可比时只写「已按三季报重新研究：估值合理」。档位变了的卡置顶，底行类型前加加粗的「判断变化 · 」。提醒只留一个入口：导航「动态」图标旁的小圆点（现有状态圆点，墨色，不用橙色，不显示数字，悬停说明原因），有未看的判断变化时亮——跳档卡、档位变了的财报卡、对话写回导致档位变化的记录；进入动态页即清除并记在本机。导航「跟踪」旁不再有圆点。
建产业链：对话回答末尾的推荐可以是「产业链」（与追问、关注公司、开始观察推荐四选一，每次最多一条）。一行：左边「{链名}」，下一行灰字一句理由，右边灰字状态「建这条产业链」；点一下以用户已关注的公司为底建链并进入该链，失败在下面写一句灰字；已经建好的（含重新打开对话）状态显示「查看」，点一下进入该链。不出现 public_chain、suggest 这类内部词，也不写买卖建议。

开始观察：对话回答末尾的推荐可以是「开始观察」（与追问、关注公司推荐三选一，每次最多一条）。一行：左边「开始观察：{指标名}」，下一行灰字写为什么重要（观察要验证的那句判断），右边灰字状态「开始观察」；点一下就建成一条观察项，成功后变「已在观察」，失败在下面写一句灰字，已经在观察的重新打开对话也直接显示「已在观察」。跟踪页的「正在盯的」列表里，每条观察项也是一行（与价格同一个列表，排在价格后面）：粗体写议题名，下一行灰字「为什么重要」，行尾灰字写汇总「4 条消息里 2 条支持、1 条不利」（只有一种时只写那一种，如「3 条消息里 2 条不利于这个判断」；支持和不利都没有写「还没有相关消息」）。观察项本身是一个判断，每条消息按它对这个判断的影响说，标签是「支持这个判断」「不利于这个判断」「无关」「还没判断」，界面不出现加强、削弱、偏削弱、偏加强、方向不明。展开后是一条时间轴加信号列表：支持画向上实心三角，不利画向下实心三角，无关画空心圆，还没判断画虚线圆，轴下一行图例「▲ 支持　▼ 不利　○ 无关」；列表每条写日期、标签、一句话，标签可点开改成另外三种（改的是这一条，改完立即生效）。观察项同样可「不再盯」与恢复；观察项的评估与提醒不在这里。界面不出现议题、tracking、indicator 这类内部词，也不写买卖建议。

### 表格

装进描边圆角容器（白底、12% 描边、16 圆角）。表头 12px 灰字；行间 8% 分隔线；悬停行 6% 底色。

| 元素 | 呈现 | 原因 |
|---|---|---|
| 字段值 | 纯文字；数字右对齐、等宽 | 同列比较是主要用途，加框打断对齐 |
| 类别 | 有列头时纯文字；无列头列表里用浅底标签 | 列头已说明含义；无列头时用来区分属性与标题 |
| 状态 | 名称后 7px 圆点，悬停出文字，不单独占列，正常不显示 | 多数行正常，单列大片空着 |
| 默认币种、市场 | 不显示 | 不提供信息 |
| 行主动作 | 点整行或名称进入 | 每行重复大按钮是最大噪音 |
| 次要动作 | 行尾图标按钮，悬停该行才出现；删除进「⋯」 | 平时不抢视线 |

### 无列头列表

任务、最近对话：标题前状态点，对象用品牌橙浅底标签，时间与用时用灰底标签，动作是行尾文字按钮。动态卡不属于这一类，动作在卡片底行右侧，是灰底全圆胶囊（次要按钮样式）。

### 面板与指标

页面每节一块面板：标题（14px）与右侧期间或出处，下面一句话结论，再下面是数据。指标：12px 灰标签 + 22px 数字；期间与出处放在悬停提示里，只在期间与同节其他数字不同时，标签后加一个期间胶囊。图表配色用墨色深浅表示一般项，品牌橙只标当前值或重点项。

同一页上同一个量只有一种说法：「现价」一律用页首实时价，数据包快照价只在「查看数据」里并标日期；市盈率区分「近四季」（实际净利润）与「按估算利润」（利润试算），悬停说明差别；期间统一写成「2025 年报、2026 半年报、2026 三季报、近四季（截至 2026 三季报）」；百分号紧跟数字（23.35%）；句中数字用正文字体加粗，不用等宽；缺现金分红总额但有每股分红时按「每股分红 × 总股本」估算并标明；三档估值每行用同一个主价格讲，其他因素取值收进展开。三档价（模型行、档位行、区间带标签、三档表）统一截断到两位小数，不四舍五入，同一个价同页只有一种写法。

### 状态

- 状态点：进行中品牌橙、未完成注意色、有新资料或提示墨灰（蓝色不在色板，只留给链接与对象类型小图标）、完成绿；正常不显示。
- 状态胶囊：22px，浅底加同色文字，用于卡片主体或工具栏旁。
- 同一状态在同一块里只出现一次；名单、工具栏、页内进度属不同层级。

### 加载、空与失败

- 加载：骨架条占住最终位置；研究类内容保留已验收的扫描动画。
- 空：一句话说明会出现什么、怎么产生，配一个主按钮；整节无数据时不渲染该节。
- 失败：已到的数据照常显示，失败部分一句话加「重试」；可选部分失败直接不显示，诊断进日志。

### 关注页对象分段

关注页分段「个股 / 产业链」，不新增一级导航。个股分段仍是自选公司列表。产业链分段只列用户自己建的链（名称、上游到下游的环节、链上已关注公司数），点进 `/chains/:id`，不触发研究，不展示预置链；一条都没有时只写一句灰字：「还没有产业链。打开一家公司，点「建这条产业链」，或在对话里让助手推荐。」读取失败写一句话加「重试」。关注为空时，第一次打开空态只出现在个股分段；产业链分段照常显示自己的链或上面那句话。

关注页「研究」列：个股分段列表视图每家公司一行里，「研究」列一行写完研究状态，动作在同一行，不再在行内名称旁放状态点。已完成写「10-24 研究 · 估值偏高」（完成日 M-DD、估值五档完整句）；研究中写「研究中 · 3/6」后接一条 64px 宽、4px 高的短进度条（已完成步数 / 总步数，品牌橙）；接着上次继续写「接着上次继续 · 3/6」；有新资料写完成句后接灰底胶囊「重新研究」；上次没完成写「上次没有完成」后接「重新研究」；没有研究过写「未研究」后接「重新研究」；A 股以外写「暂不支持研究」。「重新研究」是次要灰底全圆胶囊（28 高），只有点它才开始，打开关注页不会自动开始研究；研究中不显示。整行仍点进公司页。卡片视图不变。

### 第一次打开

个股分段在关注列表为空（且没有在搜索）时，不出现表格和页首搜索，只放一块居中的空态；已有关注的用户看不到它。分段「个股 / 产业链」在空态时也保留。

1. **一句话**：标题（页标题字号）「你在关注哪些公司？」，下一行一句灰字说产品做什么：「输入公司名称或代码，我们会自动研究它：靠什么赚钱、哪些价格影响利润、现在的价格在赌什么。」
2. **一个输入框**：搜索同款全圆、12% 描边加白底、32px，右侧一个主按钮「开始」（本页唯一的主按钮）；回车等同点击。名称只匹配已研究过的公司，代码按现有规则解析（只支持 A 股）；没认出来时输入框下一行灰字说明，不弹窗。
3. **示例**：输入框下 2–3 个灰底胶囊按钮，写已研究过的公司名（神火股份、长江电力、农业银行），点一下等同输入并开始；没有已研究过的公司时不显示这一行。
4. **选中之后**：加入关注与研究名单，直接进入该公司；研究打开后自己开始，进度显示在页首，空态页不另做进度。
5. 本版不推荐同链公司、不做多步引导；橙色不出现在空态。

### 关于我

设置页第一个分段，分段为「关于我 / 模型 / 连接」，默认进入「关于我」。助手记得的关于用户的事只有一张列表，不分卡、不显示分类。

1. **顶部输入框**：搜索同款全圆输入加「记下」次要按钮；回车等同点击，空输入不提交；记下后清空输入框，新条目出现在列表最上面。
2. **列表**：分组卡，一行一条：左边一句话，下一行灰字写来源与日期（自己填写、对话里说的、从对话中推断、自己改过）；对话里说的来源可点，打开那次对话；右边文字按钮「删除」，删除即生效，不弹确认。按更新时间倒序，没有时间的排最后。
3. **说明**：列表下一句灰字「不对的直接删掉，助手以后不再按它来。」；没有条目时一句灰字说明怎么产生（在对话里说“记住：…”，或在上面的输入框里补充）。
4. **用语**：标签用「我」，说明文字不带人称；不出现 soul、recent、stance 等内部词。不做原地改字（删了重记）；议题建议不在本页。
5. 不用橙色，不描边行，不加状态胶囊。

### 研究页叙事结构（个股、产业链）

1. **页首**：名称、代码、实时价格与涨跌；下一行一句话定性（研究的 thesis）；代码那一行末尾灰字写「推荐所在链：煤—电—铝」（读自推荐接口，不再按申万行业自动挂）：已建的链名可点，进入你的那条链；未建的链名后跟文字按钮「建这条产业链」，点一下以已关注公司为底建链并进入；读不到或没有推荐时整段不出现，不报错。再下一行「完整判断：按现在的股价，大致对应 X 约 N（现在 M）」（如「估值偏高：按现在的股价，大致对应沪铝约 23,258 元/吨（现在 23,350 元/吨，10-23 收盘）」；「现在」是变量最新价，取跟踪接口：盘中有报价写「现在 …，M-DD HH:mm 盘中」，否则写最近收盘「…，M-DD 收盘」，都取不到才退回研究时的默认值并写「研究时 22,970 元/吨」；隐含值 N 与跳档半句的远近都以这个「现在」为准，百分比变量不写；产业链页公司行同此；隐含价缺失时只写完整判断，缺口原因进「查看数据」；若主价格距最近的跳档价不超过 3%，句末加半句「跌破 / 涨过 X，判断变为 Y」；Y 由跳档边界和价格涨跌方向推出：按明显低估 < 偏低 < 合理 < 偏高 < 明显高估的顺序，利润变大时估值往低档走，推不出时写「判断会改变」）；主变量单位是 % 时（取值是相对对比期的变动，不是价格）写「估值合理：按现在的股价，大致对应境内水电发电量比对比期低约 0.5%」，隐含值不到 0.05 写「与对比期持平」，不写「现在」，跳档半句写「境内水电发电量再升 2.0%，判断变为…」，距离按百分点算、3 个点内才写；市场隐含值超出近年区间（Backend 标 `within_range` 为假）时照写数值并说明：「估值偏低：按现价，市场隐含的沪铜约 80,000 元/吨，低于近年区间」，没有该字段时保持原写法。「接下来盯什么」里单位为 % 的变量不写「0 %」，写「持平 / 高 x% / 低 x%」，说明里写「与对比期持平」或「比对比期高 / 低 x%」；最后一行最近一次判断变化（日期 + 资料 + 判断是否改变，可撤回）；没有变化时写「研究于某日，资料未变化」。
   页首「最近一次判断变化」同处另写一行灰字「数据截至 2026 年三季报」，取数据包的 `page_period`（年报、半年报、一季报、三季报），旧 Backend 没有该字段时不写。第一层数字与页面报告期不同期时（分部只到半年报、分红按上一年度方案），就在数字旁用灰色小字标出自己的期间（「2026 年半年报」「2025 年度方案」），同期的不标，市场时点（现价、市盈率）不算报告期。
   研究已存在但已过期（有新资料、研究还没用上）时，打开个股页不自动重新研究：「数据截至」那行下多一行灰字「有新资料（三季报）」，后接文字按钮「重新研究」，点了才开始；资料名取不到只写「有新资料」。从未研究过的公司仍打开即开始。财报到达自动重研不受影响。
   研究任务统一叫「公司研究 · 神火股份」，不显示代码：建任务时查公司名，旧任务显示时名称是代码就就地补名，查不到才显示代码。任务过程面板里，后台整理没有产出时不出现「知识整理」页签，也不写「没有需要展示的整理过程」；有产出时只写一句结果。
   页首再下面一行「我的看法：{原句}」，后接灰字「{来源} · {日期}」（来源与「关于我」列表同一套：对话里说的、自己填写、自己改过）：取自「关于我」里用户自己说过或改过、正文含这家公司名（或去掉「股份」的简称、6 位代码）的条目，推断的不算；最多 2 条，按时间倒序，其余收成「另有 N 条」链到设置；没有或读取失败整行不出现。只并列摆放，不比较、不评判对错，不改论点与档位；灰字正文，不描边、不用橙色。
2. **每节**：问题标题 → 一句带数字的回答 → 一个专用图 → 「查看数据」展开其余指标。第一层每节最多三个关键数；整节无数据时只留回答句或不渲染。
3. **句中数字**：正文里的数字由页面按字段填入，与正文同字号、加粗、等宽数字；悬停显示期间、口径与出处；缺口显示灰色「暂缺」，不留空。
4. **个股页五节**（问题文字可按公司类型微调）：

| 节 | 问题 | 专用图 | 无数据时 |
|---|---|---|---|
| 生意 | 它靠什么赚钱 | 第一层关键数：各业务毛利（分部收入 − 分部成本，亿元），最多三项按毛利排序；没有分部成本的公司只写各业务收入，缺口写进「查看数据」；不放单独的成本或收入；名称含「其他、抵消、内部、合并调整」的分部，以及毛利为负且收入占比不到 5% 的分部不上第一层，只在「查看数据」里列出 | 只留回答句 |
| 关键变量 | 关键变量动一下，利润变多少 | 公式行（利润 ≈ 各驱动项）在上，敏感性滑块（见第 6 条）在下 | 公式用行业通用式，滑块换单季营收与归母净利柱图 |
| 现金 | 利润是不是真金白银 | 去向条：经营现金流 → 资本开支 → 分红 → 剩余 | 已有项照画，缺项灰色 |
| 估值 | 现在的价格在赌什么 | 区间带：现价落在悲观—中性—乐观三档价的位置，回答句给出现价隐含的主变量取值（市场在赌什么）；每档写明关键变量取值 → 利润 → 倍数（倍数按行业与周期位置给出理由）；区间带上方三行预期对比，每行一句话加一个数：「机构预期：2026 年每股收益 4.12 元（4 家）」（研报一致预期，少于 3 家加「样本少」；没有写「暂无机构预期」，不估）、「模型：中性价 26.81 元/股，估值偏高」、「股价隐含：按现在的股价，大致对应沪铝约 24,100 元/吨（现在 23,465 元/吨）」（隐含值越出近年区间时照写并说明）；三行下一句差异，把三方折成同口径的每股收益（机构预测；模型中性价对应的预测利润÷股本；现价÷中性倍数），只写分歧最大的一方比另外两方高或低多少，三者相差不到 5% 就写相差不到 5%，不写买卖建议；「股价隐含」行写「暂无」时，差异句同样不纳入股价隐含（只比剩下两方，只剩一方不写差异句），三行与差异句说的是同一件事；机构预测年与模型利润期间不同时，差异句末尾加「（机构为 2026 年预测，模型按近 12 个月利润，口径不同）」，期间按实际写，相同不加，不换算；期间码（FY2026E、TTM:2026Q3）在页面与「查看数据」里一律写成中文（2026 年预测、近四季（截至 2026 三季报））；三档里某一档因亏损等原因没有价，只那一档在档位行与「查看数据」的三档表里写「亏损，不给价」（不上区间带），其余两档与模型行照常，不整表丢；来源与期间收进「查看数据」；三行是灰字正文，不描边、不用橙色；下方五档结论与市盈率、市净率、股息率三个数 | 无三档价时只显示五档与三个数 |
| 跟踪 | 接下来盯什么 | 盯的卡：每张一句话加一个数。先列利润模型里的价格（现价、比对比期均价高低多少、对利润的影响，附每涨跌一档利润变多少），没有价格模型时列行业驱动项的当前值；最后一张是下一次报告（「三季报最晚 10-31 披露」，按法定截止日）。不拿毛利率、净利同比、市盈率这类结果指标当盯的项，估值不作支柱；没有价格模型的公司再列所属行业估值框架里的驱动（最多三个，已有数值的先列，其余只写驱动名与「影响什么」，不编数字）；原研究的支柱与不成立的条件收进「查看数据」 | 只留下一次报告 |

5. **产业链页**（`/chains/:链编号`，对象是用户自己建的链，不新增一级入口，从关注页「产业链」分段、个股页「推荐所在链」、对话推荐卡与动态、跟踪里提到的链名进入；预置链没有入口）自上而下几块，仍遵守 §1 原则：近白底、细描边、不用阴影，橙色只用在图表里的现价点，其余强调只用墨色深浅。
   - **页首**：链名（14px 标题）下一句话，写这条链从哪个环节到哪个环节、由哪几个价格连起来、链上已研究几家公司各在什么档位。
   - **链条**：上游到下游的环节横排，环节之间的箭头上写传导的价格；每个环节一张白底细描边卡：环节名、位置（上游 / 中游 / 下游）、估值方法一句话、你在这个环节关注的公司数。环节骨架、估值方法、共同驱动与逐段传导沿用公共链内容，用户只改链上放哪些公司。窄屏改竖排。
   - **共同驱动**：每个价格一行：价格名加粗，一句话说怎么传导，后面灰底标签列出影响到的环节。
   - **周期位置**（共同驱动之后，仅当链上同时有「铝价」「氧化铝」两个驱动时出现；现为煤—电—铝）：标题「现在在周期什么位置」；一句话「铝价减去氧化铝成本的价差处在近 N 年的 X% 分位，在底部 / 中位 / 高位区间」（25% 以下底部、75% 以上高位）；下面一条底部—中位—高位刻度，现在的价差是橙色点（图表里的当前值，与区间条的现价点同一种用法）；灰字小字写价差公式（沪铝 − 1.93 × 氧化铝，1.93 为每吨铝耗氧化铝的行业参考值）、现值与历史最低最高、日线期间与交易日数、不含电价与吨成本。日线读自 Backend 只读接口 `/market/futures-daily`（新浪主力连续日收盘，不复权）；氧化铝期货 2023 年 6 月才上市，不足十年时按可得年份算并在小字里写明，N 写实际年数；日线读不到只这一节写缺口加「重试」。只写位置，不写高位该怎么办、接下来盯什么。
   - **试算**（共同驱动之后，仅当链上至少一家已存的利润模型带该价格时出现；现为沪铝）：标题「沪铝变一下，链上各家利润怎么动」；一个滑块，默认现价，范围取各家研究里的近年区间并集，旁边写现价与拖离多少；每家一行：公司与环节、利润变动（亿元，带正负号）、占对比期利润比例（附对比期名）。数只用各家研究保存的利润模型（与个股页敏感性滑块同一套系数），只算该价格单独变动、其余价格不动；没有研究写「未研究」，研究里没存模型写「研究里没有利润模型」，模型缺对比期均价写缺什么，一律不估；不做吨利润公式（电价与吨成本取不到）。表格用灰字小标题、无描边、不用橙色，滑块用墨色。
   - **链上公司**：只显示这条链上你已关注的公司，按环节分小组（灰字环节名为小标题）；某环节还没有就写一句灰字「这个环节还没有你关注的公司」。每组末尾一行文字按钮「同环节还可关注」，点开列出该环节的候选（Backend 给，整条链最多 8 家，已关注的不列），一家一行：简称、代码、文字按钮「关注」；点「关注」即关注该公司并放进这条链，候选行消失、公司出现在上面。没有候选时展开处写一句灰字「这个环节暂时没有可推荐的公司」，候选读不到只写一句话加「重试」。一家一行，按环节顺序：公司名（可点进公司）、所在环节、估值档位（灰底标签，完整句「估值偏高」）、三档区间条（墨色短条标悲观—中性—乐观，现价是橙色点）、市场在赌的价格（与公司页首同一句式）。还没研究的写「尚未研究」，不在这里触发研究；已研究但缺三档价或隐含价的就地写缺什么。
   - **管理**：页首右侧灰底按钮「撤回上一版」（没有上一版时不显示）与文字按钮「删除这条产业链」；每家公司行末文字按钮「移出」，只移出这条链，不取消关注。删除前弹确认「只删除这条产业链，关注的公司和研究不受影响」。每次改动都带当前版本号：别处已改过（版本冲突）时重读这条链，并在页首下写一句灰字「这条产业链刚被改过，已显示最新内容，请再操作一次」，不静默覆盖；改动失败在原处写一句话，不弹窗。不新增状态词，主按钮仍只有一个（本页没有）。
   - 数据：链结构与驱动读行业公共层接口，公司估值读各家已存研究；任何一块读不到，只那一块写一句话加「重试」，其余照常；不写买卖建议，不出现内部用语。
6. **敏感性滑块**（样张：Artifact「华能蒙电个股页 v2」https://claude.ai/artifact/GRU97VgRrf1qMkwDxFWjzN 的神火一块）：
   - 本节的本质是解释利润：利润由哪几个变量决定、各自弹性多大；估值建立在这个利润解释上，再按行业与周期位置给倍数。
   - 变量取自公司最近一份定期报告或业绩预告自述的利润变动原因，或用户在对话中讨论并确认的变量（标明「对话确认」与日期），最多三个；有行业模型时按真实单位拖动（元/吨、分/千瓦时），初始值为当前行情，滑轨标出上期均价；无行业模型时按百分比调价格、成本、量。
   - 右侧实时显示年化归母净利、相对基数的变化与各变量贡献（正负条，红增绿减），下方给对应每股收益与现价对应市盈率；估值节区间带同步出现调整后的中性价（空心点）。
   - 计算按 Backend 给出的每单位利润系数线性相加，页面不另写公式；口径与假设一行小字写在结果下方。银行等无适用模型的类型不画滑块。

## 6. DSH 渲染的界面

DSH 原生对话与面板只通过扩展点调整（见[产品界面契约](contracts/product-ui.md) §2），不用 CSS 覆盖 DSH 内部结构；统一观感优先调整我们自己的外层容器与令牌映射。

产品默认工作细节为原生 Compact：启动时仅在 Host 用户设置缺少 `ui-chat.transcriptView` 时补写 `compact`，保留已有选择。已完成思考不显示首行预览，用户仍可手动展开；流式中仍可能预览正在进行的思考段，不更改 DSH 渲染。

## 7. 审阅清单

改界面的 Task 在验收里引用本节，Claude 审阅时逐条核对：

1. 是否新增了页面私有的颜色、卡片、面板或按钮样式（应复用令牌和公共组件）。
2. 是否出现阴影、渐变、第二层色块、左边条、装饰编号。
3. 橙色是否只用于进行中、选中、图表当前值（聚焦也不用）；按钮是否靠底色而非边框。
4. 同行卡片是否等高；控件高度是否为 32 / 28 / 22。
5. 表格里状态是否占列、数字是否右对齐、是否每行重复按钮。
6. 第一层是否只有数和一句话，是否露出内部机制。研究页：每节是否先答问题、关键数是否不超过三个、期间与出处是否收进悬停。
7. 亮暗两种主题各截图一张核对。
8. 用户可见字符串是否含内部用语（关键变量、基数期、警戒线等）：`desktop/test/ui_wording.test.ts` 的禁用词清单会拦；数值一律走格式化函数（倍数一位小数、界面不出现超过两位的小数），五档判断写完整句（「估值偏高」）。
