# 视觉设计协议

工作台所有页面（关注、个股、行业、产业链、动态、跟踪、资料、设置、任务和以后新增的对象）共同遵守的视觉规格。改界面先改本文件，再改代码；不按截图逐页修补。

样张：Artifact「工作台卡片体系」（https://claude.ai/artifact/C3GiU3WjJiskExCYDTwEUc）与「工作台外壳样张」（https://claude.ai/artifact/MJrxZZqBLSsaSwYvuoefJQ）。研究页（个股、产业链）的叙事样张为 Artifact「华能蒙电个股页原型」（https://claude.ai/artifact/UAcygS9E3WAGzzmm2D9PDf）。样张与本文件不一致时以本文件为准。设计方法参考 grok bot（本地参考源码与参数见[视觉基础过程记录](tasks/archived/工作台视觉基础_Task_2026-10-10.log.md)），只借方法，不照搬外观。

状态：2026-10-10 用户确认方向；落地见 [工作台视觉基础](tasks/archived/工作台视觉基础_Task_2026-10-10.md)（UI-0，与 T8a 导航收敛合并实施）。落地前的页面逐步迁移，新页面直接遵守。

## 1. 原则

1. **近白底，细描边，不用阴影。** 外框（图标栏）浅灰，内容区近白，卡片白底加一圈淡描边；层次靠底色深浅和圆角，不靠阴影和分隔线。
2. **一个墨色派生所有灰。** 文字、底色、描边都是同一个墨色的不同透明度；不再单独定义灰、粉、浅橙。
3. **按钮靠底色，不靠边框。** 次要按钮是灰底全圆胶囊，主按钮是墨色；只有输入类控件（搜索、下拉）用细描边。一个区域最多一个主按钮。
4. **橙色只做三件事：** 进行中、选中、图表里的当前值。涨跌用红绿（A 股红涨绿跌）；对象类型色只用在小图标上。
5. **组名在卡片外，卡片里一行一项；同类卡片骨架固定、同行等高。** 缺内容时保留位置，布局不随数据跳动。
6. **第一层只放数和一句话。** 解释、条件、出处点开再看；不展示内部机制（计算标签、口径术语、版本号、系统提示横幅）。
7. **研究页先回答问题，再给数据。** 每节标题是一个问题，第一句是带数字的回答；数字嵌在句子和图里，不平铺成指标墙。

## 2. 颜色

所有颜色定义在 `desktop/src/index.css` 的亮暗两套变量里，页面只引用变量。

| 令牌 | 亮色 | 用途 |
|---|---|---|
| 墨色 `base` | `#161a22`（暗色 `#eceef2`） | 正文与主按钮；其余灰全部由它派生 |
| 外框 `chrome` | `#f6f7f8`（暗色 `#111316`） | 图标栏所在的最外层 |
| 内容区 `surface` | `#fcfcfc`（暗色 `#16191d`） | 页面底 |
| 卡片 `raised` | `#ffffff`（暗色 `#1c2025`） | 卡片、表格容器、弹层 |
| 文字 | 墨色 100% / 72% / 48% / 34% | 正文 / 次要 / 辅助 / 占位与空值 |
| 底色 | 墨色 6% / 10% / 16% | 悬停与标签 / 次要按钮与选中分段 / 按钮悬停 |
| 描边 | 墨色 8% / 12% / 20% | 行间分隔 / 卡片与输入框 / 悬停卡片 |
| 强调 `brand` | `#e3561f`；浅底为其 12% | 进行中、选中、图表当前值 |
| 语义 | 涨 `#d23c3c`、跌 `#1e9a57`、注意 `#c27c12`、信息 `#2f6fde` | 只表达语义 |
| 对象类型 | 个股蓝、行业紫、产业链青、资料橙褐 | 只用于小图标块里的图标或文字 |

派生写法：`color-mix(in srgb, var(--base) 12%, transparent)`。暗色主题只换墨色、外框、内容区、卡片四个值，派生比例不变。

## 3. 尺寸

| 项 | 规格 |
|---|---|
| 控件高度 | 按钮与搜索 32；小按钮、下拉、分段、图标按钮 28；状态胶囊与标签 22；状态点 7 |
| 圆角 | 卡片、表格容器、弹层 16；下拉、图标按钮、小图标块 8；标签 6；按钮与胶囊全圆 |
| 字号 | 页标题 24–26（600）；卡片与面板标题 14（600）；指标 22（600）；正文 13；辅助 12；代码 11 等宽 |
| 间距 | 4 · 8 · 12 · 16 · 20 · 24；卡片内边距 16–20；卡片间距 12；区块间距 28–44 |

数字一律等宽数字（`tabular-nums`）。

## 4. 外壳与页面骨架

1. 外壳：左侧图标栏放在外框上，六个两字入口（对话、动态、跟踪、关注、资料、设置），选中项用 10% 底色；右侧内容区为近白的大圆角面，1px 淡描边。
2. 页首：左侧标题，右侧搜索与一个主按钮；不放面包屑、橙色小标题和装饰性说明。
3. 主体：区块纵向排列；区块组名用 12–13px 灰字放在卡片或表格外的左上方，右侧可放一句说明或时点。
4. 桌面包（macOS）：只在 `html[data-platform='darwin']`（全屏即 `data-fullscreen='true'` 时除外）下，外壳顶部留一条窗口按钮带（36px），左栏与各页标题都从带下开始，不压红黄绿按钮；该带标 `data-window-drag`，可拖动窗口，带内没有控件。Web 没有该属性，外观不变。
5. 页尾：免责声明为一行灰字，不加框，只在研究类页面出现。

## 5. 组件

### 按钮与控件

- 主按钮：墨色底、白字、全圆，32px。
- 次要按钮：10% 底色、无边框、全圆；悬停 16%。小号 28px。
- 文字按钮：无底，次要文字色；悬停加 6% 底色。
- 图标按钮：28px 方形、8 圆角、无底；悬停加底色。
- 输入类：搜索全圆、下拉 8 圆角，都是 12% 描边加白底。
- 面板输入框（问助手）与 DSH 主对话输入框同款：无描边或墨色 8% 描边、柔和阴影、圆角与主输入框一致（16）；聚焦时不出现品牌色描边。这是原则 1「不用阴影」的唯一例外。
- 聚焦不用品牌色：文本输入（input、textarea、select）聚焦只靠自身描边或阴影变化（描边升到墨色 20%），不加外框；按钮与链接仅键盘聚焦（`:focus-visible`）显示 2px 墨色 20% 外框。
- 资料阅读页只有一个提问入口：选中文字后在浮动工具条（复制旁）出现「问助手」，点了才把原文放进问助手的「已选原文」（默认收起成一行）；阅读器底部不再设「追问范围 / 就此追问」条。面板标题已是文档名时不再另显文档标题标签；「问问这个页面」说明卡关掉后不再出现。
- 分段切换：无底文字，选中项 10% 底色。
- 开关：开为品牌橙，关为 16% 底色。
- 删除类动作进「⋯」菜单，不和常用动作并排。

### 分组卡

组名在卡片外；卡片里一行一项，左边名称和一行说明，右边控件或数值；行间 8% 分隔线。用于设置、个股页信息区、资料详情。

### 对象卡

三行骨架：`grid-template-rows: auto 1fr auto`，同类统一 `min-height`。

| 行 | 内容 |
|---|---|
| 头部 | 小图标块（30px、对象类型色）+ 名称（14px）与代码或类别（11px 等宽灰）；右侧关键数（现价与涨跌）或状态胶囊 |
| 主体 | 一句话（最多两行）+ 一条数据线；没有内容时显示状态胶囊或「关注后自动研究」，高度保留 |
| 底部 | 左：时点或关联；右：进入链接（灰，悬停加深） |

各对象的数据线：个股为近 60 日走势线（当前点用品牌橙）；行业为关注公司数、画像状态、更新时间；产业链为上游到下游的环节标签，利润最集中的环节用墨色加深底（橙色只做进行中、选中、图表里的当前值）；动态卡没有数据线，主体只放一句话。需要提醒的卡片靠置顶与第一句话区分，不用描边色或底色。

财报到达对账卡：关注公司最近 14 天内披露了新的季度报告时（不管研究是否已经用上这份季报，价格部分始终按已存研究的系数算），动态「行情」分段在跳档提醒之后出一张对账卡，不描边。第一层一句话：「神火三季报：单季净利润 27.05 亿元，比上季多 2.14 亿元」；有价格模型时再加半句「沪铝、氧化铝变化约带来 +1.20 亿元，其余 +0.94 亿元来自量和成本等，报告未单独披露」；展开看各价格的本季均价、上季均价与贡献，没算进去的因素逐个说明。解释的是环比变化，不写准确度，不写买卖建议；没有价格模型的公司只写与上季的差额。

Jev 判断：Backend 的 Jev 读到某条新闻碰到公司哪个估值驱动时，那一句改写成「碰到沪铝：对利润偏负面」（偏正面 / 偏负面 / 影响不明三种，不写利好、利空，不写买卖建议），有价格模型且有每步影响的保留数值半句「；每 +1,000 元/吨，净利润 +9.96 亿元」；Jev 没读到（首次读取、没开、失败）时仍用下面的关键词句。同一事件的改写合并成最早的一条，标题后加灰底标签「另有 N 篇报道」；同一事件的新进展加灰底标签「新进展」。公告默认只显示可能影响估值的，Jev 判为例行的收起，列表上方出现一个文字按钮「查看全部（另有 N 条例行）」，点开后例行的加灰底标签「例行」，按钮变成「只看重要的」。三种标签都是灰底，不用橙色，不描边。

驱动说明：动态里的新闻标题碰到公司价格变量时写原来的一句（「碰到沪铝：每 +1,000 元/吨，净利润 +9.96 亿元」）；公司没有价格模型时，碰到所属行业框架的驱动写「碰到净息差：影响利润和净资产，进而影响市净率」，同一条只写一句、价格变量优先，不判断方向、不读正文。跟踪页「研究」里没有价格模型的公司那行加一句「盯：净息差、不良率」。驱动名取行业框架的名字（去掉括号注释），营业收入、净利润、毛利率、市盈率、市净率、股息这类结果指标不当驱动。

跳档提醒：关注公司的主价格接近或越过研究里的跳档价时，动态「行情」分段置顶一张提醒卡（越过在前、接近在后，样式与普通动态卡一致，不描边、不加「接近 / 越过」标签，句子本身已说明），跟踪页「研究」里该公司那行同步写同一句；平时不出现。句式：越过写「沪铝跌破 22,500 元/吨，神火估值从偏高变为明显高估」，接近写「沪铝距 22,500 元/吨只差 1.2%，越过后神火估值会从偏高变为明显高估」；只写估值事实，不写买卖建议；原档取已存研究，新档由跳档边界推出，推不出时写「估值判断会改变」。
开始观察：对话回答末尾的推荐可以是「开始观察」（与追问、关注公司推荐三选一，每次最多一条）。一行：左边「开始观察：{指标名}」，下一行灰字写为什么重要（观察要验证的那句判断），右边灰字状态「开始观察」；点一下就建成一条观察项，成功后变「已在观察」，失败在下面写一句灰字，已经在观察的重新打开对话也直接显示「已在观察」。跟踪页在「正在盯的」与「研究」之间多一组「正在观察」：一行一项，粗体写指标，下面灰字「为什么重要 · 下一个来源：…」（没有来源就不写）；没有观察项或读取失败时整组不出现。界面不出现议题、tracking、indicator 这类内部词，也不写买卖建议；观察项的定期评估与提醒不在这里。

### 表格

装进描边圆角容器（白底、12% 描边、16 圆角）。表头 12px 灰字；行间 8% 分隔线；悬停行 6% 底色。

| 元素 | 呈现 | 原因 |
|---|---|---|
| 字段值 | 纯文字；数字右对齐、等宽 | 同列比较是主要用途，加框打断对齐 |
| 类别 | 有列头时纯文字；无列头列表里用浅底标签 | 列头已说明含义；无列头时用来区分属性与标题 |
| 状态 | 名称后 7px 圆点，悬停出文字，不单独占列，正常不显示 | 多数行正常，单列大片空着 |
| 默认币种、市场 | 不显示 | 不提供信息 |
| 行主动作 | 点整行或名称进入 | 每行重复大按钮是最大噪音 |
| 次要动作 | 行尾图标按钮，悬停该行才出现；删除进「⋯」 | 平时不抢视线 |

### 无列头列表

任务、动态、最近对话：标题前状态点，对象用品牌橙浅底标签，时间与用时用灰底标签，动作是行尾文字按钮。

### 面板与指标

页面每节一块面板：标题（14px）与右侧期间或出处，下面一句话结论，再下面是数据。指标：12px 灰标签 + 22px 数字；期间与出处放在悬停提示里，只在期间与同节其他数字不同时，标签后加一个期间胶囊。图表配色用墨色深浅表示一般项，品牌橙只标当前值或重点项。

同一页上同一个量只有一种说法：「现价」一律用页首实时价，数据包快照价只在「查看数据」里并标日期；市盈率区分「近四季」（实际净利润）与「按估算利润」（利润试算），悬停说明差别；期间统一写成「2025 年报、2026 半年报、2026 三季报、近四季（截至 2026 三季报）」；百分号紧跟数字（23.35%）；句中数字用正文字体加粗，不用等宽；缺现金分红总额但有每股分红时按「每股分红 × 总股本」估算并标明；三档估值每行用同一个主价格讲，其他因素取值收进展开。三档价（模型行、档位行、区间带标签、三档表）统一截断到两位小数，不四舍五入，同一个价同页只有一种写法。

### 状态

- 状态点：进行中品牌橙、未完成注意色、有新资料或提示墨灰（蓝色不在色板，只留给链接与对象类型小图标）、完成绿；正常不显示。
- 状态胶囊：22px，浅底加同色文字，用于卡片主体或工具栏旁。
- 同一状态在同一块里只出现一次；名单、工具栏、页内进度属不同层级。

### 加载、空与失败

- 加载：骨架条占住最终位置；研究类内容保留已验收的扫描动画。
- 空：一句话说明会出现什么、怎么产生，配一个主按钮；整节无数据时不渲染该节。
- 失败：已到的数据照常显示，失败部分一句话加「重试」；可选部分失败直接不显示，诊断进日志。

### 关注页对象分段

关注页分段「个股 / 产业链」，不新增一级导航。个股分段仍是自选公司列表。产业链分段列出全部链（名称、上游到下游的环节、链上已关注公司数），点进 `/chains/:id`，不触发研究。关注为空时，第一次打开空态只出现在个股分段；切到产业链分段仍能看见全部链。

### 第一次打开

个股分段在关注列表为空（且没有在搜索）时，不出现表格和页首搜索，只放一块居中的空态；已有关注的用户看不到它。分段「个股 / 产业链」在空态时也保留。

1. **一句话**：标题（页标题字号）「你在关注哪些公司？」，下一行一句灰字说产品做什么：「输入公司名称或代码，我们会自动研究它：靠什么赚钱、哪些价格影响利润、现在的价格在赌什么。」
2. **一个输入框**：搜索同款全圆、12% 描边加白底、32px，右侧一个主按钮「开始」（本页唯一的主按钮）；回车等同点击。名称只匹配已研究过的公司，代码按现有规则解析（只支持 A 股）；没认出来时输入框下一行灰字说明，不弹窗。
3. **示例**：输入框下 2–3 个灰底胶囊按钮，写已研究过的公司名（神火股份、长江电力、农业银行），点一下等同输入并开始；没有已研究过的公司时不显示这一行。
4. **选中之后**：加入关注与研究名单，直接进入该公司个股页；研究由个股页自己开始，进度显示在页首，空态页不另做进度。
5. 本版不推荐同链公司、不做多步引导；橙色不出现在空态。

### 关于我

设置页第一个分段，分段为「关于我 / 模型 / 连接」，默认进入「关于我」。助手记得的关于用户的事只有一张列表，不分卡、不显示分类。

1. **顶部输入框**：搜索同款全圆输入加「记下」次要按钮；回车等同点击，空输入不提交；记下后清空输入框，新条目出现在列表最上面。
2. **列表**：分组卡，一行一条：左边一句话，下一行灰字写来源与日期（自己填写、对话里说的、从对话中推断、自己改过）；对话里说的来源可点，打开那次对话；右边文字按钮「删除」，删除即生效，不弹确认。按更新时间倒序，没有时间的排最后。
3. **说明**：列表下一句灰字「不对的直接删掉，助手以后不再按它来。」；没有条目时一句灰字说明怎么产生（在对话里说“记住：…”，或在上面的输入框里补充）。
4. **用语**：标签用「我」，说明文字不带人称；不出现 soul、recent、stance 等内部词。不做原地改字（删了重记）；议题建议不在本页。
5. 不用橙色，不描边行，不加状态胶囊。

### 研究页叙事结构（个股、产业链）

1. **页首**：名称、代码、实时价格与涨跌；下一行一句话定性（研究的 thesis）；再下一行「完整判断：市场在赌 X 约 N，现在 M」（如「估值偏高：市场在赌沪铝约 23,258 元/吨，现在 22,970 元/吨」；隐含价缺失时只写完整判断，缺口原因进「查看数据」；若主价格距最近的跳档价不超过 3%，句末加半句「跌破 / 涨过 X，判断变为 Y」；Y 由跳档边界和价格涨跌方向推出：按明显低估 < 偏低 < 合理 < 偏高 < 明显高估的顺序，利润变大时估值往低档走，推不出时写「判断会改变」）；主变量单位是 % 时（取值是相对对比期的变动，不是价格）写「估值合理：市场在赌境内水电发电量比对比期低约 0.5%」，隐含值不到 0.05 写「与对比期持平」，不写「现在」，跳档半句写「境内水电发电量再升 2.0%，判断变为…」，距离按百分点算、3 个点内才写；市场隐含值超出近年区间（Backend 标 `within_range` 为假）时照写数值并说明：「估值偏低：按现价，市场隐含的沪铜约 80,000 元/吨，低于近年区间」，没有该字段时保持原写法。「接下来盯什么」里单位为 % 的变量不写「0 %」，写「持平 / 高 x% / 低 x%」，说明里写「与对比期持平」或「比对比期高 / 低 x%」；最后一行最近一次判断变化（日期 + 资料 + 判断是否改变，可撤回）；没有变化时写「研究于某日，资料未变化」。
   页首「最近一次判断变化」同处另写一行灰字「数据截至 2026 年三季报」，取数据包的 `page_period`（年报、半年报、一季报、三季报），旧 Backend 没有该字段时不写。第一层数字与页面报告期不同期时（分部只到半年报、分红按上一年度方案），就在数字旁用灰色小字标出自己的期间（「2026 年半年报」「2025 年度方案」），同期的不标，市场时点（现价、市盈率）不算报告期。
   页首再下面一行「我的看法：{原句}」，后接灰字「{来源} · {日期}」（来源与「关于我」列表同一套：对话里说的、自己填写、自己改过）：取自「关于我」里用户自己说过或改过、正文含这家公司名（或去掉「股份」的简称、6 位代码）的条目，推断的不算；最多 2 条，按时间倒序，其余收成「另有 N 条」链到设置；没有或读取失败整行不出现。只并列摆放，不比较、不评判对错，不改论点与档位；灰字正文，不描边、不用橙色。
2. **每节**：问题标题 → 一句带数字的回答 → 一个专用图 → 「查看数据」展开其余指标。第一层每节最多三个关键数；整节无数据时只留回答句或不渲染。
3. **句中数字**：正文里的数字由页面按字段填入，与正文同字号、加粗、等宽数字；悬停显示期间、口径与出处；缺口显示灰色「暂缺」，不留空。
4. **个股页五节**（问题文字可按公司类型微调）：

| 节 | 问题 | 专用图 | 无数据时 |
|---|---|---|---|
| 生意 | 它靠什么赚钱 | 第一层关键数：各业务毛利（分部收入 − 分部成本，亿元），最多三项按毛利排序；没有分部成本的公司只写各业务收入，缺口写进「查看数据」；不放单独的成本或收入；名称含「其他、抵消、内部、合并调整」的分部，以及毛利为负且收入占比不到 5% 的分部不上第一层，只在「查看数据」里列出 | 只留回答句 |
| 关键变量 | 关键变量动一下，利润变多少 | 公式行（利润 ≈ 各驱动项）在上，敏感性滑块（见第 6 条）在下 | 公式用行业通用式，滑块换单季营收与归母净利柱图 |
| 现金 | 利润是不是真金白银 | 去向条：经营现金流 → 资本开支 → 分红 → 剩余 | 已有项照画，缺项灰色 |
| 估值 | 现在的价格在赌什么 | 区间带：现价落在悲观—中性—乐观三档价的位置，回答句给出现价隐含的主变量取值（市场在赌什么）；每档写明关键变量取值 → 利润 → 倍数（倍数按行业与周期位置给出理由）；区间带上方三行预期对比，每行一句话加一个数：「机构预期：2026 年每股收益 4.12 元（4 家）」（研报一致预期，少于 3 家加「样本少」；没有写「暂无机构预期」，不估）、「模型：中性价 26.81 元/股，估值偏高」、「股价隐含：市场在赌沪铝约 24,100 元/吨，现在 23,465 元/吨」（隐含值越出近年区间时照写并说明）；三行下一句差异，把三方折成同口径的每股收益（机构预测；模型中性价对应的预测利润÷股本；现价÷中性倍数），只写分歧最大的一方比另外两方高或低多少，三者相差不到 5% 就写相差不到 5%，不写买卖建议；「股价隐含」行写「暂无」时，差异句同样不纳入股价隐含（只比剩下两方，只剩一方不写差异句），三行与差异句说的是同一件事；机构预测年与模型利润期间不同时，差异句末尾加「（机构为 2026 年预测，模型按近 12 个月利润，口径不同）」，期间按实际写，相同不加，不换算；期间码（FY2026E、TTM:2026Q3）在页面与「查看数据」里一律写成中文（2026 年预测、近四季（截至 2026 三季报））；三档里某一档因亏损等原因没有价，只那一档在档位行与「查看数据」的三档表里写「亏损，不给价」（不上区间带），其余两档与模型行照常，不整表丢；来源与期间收进「查看数据」；三行是灰字正文，不描边、不用橙色；下方五档结论与市盈率、市净率、股息率三个数 | 无三档价时只显示五档与三个数 |
| 跟踪 | 接下来盯什么 | 盯的卡：每张一句话加一个数。先列利润模型里的价格（现价、比对比期均价高低多少、对利润的影响，附每涨跌一档利润变多少），没有价格模型时列行业驱动项的当前值；最后一张是下一次报告（「三季报最晚 10-31 披露」，按法定截止日）。不拿毛利率、净利同比、市盈率这类结果指标当盯的项，估值不作支柱；没有价格模型的公司再列所属行业估值框架里的驱动（最多三个，已有数值的先列，其余只写驱动名与「影响什么」，不编数字）；原研究的支柱与不成立的条件收进「查看数据」 | 只留下一次报告 |

5. **产业链页**（`/chains/:链编号`，不新增一级入口，从关注页「产业链」分段、个股页「所属产业链」与动态、跟踪里提到的链名进入）自上而下几块，仍遵守 §1 原则：近白底、细描边、不用阴影，橙色只用在图表里的现价点，其余强调只用墨色深浅。
   - **页首**：链名（14px 标题）下一句话，写这条链从哪个环节到哪个环节、由哪几个价格连起来、链上已研究几家公司各在什么档位。
   - **链条**：上游到下游的环节横排，环节之间的箭头上写传导的价格；每个环节一张白底细描边卡：环节名、位置（上游 / 中游 / 下游）、估值方法一句话、链上公司数。窄屏改竖排。
   - **共同驱动**：每个价格一行：价格名加粗，一句话说怎么传导，后面灰底标签列出影响到的环节。
   - **周期位置**（共同驱动之后，仅当链上同时有「铝价」「氧化铝」两个驱动时出现；现为煤—电—铝）：标题「现在在周期什么位置」；一句话「铝价减去氧化铝成本的价差处在近 N 年的 X% 分位，在底部 / 中位 / 高位区间」（25% 以下底部、75% 以上高位）；下面一条底部—中位—高位刻度，现在的价差是橙色点（图表里的当前值，与区间条的现价点同一种用法）；灰字小字写价差公式（沪铝 − 1.93 × 氧化铝，1.93 为每吨铝耗氧化铝的行业参考值）、现值与历史最低最高、日线期间与交易日数、不含电价与吨成本。日线读自 Backend 只读接口 `/market/futures-daily`（新浪主力连续日收盘，不复权）；氧化铝期货 2023 年 6 月才上市，不足十年时按可得年份算并在小字里写明，N 写实际年数；日线读不到只这一节写缺口加「重试」。只写位置，不写高位该怎么办、接下来盯什么。
   - **试算**（共同驱动之后，仅当链上至少一家已存的利润模型带该价格时出现；现为沪铝）：标题「沪铝变一下，链上各家利润怎么动」；一个滑块，默认现价，范围取各家研究里的近年区间并集，旁边写现价与拖离多少；每家一行：公司与环节、利润变动（亿元，带正负号）、占对比期利润比例（附对比期名）。数只用各家研究保存的利润模型（与个股页敏感性滑块同一套系数），只算该价格单独变动、其余价格不动；没有研究写「未研究」，研究里没存模型写「研究里没有利润模型」，模型缺对比期均价写缺什么，一律不估；不做吨利润公式（电价与吨成本取不到）。表格用灰字小标题、无描边、不用橙色，滑块用墨色。
   - **链上公司**：一家一行，按环节顺序：公司名（可点进个股页）、所在环节、估值档位（灰底标签，完整句「估值偏高」）、三档区间条（墨色短条标悲观—中性—乐观，现价是橙色点）、市场在赌的价格（与个股页页首同一句式）。还没研究的写「尚未研究」，不在这里触发研究；已研究但缺三档价或隐含价的就地写缺什么。
   - 数据：链结构与驱动读行业公共层接口，公司估值读各家已存研究；任何一块读不到，只那一块写一句话加「重试」，其余照常；不写买卖建议，不出现内部用语。
6. **敏感性滑块**（样张：Artifact「华能蒙电个股页 v2」https://claude.ai/artifact/GRU97VgRrf1qMkwDxFWjzN 的神火一块）：
   - 本节的本质是解释利润：利润由哪几个变量决定、各自弹性多大；估值建立在这个利润解释上，再按行业与周期位置给倍数。
   - 变量取自公司最近一份定期报告或业绩预告自述的利润变动原因，或用户在对话中讨论并确认的变量（标明「对话确认」与日期），最多三个；有行业模型时按真实单位拖动（元/吨、分/千瓦时），初始值为当前行情，滑轨标出上期均价；无行业模型时按百分比调价格、成本、量。
   - 右侧实时显示年化归母净利、相对基数的变化与各变量贡献（正负条，红增绿减），下方给对应每股收益与现价对应市盈率；估值节区间带同步出现调整后的中性价（空心点）。
   - 计算按 Backend 给出的每单位利润系数线性相加，页面不另写公式；口径与假设一行小字写在结果下方。银行等无适用模型的类型不画滑块。

## 6. DSH 渲染的界面

DSH 原生对话与面板只通过扩展点调整（见[产品界面契约](contracts/product-ui.md) §2），不用 CSS 覆盖 DSH 内部结构；统一观感优先调整我们自己的外层容器与令牌映射。

产品默认工作细节为原生 Compact：启动时仅在 Host 用户设置缺少 `ui-chat.transcriptView` 时补写 `compact`，保留已有选择。已完成思考不显示首行预览，用户仍可手动展开；流式中仍可能预览正在进行的思考段，不更改 DSH 渲染。

## 7. 审阅清单

改界面的 Task 在验收里引用本节，Claude 审阅时逐条核对：

1. 是否新增了页面私有的颜色、卡片、面板或按钮样式（应复用令牌和公共组件）。
2. 是否出现阴影、渐变、第二层色块、左边条、装饰编号。
3. 橙色是否只用于进行中、选中、图表当前值（聚焦也不用）；按钮是否靠底色而非边框。
4. 同行卡片是否等高；控件高度是否为 32 / 28 / 22。
5. 表格里状态是否占列、数字是否右对齐、是否每行重复按钮。
6. 第一层是否只有数和一句话，是否露出内部机制。研究页：每节是否先答问题、关键数是否不超过三个、期间与出处是否收进悬停。
7. 亮暗两种主题各截图一张核对。
8. 用户可见字符串是否含内部用语（关键变量、基数期、警戒线等）：`desktop/test/ui_wording.test.ts` 的禁用词清单会拦；数值一律走格式化函数（倍数一位小数、界面不出现超过两位的小数），五档判断写完整句（「估值偏高」）。
