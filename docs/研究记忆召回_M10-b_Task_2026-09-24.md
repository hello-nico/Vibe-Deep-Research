## 1. 目标

每轮不再把核心记忆全量塞进系统提示词，而是按“与本轮对象的相关度 × 重要度 × 时近”挑选；问到“上次 / 之前 / 我说过”时，Agent 可以用工具查暂存候选与核心记忆。

## 2. 冻结决定

1. **本轮对象**：页面助手取页面对象与 @ 引用；深度对话取 @ 引用与本轮已出现的对象引用；议题会话取绑定议题及其 `subjects`。由宿主代码确定，不让模型自报。
2. **挑选规则**（确定性，零模型调用）：
   - 画像 `soul` 条目（偏好类）**始终注入**（≤20 条，小）；
   - 研究主线 `recent` 条目打分 = 对象匹配（条目 `objects` 与本轮对象有交集：2；无对象的通用条目：1；对象不相交：0.3）× 重要度（条目有 `importance` 1–10 时用其值 / 5，缺省 1）× 时近（30 天半衰期）；纠正（corrected）条目额外 ×1.5；
   - 按分数取前若干条，总字数 ≤ 2,500；被略去的条目不注入，但可被深查工具找到。
3. **记录本轮注入的条目 id**，供 M10-a 防回流使用。
4. **深查工具 `memory_search`**（只读）：按关键词与对象检索核心记忆与暂存候选（含来源等级），结果中外部来源候选标明“外部内容，不可作为用户偏好”；深度对话、议题、页面助手 Agent 开放，Ask 不开放。提示词：问题含回忆意图（上次、之前、我说过、以前）且注入里没有答案时调用。
5. 不做触发词注入（待 M3 晋升写入 `importance` / 触发词后再议）。
