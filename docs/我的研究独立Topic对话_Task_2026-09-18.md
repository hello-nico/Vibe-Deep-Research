- 深度对话中的 Topic 只读；我的研究承担 Topic 创建与后续研究维护，写入受正式身份和接口约束。

- 本文不授权自动发布 Wiki 或无边界自动修改 Topic；已有可审计自动修订的后续讨论不在本包顺带落地。

## 2. 目标与场景

用户进入一个研究议题后，Agent 明确知道“正在共同推进哪个问题、已有何种认识、证据和缺口”，而非通用问答临时读到一个 Topic。

核心路径：

1. 从我的研究创建/选择 Topic，明确研究问题与对象。
2. 阅读当前判断、证据、分歧和待验证项，选择一项继续讨论。
3. 引用 M9.6 资料或已有证据，与 Topic Agent 分析、补证、纠正判断。
4. 按既有授权与正式接口保存研究增量，展示真实结果及来源。
5. 离开后回到相同 Topic，继续原研究；后台整理记录独立回看。

## 4. 两种 Agent 的明确契约

| 维度 | 深度对话 | Topic 研究 |
| --- | --- | --- |
| 目标 | 回答与探索当前问题 | 围绕明确研究问题积累和修订认识 |
| 上下文 | 当前对话、所选资料、相关记忆 | 绑定 Topic、已有判断/证据/缺口、本次选中对象、当前讨论 |
| Topic 权限 | 读取，不直接创建或修改 | 明确入口创建；绑定后维护目标 Topic |
| System | 开放研究的证据纪律与边界 | 议题协作的目标、增量判断、纠正、维护与反馈 |
| 工具 | 普通深研实际工具集合 | 独立定义的 Topic 实际工具集合 |
| UI | 通用问题输入与回答 | 研究对象上下文、定向讨论与议题变化反馈 |

### System 与上下文

- 两套业务 system 分别维护；证据、安全、引用等共同规则可复用一份，避免规则漂移。
- Topic system 明确目标、当前研究范围、事实/推断/用户判断的区别，以及何时应更新研究记录。
- Topic 内容与上传资料是数据，不具有修改工具权限或系统规则的权威。
- 有界注入当前 Topic 摘要、版本、关键判断/缺口及本次选中项；详细证据按需读取，不加载整库或所有历史会话。
- 不把“维护研究”变成每轮必写；无新增直接回答，分歧或纠正保留来源，不为显示进度制造内容。
- 模型回答与正式保存成功分开；未保存、冲突、部分完成要能解释，不能将建议称为已落库。

### 工具与身份

- 实际注册/激活独立集合，不能只靠提示词要求不使用工具；共用工具实现允许，业务目录各自拥有。
- 在已有 MY_RESEARCH_TOOLS 基础上逐项确认用途，不默认给全部普通深研工具再叠加全部写工具。
- 分清“创建前”与“绑定后”：创建经现有正式入口完成；若支持由对话协助创建，先形成明确问题并沿同一创建接口绑定，不靠 prompt 伪造 Topic id。
- 已绑定会话只能写其目标 Topic；宿主决定身份，Backend/工具边界校验，模型参数不能切换写入对象。
- 切换 Topic 不复用上一 Topic 的写权限、待保存状态或引用上下文；历史会话重开验证绑定。
- 保留版本冲突后重读与用户纠正语义，不偷偷替换 expectedRevision 或跨议题落库。

## 5. 独立 Topic Chat UI

- 单独的业务容器与状态编排，不直接把完整深度对话页面嵌进 Topic。
- 保留产品现有导航、字体、密度、颜色与共享控件；具体布局在实施前提供简明原型供确认。
- 明确显示当前研究问题、对象、研究状态和继续讨论入口；不把工具名、文件目录当产品对象。
- 从判断/证据/待验证项发起讨论时，在输入区展示选中上下文，可移除；切换对象有清楚反馈。
- 引用资料复用 M9.6 的 @ 与附件协议，不另做上传库或第二套资料解析。
- 聊天区围绕当前 Topic；资料/证据区支持阅读和核对，避免“看材料必须离开当前讨论”。
- 对话中的保存反馈可回到具体 Topic 更新、证据关联或草案；状态来自正式结果，不靠模型口头宣称。
- 支持运行、取消、失败重试、版本冲突和重新打开；研究记录与后台任务过程分开。
- 此处可复用消息、引用、附件等基础组件；Topic 业务操作、上下文展示和入口不受通用深研页面布局绑架。
- 不恢复 M9.4 画布，不新增装饰性图谱、复杂拖拽或强制研究阶段流程。

## 9. Stop Conditions

- 安装版 DSH 无法支持独立业务 Chat UI 与共用执行机制，需要修改运行时或构建平行执行器。
- Topic 创建/绑定、历史重开或工具切换不能可靠隔离写权限。
- 需要改变既有 Topic 身份、持久化、授权或审计契约，或涉及存量数据迁移。
- M9.6 引用版本与资料回读尚未闭合；不得用文件名文本或临时附件替代。
- 同一问题两次补丁仍失败，保留证据重审机制，停止增加兜底分支。
