## A. 深度对话行情图

- 示例：「查华能国际最近的行情数据」。识别唯一公司后调用正式行情工具，回答直接显示 K 线及简短说明，不要求先选择图型或 Provider。
- 卡片支持区间切换、悬停日期／价格、均线与成交量联动；可展开，窄屏仍能操作。
- 数据表显示同区间日期、开高低收、成交量／额及已展示均线，注明来源、更新时间、复权和单位。
- 已取范围内切换区间不重新取数；超出范围明确加载。均线预热历史与显示窗口分开，不能因窗口截短改变同日均线。
- 数据不足明确显示缺口；只有收盘价时可以显示折线，但不能标成 K 线已完成。

## B. 财务分析与统一图数交互

- 首例拟采用「华能国际利润改善是否有现金流支撑」，复用现有 Skill 和确定性计算，先核对真实字段可得性。
- 按数据选择同期利润／经营现金流趋势，以及资本开支／自由现金流比较；不满足加减分解关系时不画瀑布图，不新增未经定义的质量评分。
- 年度、累计、单季、TTM 不混用；同业比较先对齐期间、单位和口径，保留未披露与数据缺口。
- 所有图形统一提供「图表｜数据」或查看驱动数据按钮，展开后仍可切换。图与表消费同一结果，筛选同步；切换不重新取数、不由模型重写数字。
- 图上允许缩写，表格保留源数据或确定性计算结果的精度，注明单位、报告期和舍入规则；缺失显示“—”，与零区分。
- 聚合图的数据视图显示对应聚合结果，并可查看参与聚合的明细。计算指标可查看输入、口径和来源，不把结果表冒充原始数据。
- 悬停是快捷读数，不能替代完整数据表；关键结论和数字保持直接可见，依据沿 M6-B 入口回读。

## Owner 与成果生命周期

| Owner | 责任 |
| --- | --- |
| Stock Backend | 数据、计算、来源绑定，以及沉淀成果和对象关联的业务写入；不自动授予 Evidence 身份 |
| Agent／研究 Skills | 根据问题选择分析及表达，调用正式工具；不编数据、计算结果或任意脚本 |
| Finance 成果组件 | 受控图型和报告布局、图数切换、展开、来源交互；不重复财务计算 |
| DSH | 原生执行、取消、持久消息身份、展示组合与 Session 生命周期 |
| FinanceShell | 容器、主题、宽窄屏及展开位置，不生成或保存研究内容 |

- 先核对原生文件成果与 Backend 现有保存机制，确定最小成果契约；不新增 Artifact 数据库或第二套 Topic／Wiki。
- 保存的成果须能回溯业务对象、数据期间／截至日、来源、计算输入／结果及展示配置；具体字段归对应模块契约，不在本 Task 发明通用协议。
- 结果校验并保存成功才挂到消息；失败、取消和损坏不得显示完成。一个回答可有多个成果，且与原生文件成果共存。
- 历史重开默认恢复当时数据快照；显式更新产生新结果，不篡改旧引用。对象报告注明所用数据日期，不静默刷新数字。
- 关联 Topic／Wiki 沿现有写入与审阅发布流程；浏览、图数切换、展开均不触发研究写入。
- 来源缺失、目标删除、重复生成和并发更新的语义在实施前由所属存储／关联契约补齐，不用前端缓存掩盖错误。
