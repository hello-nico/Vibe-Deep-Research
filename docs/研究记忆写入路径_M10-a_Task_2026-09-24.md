# 研究记忆写入路径：来源等级、污染标记与暂存（M10-a）

权威：[Human Checklist](../human-checklist.md)「研究记忆机制 v2（2026-09-24）」；[设计稿](研究记忆机制v2_设计_2026-09-24.md) §3.1–3.2（M1 + M2）。

## 1. 目标

记忆不再由知识整理每轮直接写入核心记忆（画像 `soul`、研究主线 `recent`）；改为写入**暂存区**，每条候选带**代码标注的来源等级**。只有用户在对话里明确要求记住的内容可直写核心记忆。为后续晋升（M3）准备好干净、可追溯的候选。

## 2. 现状（Claude 核实）

- 写入：Stock `dsh/src/background-review.mjs` 知识整理输出 `memoryOps`（`target: soul|recent`、`op`、`stance: stated|inferred|corrected`、`text`），`applyMemoryOps` 直接 `PUT /wiki/research-memory`（Backend `app/services/research_memory.py`，CAS 版本号，条数 / 字数上限）。
- 注入：`dsh/src/research-tools.mjs` `formatMemoryPrompt` 每轮把两份全量注入系统提示词（≤4,000 字）。
- 记忆页：Vibe「我的研究 · 记忆」（`MemoryPanel`）展示与编辑核心记忆、议题候选。

## 3. 冻结决定

1. **暂存区**：Backend 新增记忆候选存储（`research/memory/staged.json` 或同目录 JSONL，只追加 + 状态），每条：`id`、`target`（soul / recent）、`op`、`text`、`stance`、`origin`、`objects`、`source_session`、`source_turn`、`quote`（见 4）、`created_at`、`status`（staged / promoted / dropped）。上限 200 条，超出淘汰最旧的 `dropped` 与最旧的外部来源候选。
2. **来源等级 `origin`**（由 DSH 宿主代码判定，模型不能指定）：
   - `owner`：`stance` 为 `stated` / `corrected`，且候选带的 `quote` **逐字出现在本轮用户消息里**；
   - `untrusted`：本轮在该候选之前调用过外部内容工具——`fetch_source_url`、`search_external`、`stock_search_external`、`observe_radar`、`web_search`、`web_fetch`，以及读取研报或用户上传资料原文的 `source_read_blocks`（按返回的资料类型判断，判断不了按外部处理）。读公司定期报告、Wiki、议题、计算工具不算污染；
   - `agent`：其余由 Agent 推断的候选；
   - `system`：后台会话（公司研究任务、知识整理自身、报告任务）——**这些会话不产生候选**，直接跳过。
   - 规则顺序：后台会话 → 跳过；满足 owner 条件 → owner；本轮已污染 → untrusted；否则 agent。
3. **防回流**：候选文本与本轮已注入的核心记忆条目高度重复（规范化后相同，或同对象且包含关系）时不入暂存。
4. **直写核心**：`origin = owner` 且 `quote` 含明确的记住意图（“记住”“以后都”“以后请”“每次都”“不要再”“别再”等，词表放配置）时，直接写核心记忆（沿用现有 `PUT /wiki/research-memory` 与 CAS），同时在暂存区记一条 `promoted` 以便追溯。其余一律只进暂存。
5. **知识整理提示词**：`memoryOps` 每条增加 `quote`（用户原话里支撑它的片段，没有则留空）与 `objects`；说明只有用户原话能成为“明确表达”。
6. **记忆页**：新增只读分组“待整理（N）”，列出暂存候选（文本、来源等级中文名、来源会话时间），可删除；核心记忆编辑不变。
7. 注入逻辑本 Task 不改（M10-b 改）；晋升（M3）不在本 Task。

## 4. 范围

- Stock Backend：`app/services/research_memory.py`（暂存存储与接口：列表、追加、删除）、`app/api/v1/wiki.py`（路由）、测试。
- Stock DSH：`dsh/src/background-review.mjs`（来源判定、污染计算、分流写入）、`dsh/src/research-tools.mjs`（本轮注入条目记录，供防回流）、提示词、测试。
- Vibe：`dsh/finance-ui/research.mjs`（代理放行）、记忆页组件与测试。

## 5. 验收

- **执行方（自动）**：Backend 相关 pytest；Stock DSH `pnpm run test`；Vibe `npm run typecheck && env -u NODE_ENV node --test test/*.test.ts`、`node dsh/build-ui.mjs`；`git diff --check`。新增测试：四种来源判定（含 quote 不在用户原话里时不得为 owner）；外部工具之后的候选为 untrusted、读年报不污染；后台会话不产生候选；防回流；“记住”直写核心且留追溯；暂存上限淘汰；代理放行。
- **用户验收**：① 深度对话里说“记住：金额默认用亿元”，记忆页画像出现该条；② 让 Agent 读一个网页后讨论，记忆页“待整理”里相关候选标为“外部内容”；③ 普通研究对话后，核心记忆不再被自动改写，新内容出现在“待整理”。

## 6. Out of Scope

晋升任务（M3）；召回裁剪与 `memory_search`（M10-b）；议题跟踪项触发（M5）；画像指令化（M6）；向量检索。

## 7. Stop Conditions

- 从会话轨迹无法可靠取得“本轮用户消息”或“本轮工具调用顺序”：停止回填。
- 资料类型无法从 `source_read_blocks` 结果判断且会让几乎所有研究轮次都算污染：停止回填样例，由用户定边界。
- 与其他工具同时修改同一文件：先看 git 状态，冲突时停下告知用户。
