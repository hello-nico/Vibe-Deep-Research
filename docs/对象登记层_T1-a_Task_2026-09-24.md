## 1. 目标

每种对象只登记一次：身份解析、显示名、主页地址、打开方式都从一处取。标签点击一律进对象主页；刷新页面后标签仍显示真实名称；研究材料页下线。

## 2. 现状（2026-09-24 Claude 核实）

- **打开**：`dsh/client.tsx:116` `openResearchTarget` 按 `researchTarget()` 分支跳转；研究页类引用（`kind: 'wiki'`，公司 / 行业 / 主题 / 对比）一律跳 `/my-research/material?slug=…` 通用阅读页（`pages/ResearchMaterial.tsx`，14 行，内容为 `WikiReader`）。
- **显示名**：`lib/library.ts:91-101` `rememberMentionLabel` / `mentionLabel` 只存浏览器内存；刷新后 `chatFileMentions.resolve`（`dsh/client.tsx:152-168`）与 `dsh/research-input.ts:203-212` 退化为“研究材料 / 资料 / 议题”等兜底词。消息正文里带标题的折叠格式（`lib/researchMentions.ts`，如 `引用材料：<标题> \`<slug>\``）不受影响。
- **链接**：`lib/researchObject.ts`（`normalizeResearchTarget`、`researchObjectHref`）已按 slug 生成公司 / 行业主页地址，任务列表在用。
- **DSH 0.1.7 引用机制**：`InputTriggerSource.codec` 只有 `clipboardText`（复制与持久化投影）和 `serialize`（发给模型），**无显示名持久化**；新增 `openReference(session, { ref })`（输入框内引用点击预览）。结论：显示名需产品侧解析；`openReference` 接到登记层的打开。
- **可用的名称来源（无需新 Backend 接口）**：`lib/research.ts` `wikiPages(kind)`（公司 / 行业 / 主题 / 对比标题与摘要）；我的资料列表（`lib/library.ts` `listLibraryDocuments`）；议题列表（`GET /wiki/research-topics`）。

## 3. 冻结决定

- 新增 `lib/objectRegistry.ts`，每种对象一个登记项：`kind`、`parse(ref)`、`href(ref)`、`label(ref)`（同步，读缓存，未命中返回类型兜底词）、`resolve(refs)`（异步批量补名称并写缓存）。身份解析复用 `researchTarget`；地址复用并扩展 `researchObjectHref`（它的逻辑并入登记层，`researchObject.ts` 只保留转出或删除）。
- 对象与主页：

  | 对象 | 主页 |
  |---|---|
  | 公司 `companies/…` | `/research?company=<完整 slug>` |
  | 行业 `industries/nbs-…` | `/sectors/<短名>` |
  | 资料 `document:…` | `/my-reports/read/:id`（沿用现有带版本参数） |
  | 议题 `topic:<12hex>` | `/my-research/topics/<hex>` |
  | 产业研究 `profile:sw2:…` | `/sectors/profiles/<代码>` |
  | 主题 / 对比 `themes/…`、`comparisons/…` | 无主页：右侧只读抽屉（复用 `WikiReader`，外壳用统一右侧面板 `finance-side-panel` + 拖拽手柄） |

  网页、依据、行情、大盘、日期保持现有行为（网页新窗口、依据开依据面板等），登记层只转交。
- **显示名缓存**：进程内 Map + `sessionStorage` 持久（键 `finance-object-labels`，只存 `ref → 名称`，读写包 try/catch）；启动后按需批量解析：研究页类一次 `wikiPages` 各 kind（带并发去重与 5 分钟内复用），资料读资料列表，议题读议题列表。解析失败保留兜底词，不报错打断界面。
- 所有打开入口改走登记层：`openResearchTarget`、`chatFileMentions.resolve`、`finance-open-research-mention` 事件、`research-input` 的 `openReference`、任务列表与过程面板“打开研究页 / 打开成果”。
- 研究材料页下线：删除 `/my-research/material` 路由与 `pages/ResearchMaterial.tsx`；`ReportReader.tsx:140` 的来源返回文案去掉该分支；旧链接访问时回到“我的研究”。

## 5. 验收

- **执行方（自动）**：`cd desktop && npm run typecheck && node --test test/*.test.ts`；`git diff --check`；`node dsh/build-ui.mjs`。新增测试：
  - 各对象 `href` 正确（公司完整 slug、行业短名、资料带版本、议题、产业研究、旧 `companies/600309` 规范化）；主题 / 对比返回抽屉而非路由；

  - `resolve()` 对同一批 ref 并发只发一次请求；
  - 路由表不再含 `/my-research/material`。
- **用户验收（用户自己走）**：
  1. 深度对话里 @ 一家公司并发送，刷新页面后消息里的标签仍显示公司名，点击进入该公司研究页，对话面板不关闭。
  2. 点行业标签进行业研究页；点资料标签进资料阅读页；点议题标签进议题页。
  3. 点一个主题或对比研究的旧引用，右侧弹出只读抽屉显示正文，可拖动调宽、可关闭。
  4. 访问旧地址 `/my-research/material?slug=…` 回到“我的研究”，不报错。
