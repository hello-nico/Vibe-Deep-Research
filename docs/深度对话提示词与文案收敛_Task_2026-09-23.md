## 1. 问题

界面文案收敛只处理了展示文案。深度对话里还有一类问题：**写给模型的指令被当成用户消息显示出来**，外加模型回答用词与界面术语不一致。代码审查（未经浏览器实看）发现：

1. **界面代发的首条提问原样上屏**：
   - `pages/CompanyWiki.tsx:262-263` 公司研究：页面标识 `companies/xxxxxx-sh`、“公司 Wiki”、“系统按既有流程沉淀与刷新页面”。
   - `pages/CompanyWiki.tsx:285` 港美股研究：“不要把加入研究名单当成资料已发布”。
   - `pages/TopicWorkspace.tsx:118-124` 议题研究：议题 ID、`note_list` / `note_read` / `topic_list_links` / `read_composition_skill` / `wiki_validate_page_draft`、Theme / Comparison、沉淀记录。
   - `components/WikiReportPane.tsx:56-70` 报告生成：工具名、`data-ref` 规则、字号纪律；任务标题 `报告生成 · <slug>`（`WikiReportPane.tsx:266`）。在“任务过程”中可见。
2. **@ 引用展开文字未折叠**：`lib/researchMentions.ts:3` 只折叠“引用资料 / 议题 / 材料”三种；`dsh/research-input.ts:285-305` 的行情、大盘、产业研究、日期、网页五种原样显示，含 `observe_market`、`marketBenchmarkId`、`read_industry_profile`、Theme Wiki 等；资料标签后缀“解析版本”也上屏。@ 下拉提示有“申万产业研究 Profile”“日历日，不是盘中快照”。
3. **模型回答用词**：Stock `dsh/resources/research-discipline.md` 全英文，Topic / Theme Wiki / Comparison / Industrial Research / Research Links / Tracking / staged / admitted 没有中文显示名，仅“同花顺”有对照；回答可能与界面“议题 / 主题研究 / 对比研究 / 产业研究 / 研究记录”打架。
4. **工具调用卡片**：`lib/taskTrajectory.ts` 的中文步骤名只用于“任务过程”；主对话卡片由 DSH 原生渲染，可能显示英文工具名与参数。**未确认**。
5. **问助手 `assistant/prompt.ts` 未提交改动删多了**：去掉了“页面显示值不是工具读取结果 / 不进入证据层”（`:253`、`:323`）和“补读不得覆盖或混用本轮版本”（`:327`，并把适用范围缩成“同一网址”）。与 AGENTS.md“数字必须能回到真实证据”冲突。

## 2. 目标与冻结决定

- 用户气泡只出现用户能读懂的话和可点标签；指令不上屏。
- 模型拿到的约束**不减少**：迁移位置可以变，意思不能丢。
- 模型对外用词与界面术语表（前序 Task §3）一致。
- 已有的 Stock 会话角色（`deep_research` / `my_research` / `wiki_report`）承载角色级指令；不新增角色、不改角色判定、不改工具集合与权限。
- 复用现有折叠机制：`引用材料：<标题> \`<slug>\``、`引用议题：<标题> \`topic:<id>\`` 已能显示成标签。

## 7. Out of Scope

- 工具集合、权限守卫、角色判定、会话绑定与持久化结构。
- `research-discipline.md` 除对照表外的纪律内容；各页面助手 plugin prompt 的业务条文。

- 问助手 Ask / Agent 模式名；前序 Task 已完成的展示文案。
- 历史会话中已发出的旧首问不回改。

## 8. Stop Conditions

- 指令迁入角色 prompt 后，真实运行中模型不再按原步骤调用工具（如议题会话不读已有关联、报告未发布）：回退该项迁移，记录现象，交用户裁决。
- `reportDesignContract` 依赖页面类型、无法在不改数据流的前提下迁出：保留在首问中，放到报告任务视图里默认折叠，记录。
- 任务标题、首问文字被代码用于识别会话（如 `findCompanySession` 的标题前缀）：保留被匹配部分，记录。
- DSH 不支持工具显示名定制：D 批停止，记录，不自造渲染层。
- 折叠需改动 DSH 消息结构而非 DOM 展示层：停止，记录后另议。
