## 统一规则

- 同类操作复用现有 token/组件，统一文字、图标、尺寸和状态；以已选 Session 日志样式核验新建等次要操作，避免一页一套。
- 用户要求移除的橙色装饰边框应检查选中、悬停、输入焦点等完整消费者；不得靠连续增加覆盖层解决冲突。错误和键盘操作仍须可辨。
- 技术标识从可见文案隐藏，不删除底层引用；空内容解释真实状态，不用 JSON 或假数据填满卡片。
- 点击历史后仍能新建；归档复用原生能力。隐藏入口不是删除数据，不改变权限默认值。
- 长等待应可理解、可停止或可重试，不能仅换掉“未配置”提示而不修复模型接线。
