# 客户演示计划（2026-09-26）

用途：面向客户 30–60 分钟的产品演示，一次讲清特色、核心功能和流畅性。用户 2026-09-25 决定：**等整体验收修复第 2 轮完成并复验通过后再演示**，演示前冻结版本。

## 1. 讲一条主线，只用 4 个词

| 给客户的说法 | 对应功能 |
|---|---|
| **研究页** | 每家公司、每个行业一页，数据和结论都在这里 |
| **依据** | 每个数字、每句结论都能点开，看到年报原文 |
| **议题** | 你持续关心的一个问题，系统记着当前判断和证据 |
| **助手** | 在哪一页都能问，它先看你眼前的页面再回答 |

不出现的内部名词：Jev、DSH、知识整理、草案、来源等级、快照、会话 ID。

开场一句话：**“这是一个投研工作台：它不替你荐股，但让你看到的每个数字都能追到原文，让你的研究判断有记忆、能延续。”**

## 2. 标准版流程（45 分钟）

路线：看市场 → 看公司 → 形成判断 → 沉淀。

| 时间 | 页面 | 演示内容 | 客户记住的点 |
|---|---|---|---|
| 0–3 | 开场 | 一句话定位 + 不荐股原则 | 研究工具，不是荐股工具 |
| 3–9 | 大盘行情 | 指数、情绪、成交额榜、板块资金；「问助手」用 Ask 问“今天大盘怎么样”，回答直接用页面数字；@ 一只股票追问 | 助手懂你眼前的页面，几秒回答 |
| 9–14 | 资讯雷达 | 投资资讯、AI 标题翻译、一键提炼要点；@ 一条新闻问“对哪些公司有影响”，切 Agent 看它读原文 | 信息多，但一句话钻进一条 |
| 14–24 | 个股研究：长江电力 | 研究页（经营 / 财务 / 估值 / 资料时间线）；**点“查看依据”打开年报原文块（全场最关键一下）**；图文报告；「报告已过期」徽标与「刷新资料」 | 每个数字有出处；研究页随资料更新 |
| 24–36 | 议题：电力行业公司结构 | 当前判断与判断时间；**证据墙**：长江电力 → 湖北能源持股线、关系卡；画一条假设线；“判断之后依据有更新”；议题图文报告 | 判断不是一次性的，证据变了会提醒 |
| 36–42 | 深度对话 | 问“华能国际 2025 年营业收入和上网电量分别是多少，给出原文依据”；行内引用标签、图表 | 可以深挖，答案可追溯 |
| 42–45 | 我的研究 | 待处理、议题、记录、任务过程（状态点）、记忆 | 研究会被整理和沉淀 |
| 45– | 问答 | | |

**30 分钟精简版**：去掉资讯雷达和我的研究；议题只看证据墙；深度对话改为播放提前跑好的会话。

**60 分钟加长版**：加产业研究（申万行业画像）、行业 Wiki、自选股；证据墙现场「找依据」；专门讲一段“不荐股、不给目标价”的研究纪律。

## 3. 风险与绕开方式

| 风险 | 做法 |
|---|---|
| 现场发起“公司研究”要 4–5 分钟；知识整理的失败修复刚完成，尚未真实复验 | 不在现场发起。用已有研究页的长江电力、万华化学演示 |
| 模型偶发格式错误（`MALFORMED_RESPONSE`，DeepSeek-V41-Flash 出现过） | 演示时选更强的模型；所有 Agent 问题提前跑一遍 |
| 议题图文报告里部分引用指错原文块（2026-09-25 发现，待修） | “查看依据”只在**公司研究页**上点；议题报告只展示结构与关系图，不点其中引用 |
| 晚间取数失败（东方财富盘后常 502） | 当亮点讲：标题旁黄点，悬停显示“这次没有取到最新数据，显示的是 15:00 的内容”——系统不给假数据 |
| 窗口窄时面板盖住主区 | 全屏浏览器，宽度 ≥ 1400px，投屏前调好缩放 |

## 4. 演示前准备清单

1. **版本冻结**：修复第 2 轮已实施并通过自动检查、Claude 已审阅。用户重启工作台 → Codex 复验对应编号（第 4、5、6、8、13、14、19、22–25、33、34、35、38、42 项）→ 通过后提交；之后演示前不再改代码、不再重启。
2. **数据准备**：
   - 长江电力研究页：“经营”块有内容（没有就换万华化学）；
   - 长江电力、华能国际的图文报告已生成；
   - 电力议题：证据墙有持股线和一条假设线，“依据变化”有内容；
   - “记录”里有几条像样的问答。
3. **预演一遍**，当天用完全相同的问法：大盘 Ask“今天大盘怎么样”、资讯 @ 一条新闻问影响、深度对话问华能营收与上网电量。记下每步耗时；超过 30 秒的步骤准备好已跑完的会话作备用。
4. **浏览器**：Chrome 全屏，关无关标签页，界面中文。
5. **兜底**：录一段 3–5 分钟的完整操作视频，现场网络或模型出问题时直接播放。

## 5. 收尾三句话

- **“每个数字都能回到原文”**（呼应“查看依据”）；
- **“你的判断有记忆、证据变了会提醒”**（呼应议题与证据墙）；
- **“在哪一页都能问，而且它懂你正在看什么”**（呼应问助手）。

定位收尾：**“我们不告诉你买什么，我们帮你把研究做得更快、更可核对。”**
