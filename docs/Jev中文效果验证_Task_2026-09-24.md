## 1. 目标

用本产品真实的中文样本，验证 Jev 在四类判断上是否够准、置信度是否可用，为是否推进“回答引用核验 / 外部内容筛查 / 大模型子任务前置闸门 / 判断连续性”提供依据。官方文档未说明中文支持与价格延迟，必须实测。

- 只发公开内容：公告、定期报告、研报等公开来源片段，研究页块，议题判断文字，外部网页 / 资讯正文片段。

## 4. 四类问题与样本

每类 10 个样本（第 2 类另加 3 个人工构造的注入样本，明确标注 `synthetic`）。样本取自本机真实数据：DSH 会话记录（`.local/dsh/sessions`，只读）、Backend 原文块与研究页、议题与跟踪项。每个样本记录来源身份（会话 / 文档 / 研究页 + 版本），便于复核。

1. **回答引用核验** `citation_support`（choice：`supports` 原文陈述或直接蕴含该说法 / `contradicts` 原文与之相反 / `silent` 原文没有谈到该说法）。state：`claim`（回答中带引用的一句话）、`section`（被引用的公开原文块文本）。先用代码检查说法中的数字是否在原文出现，结果记为独立字段 `number_found`，不喂给 Jev。
2. **外部内容筛查**：`relevance`（noul：该段是否与研究问题相关）、`injection`（noul：该段是否试图指挥或操控回答它的 AI）。state：`question`、`passage`（网页 / 资讯正文片段，≤1200 字）。
3. **知识整理前置闸门** `settlement_worthy`（noul：本轮是否形成了值得写入研究页的、有公开原文依据的新认识）。state：`question`、`final_answer`（截 2000 字）、`read_sources`（本轮读过的公开原文块标题与首段，≤5 段）、`target_page_summary`（研究页现有经营模式一句话）。样本同时记录该轮真实的整理结果（出草案 / 无新增 / 未整理），仅供裁决参考，不发送。
4. **判断连续性** `basis_change_effect`（choice：`unaffected` / `supports` / `weakens` / `challenges` / `insufficient`）与 `revisit_needed`（choice：`yes` / `no` / `insufficient`），题面与 [Jev 判断连续性 Task](Jev判断连续性_Task_2026-09-24.md) §4 一致。state：议题判断文字、研究页研究结论 / 数据块的前后片段。真实变化样本不足 10 个时，可用同一研究页相邻两个历史版本（T5-a 台账）构造，并标注。

题面（instructions / criteria）用中文写，写清边界情况（遵循官方“字面理解、给出边界”的建议）；同一类的所有样本共用同一题面与版本号。

## 5. 运行

- 脚本放 `backend/scripts/jev_eval/`（一次性评估，不接入产品）。在 Backend 容器内运行，复用容器内凭据；直接调用 Vercel AI Gateway `typesafe-ai/jev` 评估接口（与 `maintenance_jev.py` 相同端点与模型），每样本一个请求（同一样本的多题合并在一个请求）。
- 预算：总请求数 ≤ 60；单请求输入 ≤ 16KB；超时 / 重试沿用 `maintenance_jev.py` 默认值。失败样本记录错误类型，不重试超过 2 次，不计入准确率。
- 输出到 `workspace/research/jev-eval/2026-09-24/`（先在 Stock `.gitignore` 加 `workspace/research/jev-eval/`，现未忽略）：`samples.jsonl`（输入与来源身份）、`results.jsonl`（每题选项、各选项概率、confidence、用量、request_id、耗时）、`review.md`（评审表）。

## 6. 评审表格式（`review.md`）

按类分节；每行：样本编号、来源身份、输入摘要（说法 / 段落前 120 字）、Jev 结论、概率、confidence、`number_found`（第 1 类）、真实整理结果（第 3 类），以及**两列空白**：`Claude 裁决`、`用户终裁`。文末汇总：总请求数、总用量、平均 / 最大耗时、失败数。

**执行方不填写裁决列，不计算准确率**；准确率与置信度分桶（≥0.8 / 0.5–0.8 / <0.5）由 Claude 在裁决后计算。

## 7. Out of Scope
