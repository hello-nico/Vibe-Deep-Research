## 当前架构

```text
scripts/setup
  → 安装固定 runtime 与补丁 → 构建产品 UI → plugin add link: 安装至 Web profile

scripts/start
  ├─ 原业务 API :8765
  └─ Vite 产品入口 :5930（同源 HTTP / WebSocket 代理）
       └─ DSH runtime :5941
            ├─ Node Cordis：profile/Loader 启用服务端插件
            ├─ dsh-client-modules：清单、/plugins 资源与标准 Web 启动入口
            └─ 浏览器 Cordis：加载 finance UI，组合产品页面与 DSH slot
```

同一插件包的主入口在 Node 执行，`dsh.client.platform: web` 与 `exports["./client"]` 声明浏览器入口。两端 Context 不共享服务实例；跨端数据通过 API/远程服务传递，不会自动把工具或密钥注入浏览器。

`dsh-client-modules` 的 Node 半侧提供 `ctx.clientModules`，发现已启用包、读取预先构建的 bundle 并分发；它不负责替产品编译 TS/React。浏览器半侧提供 `ctx.modules`，注册并解析模块 factory、共享 React，再由浏览器 Loader 启用插件。

相较重构前，已删除产品自建 Context、Loader、React root 及 `desktop/src/main.tsx`、`desktop/index.html`；保留现有业务页面，由正式客户端插件装配。没有 iframe，不把 DSH 包装成旧 `/chat` 的 CLI Provider。**客户端启动权已归 DSH，产品运行入口仍使用 Vite，尚非独立桌面发行。**

## 版本、配置与启动

`@deepseek-ai/dsh` 与 `dsh-*` 包固定 `0.1.2-rc.1`，React / ReactDOM 固定 `18.3.1`；产品 bundle 不打包 React，消费 DSH 平台共享实例。补丁清单与升级边界见 [runtime 说明](../desktop/dsh/runtime/README.md)，补丁应用失败即中断安装。本地 deepseek-harness 的 `dd6322d604` / `0.1.2-alpha.3` 仅是此前原理阅读基线，不是本次 rc.1 的精确源码。

首次或依赖变化运行 `./scripts/setup`；日常运行 `./scripts/start`，访问 `http://127.0.0.1:5930/`。开发模式只启动一个 watch，**首次构建完成后再启动 DSH**，后续产物更新由 DSH 客户端更新机制接收。路径或启动配置修改后重启服务。

| 配置 | 优先级（从高到低） |
| --- | --- |
| 工作区 | `VRA_DSH_WORKSPACE` → 配置 workspace → 数据根/dsh-workspace |
| DSH 状态 | `DSH_HOME` → 配置 home → 数据根/dsh |
| runtime | `VRA_DSH_RUNTIME` → 配置 runtime → 本仓 desktop/dsh/runtime |
| 配置文件 | `VRA_DSH_CONFIG` → 仓库根 dsh.config.json（可缺省） |

数据根沿用 `VRA_DATA_ROOT` / 产品配置，相对路径按仓库根解析；显式指定但不存在的配置报错。状态目录与工作区不得相同或嵌套，包含符号链接解析后的路径。重构不自动迁移、重置会话或模型配置；会话指针继续按工作区保存，并用 `cwd` 校验复用。

入口限本机，拒绝 `VRA_LAN=1`；代理校验 Host / Origin / Fetch-Site，启动认证 cookie 留在服务端。凭据仍由 DSH 按既定环境与配置来源解析，不复制其他宿主登录态。

## 视觉与修复边界

- 产品外壳、会话与设置共用主题；主题选择仅在 DSH 设置中。侧栏「设置」紧接「研究记录」，沿用 `workspace-nav-link`，内层保留原生 trigger；收起时只留图标，不另建设置路由、不裁剪设置功能。
- 设置弹窗祖先不能通过 filter/transform 等意外限制 fixed 遮罩。产品适配使用主题变量、slot 与语义属性，不依赖上游 hash 类名。
- rc.1 composer 目录按钮硬编码、无关闭入口，保留容器内 CSS 隐藏这一有界例外；后台仍注册工作区，隐藏按钮不是权限隔离。
- 既有展示调整保留：投研助手文案、连接正常时不显示状态、共享业务表单样式、用户可见「取数」改为刷新/数据时间；轨迹分隔线只调整伪元素高度，不改变 table 模型。
- 启动超时修复：移除重复构建及其与 DSH 加载产物的竞争，先完成 watch 首次构建，并补充进程退出/认证失败提示；未靠延长总等待时间掩盖问题。
- 模型搜索错位修复：在 `dsh-client-ui-model-selection` 持久化补丁内补齐 `search/searchIcon/searchInput` 类名映射和样式，横向排列、16px 图标、输入框收缩与主题色均由该组件拥有；不向产品全局 CSS 追加兜底。已同步当前安装产物，后续 setup 可重放。
